# 에셋 확보 판정

> 상위: `docs/07-production/dev-requirements.md` §5 · `docs/07-production/asset-ledger.md`(대장)

## 0. 대전제 — 이것 하나만 틀리지 않으면 된다

**「무료」는 「상용 가능」이 아니다.**

이 프로젝트는 **상용 모바일 게임**이다. 스토어에 올라가고 과금이 붙는다.
따라서 비상업 전용(NC) 에셋은 **무료여도 쓸 수 없다.**

두 번째 대전제: **사이트를 믿지 말고 파일을 믿는다.**
OpenGameArt·Freesound처럼 **파일마다 라이선스가 다른** 사이트가 많다.
「이 사이트는 CC0이더라」는 판정 근거가 되지 않는다. **항목 단위로 확인한다.**

## 1. 판정 순서

항목 하나를 받으면 이 순서로 내려간다. **위에서 걸리면 아래는 보지 않는다.**

| # | 질문 | 예 → | 아니오 ↓ |
|---|---|---|---|
| 1 | **게임의 정체성에 닿는가?** (성계 지도·주요 인물·UI 골격) | **자작 또는 외주.** 무료 에셋 금지 — 다른 게임과 겹치면 세계관이 죽는다 | ↓ |
| 2 | 형태가 정해진 범용물인가? (아이콘·UI 부품·기본 SFX) | **무료(CC0 우선)** | ↓ |
| 3 | 양이 많고 규격이 반복되는가? (권역 45개 배경 등) | **절차적 생성 + 자작 변주**를 먼저 검토 | ↓ |
| 4 | 전문 기술이 필요한가? (BGM·성우) | **외주.** 단가와 저작권 양도 범위를 먼저 확정 | ↓ |
| 5 | 그 외 | **자작** | |

> 1번에서 걸리는 항목이 생각보다 많다. 성계 지도·회랑 표현·천명 게이지는
> 이 게임의 **주제축을 시각화한 것**이라 대체 불가다.

## 2. 라이선스 등급

| 등급 | 라이선스 | 이 프로젝트에서 |
|---|---|---|
| ✅ **무조건 가능** | CC0 / Public Domain / Unlicense | 표기 의무도 없다. **1순위** |
| ✅ **가능, 표기 필요** | CC-BY 4.0 / MIT / Apache-2.0 / **OFL**(폰트) | 크레딧 화면이 **필수 산출물이 된다.** UI 요건에 반영할 것 |
| ⚠ **조건부** | CC-BY-SA | **전염성이 있다.** 2차 저작물도 같은 조건으로 공개해야 한다. 게임 에셋에는 원칙적으로 쓰지 않는다 |
| ⚠ **개별 확인** | 독자 EULA (Kenney·Unity Asset Store 등) | 재배포·수정·상용 조항을 **원문으로** 읽는다 |
| ❌ **사용 금지** | **CC-BY-NC** / NC 계열 / 「개인 사용만」 / 「비상업적」 | 상용 게임이므로 예외 없음 |

## 3. 함정 6개

1. **CC-BY-SA의 전염성** — 배경 하나 잘못 쓰면 그 화면 전체가 걸릴 수 있다
2. **폰트는 별개 세계다** — 한글 폰트는 「무료 배포」와 「임베딩 허용」이 다르다.
   게임은 **임베딩**이다. OFL은 임베딩 허용, 그 외는 개별 확인
3. **AI 생성물** — 스토어·심의에서 **고지 의무**가 생길 수 있다. 학습 데이터 출처
   분쟁도 있다. 쓰려면 대장에 「AI 생성」으로 명시하고 §7.3 스토어 정책과 대조한다
4. **「출처 표기」의 실제 비용** — CC-BY 에셋 200개면 크레딧 화면 200줄이다.
   대장을 안 쓰면 출시 직전에 복원 불가능해진다
5. **원저작자 표기 형식** — CC-BY는 저작자·라이선스·원본 링크·수정 여부까지 요구한다.
   「출처: OO」만으로는 부족하다
6. **삼국지 소재의 2차 저작물** — 원전 자체는 공유재산이지만, **특정 게임·만화의
   디자인**을 참조하면 별개 문제다. CLAUDE.md §6.1 「원전에서 답을 찾는다」를 지킨다

## 4. 라이선스 대장 — 형식

산출 위치: `docs/07-production/asset-ledger.md`
**에셋 하나 = 한 줄.** 확보하는 즉시 기록한다. 나중에 몰아 쓰면 복원 못 한다.

| ID | 항목 | 확보 | 출처 | 라이선스 | 표기 의무 | 수정 | 확인일 |
|---|---|---|---|---|---|---|---|
| `SFX-001` | 함대 이동음 | 무료 | (URL) | CC0 | 없음 | 있음 | 2026-08-24 |
| `FNT-001` | 본문 서체 | 무료 | (URL) | OFL 1.1 | **필요** | 없음 | 2026-08-24 |

- **`확인일`을 반드시 넣는다.** 라이선스는 바뀐다. 출시 전 재확인 근거가 된다
- **`표기 의무: 필요`가 하나라도 있으면** 크레딧 화면이 UI 요건으로 승격된다

## 5. 확보처 — 후보일 뿐, 항목 단위로 확인한다

| 종류 | 후보 | 주의 |
|---|---|---|
| 2D·UI | Kenney (대부분 CC0) | 독자 EULA 확인 |
| 3D·HDRI | Poly Haven (CC0) | — |
| 혼합 | OpenGameArt | **파일마다 라이선스가 다르다** |
| 사운드 | Freesound | **파일마다 다르다.** CC-BY가 많다 |
| 서체 | Google Fonts·Noto (OFL) / 눈누 | 눈누는 **폰트별 조건이 제각각**. 임베딩 항목을 볼 것 |
