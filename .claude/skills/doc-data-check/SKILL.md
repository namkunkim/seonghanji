## 3. 검사 — 실행할 것

### 3.1 옛 숫자 잔존 (함정 3)

성계 수는 14 → 15 → **19**로 변천했다. 오래된 문단에 옛 값이 남아 있을 수 있다.

```
grep -rn "성계 14\|성계 15\|14개 성계\|15개 성계" docs/
```

### 3.2 태양계 위치 (함정 4)

청주 → 요동 → **형주**로 세 번 바뀌었다.

```
grep -rn "태양계" docs/ | grep -v "태양계권" | grep -v "형주"
```

> ⚠ **`태양계권`은 권역 이름이다.** 배제하지 않으면 `region-power.md`·
> `partial-occupation.md`에서 오탐이 대량으로 나온다.

→ 걸린 줄이 **변천 이력 서술**인지 **현행 오기**인지 반드시 눈으로 구분한다.

### 3.3 서사의 SF 어휘 (CLAUDE.md §3)

**서사 텍스트 본문에 한한 제약이다.** 기획·시스템 문서는 대상이 아니다.

```
grep -n "우주\|은하\|행성계\|성간" docs/05-narrative/*.md
```

→ 걸리는 줄은 **집필 지침·검수표뿐**이어야 한다. 본문에 있으면 위반이다.
현재 `ending-variations.md`·`event-scripts.md`·`interludes.md`는 「0회」를
합격 기준으로 기록해 두고 있다.

### 3.4 한자 병기 (CLAUDE.md §3)

한자 병기는 폐지되었다. **예외는 `glossary.md`와 `DECISIONS.md` 둘뿐이다**
(V-07·V-08에 따라 신·구 대조 목적으로 의도적으로 남긴 것).

```
grep -rn "([一-龥]" docs/ --include=*.md | grep -v "glossary\|DECISIONS"
```

### 3.5 generals-150.md 내부 충돌 (함정 1)

§1~6은 작업 순서대로 쌓인 기록이고 **§12·§13·§14가 최종본**이다.
이 파일의 앞부분 수치를 인용하기 전에 뒤를 먼저 본다.

### 3.6 프롤로그 범위 (함정 5)

184~190 → **184~189**로 단축됐다. 폐립·소각·연합은 시나리오 1의 플레이 이벤트다.

```
grep -rn "184~190\|184-190" docs/
```

## 4. 문서 구조 (CLAUDE.md §4.1)

모든 설계 문서는 상단에 `상위 문서 참조 · 작성일 · 상태`, 말미에
`## 검토 포인트`와 `## 미작성 항목`을 가진다.

```
for f in docs/*/*.md; do grep -q "## 검토 포인트" "$f" || echo "검토 포인트 없음: $f"; done
```

> ⚠ **검토 포인트는 절대 지우지 않는다.** 해소되면 `~~취소선~~`으로 바꾸고 근거를 남긴다.
> 검사에서 「해소된 항목이니 삭제」를 제안하지 않는다.

## 5. 연쇄 갱신 (§4.4)

한 문서를 고쳤을 때 함께 봐야 하는 곳.

| 고친 곳 | 함께 볼 것 |
|---|---|
| 무엇이든 주요 결정 | `00-overview/design-overview.md` (통합 기획서) · `docs/INDEX.md` |
| 수치·범위·눈금 | `docs/INDEX.md` §핵심 수치 |
| 기각·번복 | `docs/DECISIONS.md` (변경 근거를 남긴다) |
| 지리 | `01-world/star-map.md` · `assets/star-map.html` · `04-campaign/world-state*.md` |
| 인물 | `02-characters/*` · `04-campaign/character-assignments.md` |
| 시스템 눈금 | 해당 문서 + `03-systems/*` 전반 |

> ⚠ **전역 눈금은 신설 전에 검색한다.** 천명 눈금을 두 세션이 각자 만들어
> 한쪽을 철회한 사고가 있었다 (`JOBS.md` §4 검토 포인트 5).

## 6. 보고 형식

발견 사항은 **고치지 말고 먼저 보고한다.** CLAUDE.md §6.1: 「모순을 발견하면 즉시 보고」.

| # | 위치 | 발견 | 정본 | 판정 |
|---|---|---|---|---|
| 1 | `star-map.md:88` | 「성계 15개」 | 19 | **오기 — 수정 필요** |

취소선 항목은 **과거 값을 보존하는 것이 목적**이다. 판정 없이 일괄 치환하지 않는다.
