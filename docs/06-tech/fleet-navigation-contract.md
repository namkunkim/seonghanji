# 함대 이동·상세 관측 계약

## 화면 경계

| 화면 | 책임 | 선택 결과 |
| --- | --- | --- |
| 전략 함대 이동 | 지도에서 실제 이동 상태와 편대의 위치를 읽고 명령한다. 수백 척은 점·소형 실루엣 편대로 나타난다. | 함대 상세 관측을 연다. |
| 함대 상세 관측 | 선택한 같은 함대의 함종 비율을 대표 편대로 3D 항행 연출한다. | 닫으면 이전 전략 이동 화면으로 돌아간다. |

큰 기함 또는 근접 함선 모델은 상세 관측에만 사용한다. 전략 화면은 이동 판독성과 다수 편대의 동시 인지가 우선이다.

## 항행 정본

활성 이동 함대는 `at_system`(출발 성계), `target_region`, `departure_tick`, `arrival_tick`, 총 `ships`, `plan`을 보유한다. 이 값은 명령 적용 시 기록하고 도착 시 이동값을 해제한다.

전략 화면은 출발·도착 좌표와 `(현재 tick - departure_tick) / (arrival_tick - departure_tick)`로 현재 위치를 계산한다. 출항 tick 또는 유효 경로가 없는 기존/손상 데이터에는 진행률을 꾸며 내지 않고 관측 불가 또는 정지 상태로 표시한다.

`ships_by_kind()`는 총 척수와 편성안으로 함종별 정수 척수를 결정론적으로 배분한다. 전략 편대의 밀도와 상세 관측의 대표 편대는 같은 결과를 기준으로 한다. 상세 관측은 성능을 위해 최대 24척의 대표만 렌더하지만, 비율은 실제 배분을 유지한다.

## 다음 데이터 확장 조건

현재 항로는 출발·도착 좌표 사이의 진행률까지 정본화되어 있다. 중간 성계·회랑을 경유하는 동안 각 구간을 정확히 표시하려면, 월드에 `route_systems` 또는 `route_segments`와 현재 구간 인덱스를 추가해야 한다. 그 전에는 UI가 중간 경유점을 추정해 표시하지 않는다.

향후 함종별 전투 손실·보충이 도입되면 `ships_by_kind()`의 파생 배분을 `Fleet`의 영속 함종별 척수로 교체한다. 두 화면은 그 새 필드를 함께 읽어야 한다.
