## 0. 왜 이것이 최대 공백인가

우리가 만든 두 개의 핵심 시스템이 **AI 없이는 반쪽이 된다.**

| 시스템 | AI가 없으면 |
|---|---|
| **부분 점령 (권역 45)** | AI가 권역 단위 전략을 못 짜면 **플레이어 전용 이점**이 된다 |
| **세계 상태 4형 + 기능 이벤트 40** | AI가 이벤트를 못 고르면 **역사가 생성되지 않는다** |

> AI는 이 게임에서 「상대」가 아니라 **「역사를 만드는 다른 손」**이다.

## 1. 설계 원칙

### 1.1 최적화가 아니라 성격

> **AI의 목표는 잘 두는 것이 아니라 그 인물답게 두는 것이다.**

원소는 결정을 미루고, 조조는 과감하고, 유표는 지킨다.
**이것은 AI의 결함이 아니라 사양이다.**

우리는 이미 재료를 갖고 있다 — 군주 유형 5종, 인물 성향 5종, 고유 특성 150개.
**새로 만들 것이 아니라 연결할 것이다.**

### 1.2 예측 가능성

플레이어가 **읽을 수 있어야** 한다.

> 「원소는 지금 남하하지 않을 것이다. 참모 의견이 갈렸으니까.」

이런 추론이 가능해야 전략 게임이 성립한다.
**신경망 대신 유틸리티 기반(Utility AI)을 택하는 이유다.**

### 1.3 치팅 금지

AI에게 별도 규칙을 주지 않는다.

| 항목 | AI 적용 |
|---|---|
| 동원율 | **동일** |
| 전화 계수 | **동일** |
| 회랑 통과 시간 | **동일** |
| 정보 가시성 | **동일** (난이도로만 조절) |
| 자원 보너스 | **없음** |

> 치팅으로 만든 난도는 플레이어가 학습할 수 없다.

### 1.4 디버깅 가능성

모든 결정에 **사유 로그**를 남긴다.

```
[AI/원소] 결정: 남하 보류
  근거: 남하 utility 0.42 / 준비 utility 0.61
  요인: 보급 미비 −0.18 · 참모 의견 분열 −0.12 · 후방 위협 −0.09
  성격 보정: 명문형 결단 임계 0.15 (미달)
```

|---|---|---|---|

| **Operational (작전)** | 권역 목표 · 함대 배치 · 개발 | 게임 내 월 | 약 1시간 |

## 3. 유틸리티 평가

### 3.1 기본 구조

```
행동 점수 = Σ (요인값 × 성격 가중치)

선택 = 점수 최대 행동
       단, 「결단 임계」 미달 시 보류
```

### 3.2 공통 요인

| 요인 | 산출 |
|---|---|
| **국력 이득** | 획득 예상 권역 국력 합 |
| **천명 영향** | 해당 행동의 천명 증감 |
| **위험도** | 실동원 대비 손실 예상 |
| **연결성** | 획득 시 비지 해소 / 상실 시 비지 발생 |
| **위신** | 명분·체면 관련 (명문형에 중요) |
| **보복 위험** | 패권 압력 상승 · 견제 연합 결성 확률 |
| **시간 압력** | 할거 페널티 진행도 · 격차 확대 속도 |

## 4. 군주 인격 프로파일

군주 유형 5종이 **가중치 세트**가 된다.

| 유형 | 국력 | 천명 | 위험 회피 | 위신 | 배신 성향 | 결단 임계 |
|---|---|---|---|---|---|---|
| **인덕형** | 0.6 | **1.4** | 1.1 | 0.9 | **0.2** | 0.5 |
| **패도형** | **1.4** | 0.6 | **0.7** | 0.8 | 1.0 | **0.3** |
| **명문형** | 1.0 | 1.1 | 1.2 | **1.5** | 0.7 | **0.8** |
| **실리형** | 1.2 | 0.9 | 1.0 | 0.7 | **1.2** | 0.5 |
| **무단형** | 1.3 | **0.2** | **0.5** | 0.6 | **1.5** | **0.2** |

### 4.1 결단 임계 — 원소의 재현

```
if (최고 점수 − 차선 점수) < 결단 임계:
    결정 보류 (다음 주기로 이월)
```

**명문형은 임계가 0.8로 가장 높다.**
선택지가 비슷하면 결정하지 못하고, 그 사이에 상황이 변한다.

> **원소의 약점은 우둔함이 아니라 구조다** (기능이벤트 F-27).
> 강한 세력이기에 선택지가 많고, 명문형이기에 임계가 높다.
> **AI가 실수하는 것이 아니라, 원소답게 행동하는 것이다.**

### 4.2 참모 의견 시스템

Grand 계층 결정 시 **참모형 인물의 조언**이 요인으로 들어간다.

```
조언 반영도 = 인물 지력 × 군주와의 상성 × 성향 보정

성향 보정:
  명사 → 명문형 군주에게 ×1.3
  실무 → 패도형·실리형에게 ×1.3
  절의(강직) → 명문형에게 ×0.5   ← 반발
```

| 결과 | 효과 |
|---|---|
| 조언 일치 | 해당 행동 점수 상승. 결단 임계 완화 |
| **조언 분열** | 점수 차 축소 → **결단 임계 미달 확률 상승** |
| 조언 무시 누적 | 해당 인물 이탈 판정 (F-28) |

> **저수와 전풍이 옳은 말을 해도 원소는 듣지 않는다.**
> 「강직」 성향 × 명문형 군주 = 반영도 0.5.
> 정확히 원전의 구도가 수치로 나온다.

## 5. 권역 전략 AI — 최대 공백

### 5.1 권역 가치 평가

부분 점령이 AI에게도 작동하려면 **권역마다 다른 가치**를 알아야 한다.

```
권역 가치 = 국력 가치      (인구·생산·수입)
          + 항로 가치      (고속항로·회랑 귀속 여부)
          + 절단 가치      ★ 아래 §5.2
          + 연결 가치      (아군 권역과 인접한가)
          + 상징 가치      (태양계권 등)
          − 방어 비용      (접경 수 · 지형)
```

### 5.2 절단 가치 (Cut Value) — 핵심

> **한 권역만 빼앗아 적의 나머지를 비지로 만들 수 있다.**
> AI가 이것을 발견하지 못하면 부분 점령은 플레이어 전용 기술이 된다.

**그래프 연산으로 해결한다.**

```
1. 적 세력의 보유 권역을 노드로, 인접 관계를 간선으로 하는 그래프 구성
2. 절단점(articulation point) 탐색
3. 각 절단점을 제거했을 때 고립되는 권역의 국력 합 = 절단 가치
```

| 규모 | 비용 |
|---|---|
| 노드 45개 · 간선 약 90개 | **매우 가벼움** (Tarjan 알고리즘, O(V+E)) |
| 세력 최대 19개 | 전체 재계산해도 밀리초 단위 |

**적용 예시 (219년 형주)**

```
촉 보유: 중부권 · 남부권 · 태양계권 · 익주3 · 한중2 · 남중2
중부권 제거 시 → 남부권·태양계권 고립
절단 가치 = 남부권(15) + 태양계권(2) + 상징 보정 = 높음

→ AI는 중부권을 최우선 목표로 인식한다
→ 여몽의 백의도강이 「설계된 이벤트」가 아니라 「AI가 발견한 최적수」가 된다
```

> **이것이 이 문서에서 가장 중요한 부분이다.**
> 기능 이벤트 F-12(동맹의 배후 기습)를 AI가 스스로 도출한다.

### 5.3 항로 절단 평가

```
항로 절단 가치 = 해당 항로를 잃었을 때 적의 동원율 하락폭
                × 적 실동원
```

형주 중부권을 잃으면 장강 대항로가 끊기고, 익주와 양주가 분리된다.
AI는 이것을 **동원율 시뮬레이션**으로 평가한다.

### 5.4 자기 방어 평가

같은 연산을 자기 영토에 적용해 **자신의 절단점을 방어**한다.

| 결과 | 행동 |
|---|---|
| 아군 절단점 식별 | 우선 방어 배치 |
| 절단점이 회랑 귀속 | 방어 비용 대폭 감소 → 소수 배치 |
| 절단점이 기저 항로만 | 전면 방어 필요 → 병력 다수 배치 |

## 6. 기능 이벤트 선택 AI

### 6.1 평가 절차

```
1. 40종 이벤트의 발동 조건 검사 (조건 미충족 즉시 제외)
2. 충족 이벤트마다 유틸리티 산출
3. 성격 가중치 적용
4. 역사 편향 계수 적용        ★ §6.2
5. 결단 임계 통과 시 실행
```

### 6.2 역사 편향 계수 (Historical Bias)

> **역사가 자연스럽게 재현되되, 강제되지 않아야 한다.**

```
if (해당 세력·인물이 역사상 이 이벤트의 주체였다):
    utility × (1 + HB)
```

| 모드 | HB 값 | 성격 |
|---|---|---|
| **역사 중시** | 0.5 | 역사대로 흐르기 쉬움. 입문자용 |
| **표준** | **0.25** | 역사 경향은 있되 자주 이탈 |
| **자유 역사** | 0.0 | 순수 유틸리티. 완전한 역사 생성 |

> **HB는 옵션이다.** 플레이어가 「삼국지를 다시 보고 싶은가」와
> 「다른 삼국지를 만들고 싶은가」를 고를 수 있다.
>
> 기능이벤트 §9-3의 우려(「역사 인물 우선이 너무 강하면 역사 생성의 의미가 약해짐」)에 대한 답이다.

### 6.3 예시 — F-16 관문을 향한 도박적 공세

```
조건 검사   ① 관문 인접 ✓  ② 실동원 0.4배 ✓
            ③ 최강자 동원율 0.42 ✓  ④ 지휘관 성향 절의 ✓

유틸리티    국력 이득     +0.35  (관문 획득 시 항로 개통)
            천명 영향     +0.10  (명분 있는 공세)
            위험도        −0.40  (배후 신뢰도 낮음)
            시간 압력     +0.30  (할거 페널티 진행 중)
            = 0.35

성격 보정   인덕형 군주 × 절의 지휘관 → ×1.15 = 0.40
역사 편향   관우 = 역사 주체 → ×1.25 = 0.50

결단 임계   0.5 → 통과 (차선 행동 0.31, 차이 0.19 < 0.5 미달)
            → 보류 후 다음 주기 재평가
```

> **관우조차 즉시 북벌하지 않는다.** 배후가 불안하면 미룬다.
> 그리고 상황이 바뀌면(조조가 다른 전선에 묶이면) 실행한다.
> **역사가 조건에서 발생한다.**

## 7. 전투 AI — 5페이즈

### 7.1 플레이어 로직과 공유

전투 v0.2의 **「인물 위임」**은 제독의 성향에 따라 자동 선택하는 기능이다.
**AI는 동일한 로직을 사용한다.**

> 코드가 하나다. 플레이어의 위임 AI와 적 AI가 같은 것을 쓴다.
> **개발 비용이 절반이고, 밸런스가 자동으로 맞는다.**

### 7.2 성향별 기본 방침

| 성향 | 방침 | 페이즈별 선호 |
|---|---|---|
| 절의 | 신중 | ③ 종심 방어 · ⑤ 질서 퇴각 |
| 명사 | 균형 | 표준 |
| 실무 | 균형 (손익 계산) | 손실률 임계 초과 시 퇴각 |
| 야심 | 적극 | ③ 중앙 돌파 · ⑤ 전면 추격 |
| 무뢰 | 적극 (약탈) | ④ 기함 직격 · ⑤ 전면 추격 |

### 7.3 전황 반응

기본 방침 위에 **실시간 보정**이 얹힌다.

```
아군 사기 < 40   → 방어·퇴각 가중 +0.3
적 사기 < 40     → 공세·추격 가중 +0.3
계략 조건 충족   → 해당 계략 가중 +0.4
지휘관 특성 조건 → 해당 페이즈 가중 +0.5
```

**예:** 장료 「소요진」은 병력 열세일수록 강해진다.
→ AI는 열세 상황에서 오히려 ③ 중앙 돌파를 선택한다. **합비 전투가 재현된다.**

## 8. 외교 AI

### 8.1 패권 압력 인식

각 AI 세력은 **매 Grand 주기마다** 전 세력의 패권 압력을 평가한다.

```
위협도(대상) = 대상 실동원 / 자국 실동원
             + 인접도 보정
             + 최근 확장 속도
             + 적대 관계 여부
```

| 위협도 | 행동 |
|---|---|
| < 1.0 | 개별 대응 또는 공세 대상 |
| 1.0~2.0 | 방어 강화 · 외교 접촉 |
| **> 2.0** | **견제 연합 결성 시도 (F-07)** |
| > 4.0 | 항복 검토 (F-26) |

### 8.2 배신 판정

```
배신 유틸리티 = 획득 예상 권역 가치 (절단 가치 포함)
              − 천명 손실 × 성격 가중치
              − 보복 위험 (상대 실동원 × 인접도)
              − AllianceTrust × 신뢰 가중치
              × 배신 성향 계수 (군주 유형)
```

| 군주 유형 | 배신 성향 |
|---|---|
| 인덕형 | **0.2** — 거의 배신하지 않음 |
| 무단형 | **1.5** — 이득만 있으면 |
| 실리형 | 1.2 |

> **손권(실리형)이 관우의 배후를 치는 것은 캐릭터에 맞는 행동이다.**
> 유비(인덕형)가 같은 상황에서 같은 선택을 하기는 어렵다.

### 8.3 조언 반영

노숙 「천하이분」 보유 시 동맹 유지 유틸리티 +25%.
여몽 「백의도강」 보유 시 배후 기습 유틸리티 상승.

> **인물이 AI의 판단을 바꾼다.**
