## 1. 신규 시스템 정식 편입

### 1.1 패권 압력

```
패권 압력 = 군사력 + 경제력 + 천명 + 인재 밀도 + 영토 + 외교 영향력
```

| 임계 | **범위** | 결과 |
|---|---|---|
| 낮음 | **0~34** | 주변 세력이 개별 대응 |
| **중** | **35~49** | 인접 세력 간 상호 접근 시작 |
| **높음** | **50~59** | **견제 연합 결성 조건 개방** |
| 극대 | **60~100** | 다수 세력이 동시 적대 전환 |

> **산식과 계수는 `function-events.md` §0.3-②에서 확정했다** [J5, 2026-08-23].
> 기저 점유율(실동원 점유율 ×100) + 우위 가산(황제 +10 · 영토 +5 · 인재 +8 · 외교 +5)
> + **명분 침해 가산**(폐립 +20 · 참칭 +25 · 수도 소각 +15 · 시해 +30).
> 6시나리오 검산은 동 문서 §8.1.

**동원율과의 관계 — 짝을 이루는 두 제약**

| | 작용 방향 | 성격 |
|---|---|---|
| **동원율** | 내부 — 국경이 넓으면 병력이 묶인다 | 물리적 |
| **패권 압력** | 외부 — 강해지면 견제가 생긴다 | 정치적 |

> 208년 조조의 실동원이 212에서 101로 떨어지는 것이 동원율이고,
> 손권과 유비가 손잡는 이유가 패권 압력이다.
> **강자가 자동으로 이기지 않는 두 개의 서로 다른 이유.**

### 1.2 동맹 신뢰도 — 중원 세력 간 확장

외교동맹 v0.1은 **외국 세력(동이 연합·대월지)만** 다뤘다.
**중원 세력 간 동맹 시스템이 비어 있었다.** 이를 채운다.

```
AllianceTrust
├─ 약속 이행     참전 요청 응답 여부
├─ 공동 전투     실제 함께 싸운 횟수
├─ 영토 분배     전과 배분의 공정성
├─ 정보 공유     첩보·전황 공유 여부
├─ 인물 관계     양측 핵심 인물 간 상성
├─ 외교 행동     제3세력과의 별도 접촉
└─ 배신 기록     영구 계승. 회복 불가
```

**외교 4단계(통교→화친→맹약→군사동맹)를 중원 세력 간에도 동일 적용한다.**
단 **천명 감소는 없다** — 같은 한의 신하끼리 손잡는 것이므로.

> **208년의 신뢰도가 219년 형주 문제로 계승된다.**
> 「동맹은 승리하는 순간부터 깨지기 시작한다.」

### ACT 1 — 원소의 선택

**Event 02. 지금 칠 것인가 [CHOICE]**

> **원소의 약점은 우둔함이 아니다.**
> **강한 세력이기에 선택지가 많고, 그래서 결정이 늦다는 것이다.**

| 선택 | 효과 |
|---|---|
| **즉시 남하** | 조조의 신점령지 안정화 전에 타격. 자국 보급 미비 |
| 준비 후 남하 | 보급 확충. 조조도 함께 강해진다 |
| 외교 우선 | 유표·손권 포섭 시도. 시간 소요 |
| 조조와 협상 | 화친 단계 체결. 북방 완전 통합 후 재개 |

**의사결정 지연 시스템**

원소 진영은 참모 간 의견이 갈린다.

| 인물 | 주장 | 특성 |
|---|---|---|
| **저수** | 지구전 — 「감군」 장기전 계략 +45% |
| **전풍** | 지구전 — 「강직」 무시 시 투옥 |
| **곽도** | 속전 — 「실책」 계략 실패율 높음 |
| **심배** | 속전 — 「사수」 |

> **채택률 판정:** 원소는 「명문형」 군주다.
> 명사 성향 참모의 의견을 잘 듣지만, **강직한 직언에는 반발**한다.
> 저수·전풍의 조언이 옳아도 채택되지 않을 수 있다 — 그것이 원소의 성격이다.
