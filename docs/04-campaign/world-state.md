# 星漢志 — 캠페인 분기 · 세계 상태 설계 v0.1

> 연속 캠페인의 분기 폭발 문제를 해결하는 상위 설계
> 시나리오 1 Timeline v0.1 · 시나리오 2·3 정합화 v0.1의 전제 문서
> 작성일: 2026-08-22 / 상태: 초안 — 검토 요망

## 0. 문제

연속 캠페인은 **역사 이탈을 허용한다.** 그런데 이탈이 누적되면 이후 시나리오가 성립하지 않는다.

```
190 ──▶ 200 ──▶ 208 ──▶ 219 ──▶ 228 ──▶ 263
                  │
                  └─ 여기서 삼국이 아니게 되면 이후가 전부 무효
```

### 0.1 주요 붕괴 지점

| 시나리오 | 붕괴 | 결과 |
|---|---|---|
| 200 | **원소 관도 승리** | 조조 몰락. 하북 패권 구도 |
| 208 | **손권 조조 항복** | 오 소멸. 위 대 촉 |
| 208 | **조조 적벽 승리** | 위 통일 임박. 삼국 미성립 |
| 208 | **적벽 미발생** | 8단계 전역 콘텐츠 스킵 |
| 190 | **황제 시해** | 천명 시스템의 전제 변경 |

### 0.2 순진한 해법의 문제

시나리오마다 분기를 만들면 **지수적으로 폭발한다.**

```
6 시나리오 × 각 3~5분기 = 최대 수천 갈래
```

**감당 불가.** 다른 접근이 필요하다.

## 1. 해법 — 세계 상태(World State)로 수렴

> **시나리오를 분기시키지 않는다.**
> **같은 시나리오가 다른 세계 상태로 시작하게 한다.**

### 1.1 발상의 전환

219년의 본질은 **「삼국」이 아니다.**

> **「최강자와 견제 세력들의 균형이 무너지는 시점」**

이 구조만 유지되면 **등장하는 세력이 달라도 시나리오는 성립한다.**

### 1.2 세계 상태 4형

| 형 | 구조 | 판정 조건 | 219년의 모습 |
|---|---|---|---|
| **삼국형(三國)** | 1강 2중 | 최강자 실동원 ≤ 견제 세력 합의 1.5배 | 역사 루트. 형주 쟁탈 |
| **양강형(兩强)** | 1강 1중 | 유효 세력 2개 | 단일 전선 집중. 한중 또는 회남 |
| **일극형(一極)** | 1초강 다약 | 최강자 실동원 ≥ 나머지 합의 2배 | **견제 연합 vs 패자** |
| **북방형(北方)** | 원소 계열 승리 | 200년 원소 승리 계승 | 하북 패권. 관중·형주가 전장 |

**각 시나리오는 4형에 대한 「시작 배치」만 갖는다.**
ACT 구조와 이벤트는 공유한다.

| | 분기 방식 | 물량 |
|---|---|---|
| 순진한 분기 | 시나리오 전체 복제 | **×4** |
| **세계 상태** | 시작 배치 + 일부 이벤트 치환 | **×1.3** |

## 2. 기능 이벤트 — 이름이 아니라 역할

두 번째 핵심 장치.

> **이벤트를 「인물의 이름」이 아니라 「압력의 기능」으로 정의한다.**

| 고정 이벤트 | → | **기능 이벤트** |
|---|---|---|
| 관우의 북벌 | → | **최강자의 관문을 향한 도박적 공세** |
| 여몽의 백의도강 | → | **동맹의 배후 기습** |
| 이릉대전 | → | **복수 원정과 그 실패** |
| 오소 기습 | → | **보급 거점 강습** |
| 삼고초려 | → | **재야 최고 인재의 초빙 시험** |
| 적벽 화공 | → | **열세측의 비대칭 결전** |

### 2.1 작동 방식

```
① 기능 이벤트의 발동 조건을 「구조」로 기술한다
   예: 「형주급 요충을 보유한 중견 세력이,
        최강자의 관문 권역에 인접하고,
        동맹 신뢰도가 임계 미만일 때」

② 조건을 충족하는 인물·세력을 게임이 찾아 배정한다

③ 배정된 인물의 특성·성향에 따라 연출과 결과가 달라진다
```

### 2.2 예시 — 「최강자의 관문을 향한 도박적 공세」

| 세계 상태 | 배정 |
|---|---|
| 삼국형 (역사) | **관우** — 형주 중부권 → 북부권(양번관문) |
| 양강형 (오 소멸) | **마초** 또는 **위연** — 한중 → 옹주(진령삼도) |
| 일극형 | **견제 연합 선봉** — 누구든 |
| 북방형 | **조조 잔존 세력** — 허권 → 관도관문 |

> **219년에 관우가 없어도 누군가는 관문을 향해 도박을 건다.**
> 시나리오의 뼈대는 인물이 아니라 **압력 구조**다.

### 2.3 연출 차등

기능은 같아도 **누가 하느냐에 따라 서술이 달라진다.**

| 인물 | 「도박적 공세」의 성격 |
|---|---|
| **관우** 「만인지적」·절의 | 명분을 걸고 나아간다. 실패해도 물러서지 않는다 |
| **마초** 「금마초」·야심 | 이민족 병력을 끌어들인다. 천명 하락 감수 |
| **위연** 「반골」·야심 | 자오곡 계책 — 고위험 고수익 |
| 문앙 「단기당천」·무뢰 | 단신 돌격. 개인 무용에 의존 |

## 3. 안전장치 3종

### 3.1 붕괴 임계 감시 — 조기 종료

> **억지로 굴리지 않는다.**

```
조기 종료 조건
  최강자 패권 압력 = 극대
  ∧ 견제 세력 실동원 합 < 최강자의 1/3
  ∧ 견제 연합 결성 실패
```

**→ 캠페인 조기 종료. 엔딩 사분면 판정으로 이행.**

| 사례 | 처리 |
|---|---|
| 208년 조조 완승 | 「**霸業** 루트 조기 통일」 또는 천명에 따라 「受命」 |
| 200년 원소 완승 후 급속 통합 | 동상 |

> **이것은 실패가 아니라 정당한 결말이다.**
> 우리 엔딩은 「승리/패배」가 아니라 **「어떤 천하를 만들었는가」**를 판정한다.
> 263년까지 가지 않아도 엔딩은 성립한다.

**후일담 처리**

조기 종료 시 남은 연도를 **사가 서술체 요약**으로 제시한다.
「그 뒤로 사십 년, 천하에는 큰 싸움이 없었다」 식의 짧은 회고.

### 3.2 역사 복원력 — 약한 되돌림

완전 자유는 서사를 무너뜨린다. **강제가 아니라 경향**으로 되돌린다.

| 장치 | 작동 |
|---|---|
| **패권 압력** | 최강자에게 자동으로 견제가 붙는다 |
| **동원율** | 확장할수록 실전력이 떨어진다 |
| **할거 페널티** | 웅크리면 천명이 깎인다 |
| **재기 이벤트** | 몰락한 세력에 재건 기회가 생긴다 (원소 사후 원상·원담 등) |
| **인재 재배치** | 특급 인물이 다른 경로로 등장한다 |
| **전화 회복** | 폐허가 된 권역이 서서히 회복된다 |

> **이미 만들어둔 시스템 대부분이 복원력으로 작동한다.**
> 새로 추가할 것은 「재기 이벤트」와 「인재 재배치」 둘뿐이다.

#### 인재 재배치 규칙

원 소속 세력이 소멸하면 명장이 사라지는 것이 아니라 **재야로 이행**한다.

| 상황 | 처리 |
|---|---|
| 세력 소멸 | 소속 인물의 **절의 성향**은 순사, **나머지는 재야 편입** |
| 재야 인물 | 등용 3중 판정으로 타 세력 합류 가능 |
| **천명 極 인물** | 정통성 높은 세력에만 합류. 없으면 은거 |

> 관우는 유비가 죽으면 은거하거나 순사한다. **아무에게나 가지 않는다.**
> 반면 장료·서황 같은 실무 성향은 새 주군을 찾는다. 원전 그대로다.

### 3.3 단편 모드 — 우회로

> **분기 문제를 회피하는 가장 싼 방법.**

| 모드 | 시작 상태 | 종료 |
|---|---|---|
| **연속 캠페인** | 이전 시나리오 계승 | 263년 또는 조기 종료 시 엔딩 |
| **단편(單篇)** | **역사 기준 배치 고정** | 해당 시나리오 종료 시 **엔딩 사분면 판정** |

단편 모드는 세계 상태 판정을 하지 않는다. 항상 **삼국형(역사 루트)**으로 시작한다.

> 우리 엔딩 사분면이 이미 단편용으로 설계되어 있다.
> 별도 개발 없이 성립한다.

## 4. 세계 상태 판정 절차

각 시나리오 시작 시 **1회** 판정한다.

```
STEP 1  유효 세력 집계
        실동원 ≥ 전체 합의 10% 인 세력만 「유효」로 계산

STEP 2  최강자 식별
        실동원 최대 세력

STEP 3  형 판정
        유효 세력 2개                      → 양강형
        최강자 ≥ 나머지 합 × 2             → 일극형
        200년 원소 계열 승리 계승           → 북방형
        그 외                              → 삼국형

STEP 4  시작 배치 로드
        해당 형의 배치 템플릿 적용

STEP 5  기능 이벤트 배정
        조건 충족 세력·인물을 탐색해 배정
```

### 4.1 형별 시작 배치 템플릿 (219년 예시)

| 형 | 최강자 | 견제 세력 | 주 전장 |
|---|---|---|---|
| **삼국형** | 위 (실동원 104) | 촉 64 · 오 47 | **형주 4권역** |
| **양강형** | 위 (실동원 130) | 촉 70 | **한중 · 옹주 회랑군** |
| **일극형** | 최강자 (실동원 180+) | 다수 약소 | **견제 연합 결성 자체가 목표** |
| **북방형** | 원소 계열 (실동원 110) | 조조 잔존 · 유표 · 손권 | **관중 · 형주** |

## 5. 각 시나리오의 「구조적 정체」

기능 이벤트가 성립하려면 **시나리오마다 바뀌지 않는 뼈대**가 있어야 한다.

| # | 시나리오 | 구조적 정체 | 세계 상태와 무관하게 유지 |
|---|---|---|---|
| 1 | 190 | **질서의 공백** | 황제·천명·토호·세력 형성 |
| 2 | 200 | **두 질서의 충돌** | 패권 경쟁·보급·정보전 |
| 3 | 208 | **강자에 대한 견제 연합** | 외교·동맹·신뢰도 |
| 4 | 219 | **동맹의 붕괴와 요충 쟁탈** | 신뢰도 청산·배후 기습·복수 |
| 5 | 228 | **약자의 강제된 공세** | 인재 고갈·할거 페널티·회랑 돌파 |
| 6 | 263 | **내부로부터의 붕괴** | 찬탈·전횡·비인접 침투 |

> **시나리오 4의 정체는 「형주」가 아니라 「동맹의 붕괴」다.**
> 양강형이면 형주가 없어도 다른 곳에서 같은 일이 벌어진다.
>
> **시나리오 6의 정체는 「촉의 멸망」이 아니라 「내부 붕괴」다.**
> 누가 최강자든, 그 세력 내부에서 찬탈이 진행된다.

## 6. 붕괴 시나리오별 대응

### 6.1 손권 항복 (208)

| 항목 | 처리 |
|---|---|
| 세계 상태 | **양강형** |
| 오 인물 | 절의 성향(황개·태사자·능통·주태) 순사 / 나머지 재야 → 위 합류 가능 |
| 219년 | 형주 전선 소멸. **한중 전선이 주 무대** |
| 대체 기능 이벤트 | 「동맹의 배후 기습」 → **「신복속 세력의 반란」**으로 치환 |
| 촉의 활로 | 익주·한중 방어 + 옹주 공세. **분치(分治) 엔딩이 현실적 목표** |

> 오가 없으면 촉은 **처음부터 「분치」를 노리게 된다.**
> 통일이 불가능하다는 것을 알고 병립을 목표로 삼는 플레이 —
> **주제축이 오히려 선명해지는 루트다.**

### 6.2 조조 적벽 승리 (208)

| 조건 | 처리 |
|---|---|
| 강동 완전 병합 + 유비 소멸 | **조기 종료** → 엔딩 판정 |
| 강동 병합 + 유비 익주 도주 | **양강형**으로 219 진행 |
| 강동 부분 점령 | **삼국형** 유지 (오 약체) |

### 6.3 원소 관도 승리 (200)

| 항목 | 처리 |
|---|---|
| 세계 상태 | **북방형** |
| 조조 | 허권 상실 시 유랑 세력화 가능 (유비와 동일 규칙) |
| 황제 | 원소가 확보하면 **명문 + 정통성** 결합 → 천명 우위 확정 |
| 208년 | 「원소의 남하」로 치환. 유표·손권·유비가 견제 연합 |
| 인물 | 장료·장합·서황 등 실무 성향은 원소 진영 편입 |

> **구조는 동일하다.** 최강자가 남하하고, 남방이 연합한다.
> **적벽의 자리에 다른 이름의 대회전이 들어선다.**

### 6.4 황제 시해 (190)

| 항목 | 처리 |
|---|---|
| 천명 | 산정 기준 재정의 — 「혈통·조서」 → 「실적·민심」 |
| 협천자 | 시스템 무효화. 조서 발행 불가 |
| 세력 | 전 세력 천명 하향 평준화 |
| 엔딩 | **「공화 복귀」 히든 엔딩 조건 개방** |
| 이후 시나리오 | **구조는 유지.** 명분 경쟁이 실적 경쟁으로 바뀔 뿐 |

> **가장 급진적인 이탈이지만 캠페인은 붕괴하지 않는다.**
> 「무엇이 통치를 정당화하는가」라는 질문이 다시 열릴 뿐이다.
> **이것이 이 게임의 주제 그 자체이므로, 오히려 정면으로 다뤄야 한다.**

## 7. 물량 영향

| 항목 | 추가 물량 |
|---|---|
| 세계 상태 4형 × 6시나리오 시작 배치 | **24개 배치표** |
| 기능 이벤트 정의 | 약 30개 |
| 형별 치환 이벤트 | 시나리오당 3~5개 = **약 25개** |
