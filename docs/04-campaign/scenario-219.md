## 0. 핵심 질문

> **이전 선택의 대가를 어떻게 감당할 것인가?**

190에서 무엇을 선택했고, 200에서 어떤 질서를 세웠고, 208에서 누구와 손잡았는지 —
**그 모든 것의 청구서가 이 시나리오에서 도착한다.**

## 0.1 구조적 정체

> **동맹의 붕괴와 요충 쟁탈**

「형주」가 아니다. 형주는 삼국형에서의 무대일 뿐이다.
**어느 세계 상태에서든 「함께 싸운 자들이 이제 서로를 겨눈다」는 구조는 유지된다.**

## 1. 208 계승 변수

이 시나리오는 **계승 의존도가 가장 높다.**

| 계승 항목 | 219년에 미치는 영향 |
|---|---|
| **형주 4권역 개별 소유자** ★ | 전쟁의 지리적 조건 자체 |
| **태양계권 소유·분점 여부** ★ | 명분 경쟁의 초점 |
| **AllianceTrust (손·유)** ★ | 배후 기습 발생 확률의 **주 변수** |
| **「형주 차용」 계약 존재** ★ | 반환 요구 이벤트 발동 조건 |
| 손권 정책 노선 | 주유형(공세) / 노숙형(유지) / 장소형(굴복) |
| 유비 유랑 해제 여부 | 미해제 시 이 시나리오 자체가 성립하지 않음 |
| 조조 실동원·동원율 | 북벌의 성공 가능성 |
| 적벽 발생·결과 | 세계 상태 판정의 주 입력 |

### 1.1 AllianceTrust 임계

```
신뢰도 고  (협약 준수 · 공동 전투 다수 · 배신 기록 없음)
   → 배후 기습 발생 확률 낮음. 동맹 유지 루트 개방

신뢰도 중  (차용 계약 · 분배 불만 잔존)
   → 반환 요구 → 협상 또는 결렬. 역사 루트

신뢰도 저  (협약 위반 점유 · 비밀 협약 발각)
   → 배후 기습 확률 극대. 북벌 개시 즉시 발동
```

> **219년의 비극은 219년에 만들어지지 않는다. 208년에 만들어진다.**

| **촉** | 익주3·**한중2**·**중부권**·**태양계권**·남중2 | 92 | 0.70 | 64 |
| **오** | 건업권★·오회권·예장권·**남부권**·교지권★·남해권 | 63 | 0.75 | 47 |

**주 전장:** 형주 4권역 · 한중 · 합비회랑

### 2.2 양강형 — 오 소멸 계열

| 세력 | 보유 권역 | 실동원 |
|---|---|---|
| **위** | 삼국형 + 오 권역 흡수 | **130** |
| **촉** | 익주3·한중2·남중2 (+ 형주 잔존분) | 70 |

**주 전장:** **한중 ↔ 옹주 회랑군** (진령삼도·기산도·검각)
**치환:** 「동맹의 배후 기습」 → **「신복속 세력의 반란」**

> 오가 없으면 촉은 처음부터 **분치를 목표로 삼는다.**
> 통일이 불가능함을 알고 병립을 노리는 플레이 — **주제축이 오히려 선명해진다.**

### 2.3 일극형 — 최강자 압도

| 세력 | 실동원 |
|---|---|
| **최강자** | 180+ |
| 나머지 다수 | 각 20~40 |

**주 전장:** **견제 연합 결성 자체**
**치환:** 「요충 쟁탈」 → **「연합 결성 교섭」**

> 이 형에서는 **영토를 얻는 것이 목표가 아니다.**
> 최강자를 상대할 연합을 만들어내는 것 자체가 승리 조건이다.
> 실패하면 조기 종료 → 엔딩 판정.

### 2.4 북방형 — 원소 계열 승리

| 세력 | 실동원 |
|---|---|
| **원소 계열** | 110 |
| 조조 잔존 / 유표 / 손권 / 유비 | 각 25~50 |

**주 전장:** **관중 · 형주**
**치환:** 「최강자의 관문 공세」의 주체가 **조조 잔존 세력**

> 구조는 동일하다. 최강자가 남하하고, 남방이 연합했다가 깨진다.

## 3. Timeline — 공통 뼈대

### ACT 0 — 요충의 확보

**【기능】 요충 쟁탈 — 지형적 결절 권역의 획득**

| 북방형 | **관중 장안서부권** |

**Event 01. 회랑 세 개의 결절 [LIKELY]**

한중 남정권을 얻으면 **진령삼도·기산도·검각**이 모두 열린다.

| 결과 | 효과 |
|---|---|
| **획득** | 북벌 경로 3개 개방. 익주 방어 종심 확보 |
| 실패 | 검각 방어에 갇힘. **분치 이하 엔딩 확정적** |
| 상용권만 획득 | **비지 상태.** 맹달「이반」 발동 조건 |

> **한중의 국력은 12에 불과하다.** 그럼에도 이것이 시나리오의 시작인 이유는
> **회랑 세 개가 모이는 유일한 권역**이기 때문이다.

### ACT 1 — 칭왕

**Event 02. 왕을 칭할 것인가 [CHOICE]**

요충 확보 후 세력 격상 선택이 열린다.

| 선택 | 자유도 | 천명 | 부작용 |
|---|---|---|---|
| **한의 신하 유지** | 낮음 (조서 제약) | 유지 | 세력 사기 −10 |
| **칭왕** | 중간 | **−중** | 타 세력에 토벌 명분 제공 |
| **칭제** | 최대 | **−대** | 전 세력 적대 가능 |

**조건부 관계 파탄 판정** (성향태그 v0.1 §3.3)

| 군주 유형 | 절의 인물 반응 |
|---|---|
| 패도형 × 절의 | **칭왕 시 이탈 경고 / 칭제 시 사직·사망** |
| 인덕형 × 절의 | 칭왕까지 용인. 칭제 시 반발 |

> **조조가 위왕을 칭하면 순욱이 떠난다.**
> **유비가 한중왕을 칭하면 「한실 부흥」 엔딩 경로가 좁아진다.**
> 자유를 얻는 대가로 명분을 내놓는 거래다.

### ACT 2 — 청산

**【기능】 동맹 신뢰도 청산 — 함께 싸운 자들의 정산**

**Event 03. 빌린 것을 돌려달라 [LIKELY]**

208년 「형주 차용」 계약이 존재하면 반환 요구가 발생한다.

| 선택 | 결과 |
|---|---|
| **전면 반환** | 신뢰도 **+대**. 국력 대폭 손실. **천명 +대** |
| **부분 반환** | 신뢰도 소폭 회복. 역사 루트(상수 협정) |
| **거부** | 신뢰도 **−대**. 배후 기습 확률 급상승 |
| 재협상 | 시간 소요. 노숙 생존 시 성공률 상승 |

**Event 04. 고향은 누구의 것인가 [CHOICE]**

**태양계권 귀속 분쟁.** 삼국형 전용.

| 상태 | 효과 |
|---|---|
| 단독 보유 + 복구 진행 | 「원향」 천명 상승 |
| **분점** | **양측 모두 천명 하락** — 「고향이 갈렸다」 |
| 방치 | 보유 세력 천명 소폭 하락 |
| **반환 협상 카드로 사용** | 실리 없는 땅을 명분으로 교환 |

> **태양계권은 국력이 2다.** 그런데 협상 테이블에서는 가장 무겁다.
> 「지구를 내놓겠다」는 제안이 강릉보다 큰 무게를 갖는다 —
> **실리가 아니라 명분을 거래하는 순간.**

### ACT 3 — 도박

**【기능】 최강자의 관문을 향한 도박적 공세**

**발동 조건 (구조 기술)**

```
① 중견 세력이 최강자의 관문 권역에 인접
② 자국 실동원 ≥ 최강자 실동원 × 0.4
③ 최강자가 다른 전선에 병력을 묶임 (동원율 저하)
④ 해당 전선 지휘관의 성향이 「절의」 또는 「야심」
⑤ 동맹 신뢰도가 「배후 안전」을 보장하지 않아도 강행 가능
```

### ACT 4 — 최강자의 대응

**Event 06. 흔들리는 중심 [LIKELY]**

관문 공세가 성공하면 최강자 진영에 **천도 검토** 이벤트가 발생한다.

| 대응 | 효과 |
|---|---|
| **천도** | 안전 확보. **천명 −대** · 위신 붕괴 |
| 증원 파견 | 타 전선 동원율 추가 하락 |
| **제3자 외교** | **배후 기습 유도** — 대가로 영토·관직 제안 |
| 정면 방어 | 우금·방덕 계열 투입. 실패 시 관문 상실 |

> **조조가 손권에게 손을 내미는 순간이 여기다.**
> 최강자가 스스로 견제 연합을 깨는 외교 — **패권 압력에 대한 반격.**

### ACT 5 — 제3자의 선택

**Event 07. 누구를 도울 것인가 [CHOICE]**

동맹의 제3자(삼국형에서는 오)가 결정한다.

```
판정 = 동맹 신뢰도
     + 최강자의 제안 가치
     + 자국 국력 대비 동맹국 성장률
     + 요충(형주 중부권) 전략 가치
     + 정책 노선 (주유형/노숙형/장소형)
     − 배신 시 천명 하락 예상치
```

| 선택 | 결과 |
|---|---|
| **동맹 유지 · 공동 공세** | 최강자 양면 압박. **역사 이탈** |
| **관망** | 양측 소모 유도 |
| **배후 기습** | 역사 루트. **신뢰도 영구 붕괴 · 천명 −대** |
| 최강자에 가담 | 동맹국 급속 붕괴 |

> **노숙이 생존해 있으면 「동맹 유지」 확률이 크게 오른다** — 「천하이분」.
> **여몽이 대도독이면 「배후 기습」 확률이 오른다** — 「백의도강」.
> **인물 하나가 역사의 방향을 바꾼다.**

### ACT 6 — 배후 기습

**【기능】 동맹의 배후 기습 — 신뢰의 청산**

**Event 08. 흰 옷을 입은 배들 [CHOICE]**

| 세계 상태 | 치환 |
|---|---|
| 삼국형 | **여몽의 백의도강** — 형주 중부권 기습 |
| **양강형** | **신복속 세력의 반란** — 최근 병합한 권역의 봉기 |
| 일극형 | **연합 이탈** — 참가 세력 중 하나가 최강자에 투항 |
| 북방형 | 동일 구조, 주체만 변경 |

**기습 성공 시 — 비지 연쇄**

```
중부권 상실
  → 남부권·태양계권과의 연결 단절
  → 비지화 (생산 −50%, 보충 불가)
  → 북벌군 보급 차단 · 퇴로 상실
  → 지휘관 고립
```

> **「형주를 잃었다」가 아니라 「중부권을 잃어 나머지가 고립됐다」.**
> 부분 점령 시스템이 가장 극적으로 작동하는 지점이다.

**Event 09. 고립된 자 [CHOICE]**

| 선택 | 결과 |
|---|---|
| **강행 돌파** | 전투 v0.2 「강행 돌입」 적용. 성공률 1/3 |
| 항복 | 인물 포로화 → 등용 3중 판정 |
| **순사** | 절의 성향은 항복 불가. **천명 +소, 인물 상실** |
| 구원 요청 | 상용권 보유 세력의 원군 판정 — **맹달「이반」 발동** |

> **맹달이 원군을 보내지 않는다.** 상용권은 비지 상태이며,
> 그의 성향은 「야심」이다. 원전 그대로다.

### ACT 7 — 승계

**Event 10. 최강자의 죽음 [FIXED]**

### ACT 8 — 복수

**【기능】 복수 원정과 그 실패**

**Event 13. 되찾을 것인가 [CHOICE]**

요충과 인물을 잃은 세력이 보복 원정을 결정한다.

| 선택 | 결과 |
|---|---|
| **전면 원정** | 역사 루트. **이릉협도 통과 필요** |
| 제한 보복 | 국경 소모전 |
| **자제 · 재정비** | 천명 유지. 국력 보존. **분치 엔딩 경로** |
| 최강자와 화친 | 제3자를 공동의 적으로 |

**Event 14. 협도의 화공 [LIKELY]**

원정이 이릉협도를 통과하면 **함대 종렬이 강제**된다.

```
이릉협도 — 대회랑
  화공 피해 ×3
  강습모함 −40%
  전개 함대 수 제한
  소요 3시간 45분
```

| 방어측 조건 | 효과 |
|---|---|
| **육손「인내」** 보유 | 방어 지속 턴마다 반격력 누적 (최대 +100%) |
| 방어 지휘관 부재 | 정면 격돌 → 원정측 유리 |
| 원정측 「신중」 방침 | 밀집 회피. 화공 피해 감소 |

> **원정의 성패는 「누가 방어하는가」로 갈린다.**
> 육손이 없으면 이릉은 원정측의 승리로 끝날 수 있다.

**Event 15. 원정의 끝 [LIKELY]**

| 결과 | 이후 |
|---|---|
| **대패** | 군주 사망 이벤트 · 후계 승계 · **동맹 복원 교섭** |
| 교착 | 양측 소모. 국경 확정 |
| **승리** | 요충 탈환. **역사 최대 이탈** |

## 4. 계승 데이터 (→ 228)

```
CampaignHistory / 219
├── 요충 소유            한중 2권역 · 형주 4권역 개별
├── 태양계권 소유        분점 여부 · 복구도
├── AllianceTrust        배신 기록 · 복원 여부
├── 군주 격              신하 / 왕 / 황제 (세력별)
├── 황제 상태            존속 / 선양 / 찬탈 / 부재
├── 인물 손실            북벌·기습·원정에서 사망한 명장 목록 ★
├── 후계                 각 세력 군주 승계 결과
├── 후방 안정도          남중 회유 / 진압 / 미해결
├── 세계 상태            228년 판정 입력
└── HistoricalDivergence
```

### 4.1 인물 손실이 228년을 결정한다

> **228년의 정체는 「인재 고갈」이다** (캠페인분기 §5).

219년에 누가 죽었는지가 228년의 난도를 직접 결정한다.

| 219년 손실 | 228년 영향 |
|---|---|
| 관우·장비·황충·마초 생존 | 촉 후기 인재난 대폭 완화 |
| 여몽·감녕 생존 | 오 중기 전력 유지 |
| 조조 조기 사망 | 위 후계 분쟁 장기화 |
| **전원 역사대로 사망** | 역사 루트 — 후기 명장 30인 체제 |

> **북벌을 하지 않으면 관우가 죽지 않는다.**
> 그리고 228년의 촉은 완전히 다른 세력이 된다.
