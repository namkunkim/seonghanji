## 0. 이 문서의 역할

세계 상태 4형이 작동하려면 이벤트가 **인물의 이름이 아니라 압력의 구조**로 정의되어야 한다.

```
「관우의 북벌」          → 특정 인물·특정 무대에 종속. 삼국형에서만 성립
「최강자의 관문 공세」   → 조건을 충족하는 누구든 수행. 4형 전부에서 성립
```

### 0.1 기재 형식

```
[F-##]  명칭
정의    이 이벤트가 표현하는 압력 구조
발동    충족해야 하는 조건 (시스템 변수로 기술)
주체    수행자 배정 규칙
결과    분기
사례    삼국형 / 양강형 / 일극형 / 북방형에서의 구현
```

### 0.3 절대 스케일 [J5 확정, 2026-08-23]

40종의 발동 조건은 지금까지 「임계」·「높음」·「0.4배」 같은 **상대 표현**만 갖고 있었다.
절대값을 넣으려면 먼저 **눈금이 있어야 한다.** 그런데 네 개의 눈금이 문서 전체에 없었다 —
천명·패권 압력·동맹 신뢰도·권역 안정도는 이름과 효과만 있고 범위가 정의되지 않았다.

> ⚠ **한계 명시.** J3이 동원율 계수를 확정하며 접경 권역 수를 신설했을 때와 같은 성격이다.
> 이 네 눈금은 **검증된 것이 아니라 이번에 도입한 자유 변수**다.
> 정확한 결론은 「임계값이 검증됐다」가 아니라 **「원전의 주요 사건이 전부 재현되는 조합이 존재한다」**까지다.
> 재현 검산은 §8.2에 전부 남겼다.

#### ① 천명(Mandate) — 0~100

세력마다 하나씩 갖는 수치. **사기에 직접 들어간다**(`combat.md` §1.1).

| 구간 | 명칭 | 사기 보정 | 등용 3중 판정 통과 상한 |
|---|---|---|---|
| **85~100** | 수명 | **+15** | 전 인물 |
| 70~84 | 정통 | +8 | 「천명 극」 인물까지 |
| 50~69 | 명분 | +3 | 절의 성향까지 |
| 30~49 | 실력 | −3 | 실무·야심 성향까지 |
| 15~29 | 참칭 | −8 | 무뢰 성향만 |
| **0~14** | 무도 | **−15** | 용병만 |

사기 보정폭을 **±15로 묶은 것**은 `combat.md` 검토 포인트 2(「과하면 전투가 정치의
종속물이 됨. 최대 ±15 정도로 제한 검토」)를 그대로 채택한 것이다.

**캠페인 개시 시 초기 천명** — [F-01]에서 사용

| 세력 조건 | 초기 천명 |
|---|---|
| 황제 물리적 보유 | **45** |
| 한실 종친 (유비 · 유표 · 유언 · 유우) | 40 |
| 사세삼공 (원소 · 원술) | 35 |
| 태수·자사 등 관직 보유 자립 | 28 |
| 관직 없는 자립 | 20 |
| 이민족 · 도적 출신 | 12 |

> **캠페인 개시 시 어느 세력도 50을 넘지 않는다.**
> 프롤로그가 끝난 천하에는 정통이 남아 있지 않다 — 그것이 [F-01]이 말하는 상태다.
> 「이 무너진 천명을 누가 다시 세우는가」(`design-overview.md` §11)가 눈금으로 성립한다.

#### ② 패권 압력(Hegemony Pressure) — 0~100

`scenario-200-208.md` §1.1의 6항목(군사력·경제력·천명·인재 밀도·영토·외교 영향력)에
가중치를 매긴다. **매 Grand 주기마다 전 세력에 대해 산출한다**(`ai-design.md` §8.1).

```
패권 압력 = 기저 점유율  +  우위 가산  +  명분 침해 가산

기저 점유율 = 100 × 해당 세력 실동원 ÷ 전 유효 세력 실동원 합
              (유효 = 실동원 ≥ 전체 합의 10%, world-state.md §4.0)
```

| 우위 가산 | 값 |
|---|---|
| 황제 또는 상징(옥새) 보유 | **+10** |
| 영토 점유율이 실동원 점유율보다 10%p 이상 높음 | +5 |
| 인재 밀도 1위 (1급 이상 인물 수) | +8 |
| 외교 영향력 (외국 동맹 또는 책봉 보유) | +5 |

| 명분 침해 가산 | 값 |
|---|---|
| 황제 폐립 | **+20** |
| 참칭 ([F-04]) | +25 |
| 수도 소각 ([F-37]) | +15 |
| **황제 시해** ([F-02]) | **+30** |

| 구간 | 범위 | 결과 (§1.1 원표) |
|---|---|---|
| 낮음 | 0~34 | 주변 세력이 개별 대응 |
| **중** | 35~49 | 인접 세력 간 상호 접근 시작 |
| **높음** | 50~59 | **견제 연합 결성 조건 개방 ([F-07])** |
| **극대** | **60~100** | 다수 세력이 동시 적대 전환 |

> **「높음」 구간이 10점으로 좁은 것은 의도다.** 패권은 중간에 오래 머물지 않는다.
> 견제 연합이 열리는 순간과 다수가 동시에 등을 돌리는 순간 사이가 짧아야
> 「강해지면 곧바로 포위된다」가 체감된다.

#### ③ 동맹 신뢰도(AllianceTrust) — 0~100

세력 **쌍**마다 하나씩 갖는다. [F-08]에서 초기값이 정해지고 이후 증감한다.

| 구간 | 명칭 | 효과 |
|---|---|---|
| 70~100 | 고 | 배후 기습 미발동. 동맹 유지 루트 개방 |
| 40~69 | 중 | 반환 요구 → 협상 또는 결렬 |
| **0~39** | 저 | **[F-12] 배후 기습 판정 개시** |

**배신 기록**은 신뢰도와 별개로 **횟수**를 영구 계승한다. [F-14] 복원 상한을 깎는다.

#### ④ 권역 안정도(Regional Stability) — 0~100

권역마다 하나씩. 신설 변수다 — 지금까지 「민심」·「안정도」라는 말만 쓰였다.

| 초기값 | 조건 |
|---|---|
| **60** | 표준 |
| 75 | 귀부·협정으로 획득 ([F-35]) |
| 40 | 무력 정복 직후 |
| 25 | 이민족·산월·남중 등 미평정 변경 |

| 매월 증감 | 값 |
|---|---|
| 평시 회복 | +2 (상한 = 초기값 + 20) |
| 비지 상태 ([F-13]) | **−8** |
| 「폭정」·수탈 정책 ([F-36]) | −10 |
| 전횡 인물 집권 ([F-32]) | −2 |
| 회유 성공 ([F-39]) | +15, 이후 영구 하한 50 |

#### ⑤ 할거 페널티(Stagnation Penalty) — 시간 단위 확정

`star-map.md` §4.6 ①이 「연속 N턴」으로만 두었던 N을 확정한다.
**이 게임에 턴은 없다.** 실시간이므로 **게임 내 개월**로 센다
(실제 1시간 = 게임 내 1개월, `time-and-monetization.md` §2.1).

| 항목 | 값 |
|---|---|
| **발동** | 연속 **12개월** 신규 권역 획득 없음 |
| 감소율 | 발동 후 매월 **천명 −1** |
| **가중** | 누적 24개월 이후 매월 **−2** |
| 중단 | 공세 개시 즉시 정지. **원정에 실패해도 정지**(§4.6 원문 유지) |
| 면제 | 유랑 세력([F-40]) · 보유 권역 3개 이하 · 이민족 세력 |

> **12개월인 이유:** 시나리오 1회는 게임 내 10~15년이므로
> (`time-and-monetization.md` §2.2), 한 시나리오 안에 **열 번 이상 청구된다.**
> 그리고 촉의 북벌 간격이 대체로 1~2년이었다 — 「가만히 있으면 진다」가
> 실제 원전의 출병 빈도와 같은 리듬으로 온다.

## 1. 질서 (Order) 계열

### [F-01] 질서의 공백
```
정의  중앙 권위가 물리적으로는 존속하나 실효를 상실한다
발동  [FIXED] 캠페인 개시 시 무조건
      전 세력 천명을 §0.3-① 초기 천명표로 설정 (상한 45)
주체  없음 (상태 이벤트)
결과  조서 시스템 개방 · 토호 자립 · 세력 형성 개시
사례  전 형 공통 — 후한 말의 전제 상태
```

### [F-02] 상징의 쟁탈
```
정의  정통성의 물리적 담지자를 누가 확보하는가
발동  현 보유 세력의 실동원 ≤ 전 유효 세력 합의 8%
      또는 보유 세력의 주권역 상실
주체  인접 권역 보유 세력 중 실동원 최대
결과  옹립 ±0 / 정중히 모심 천명 +15 / 유폐 −10 / 시해 −45
      시해 시 추가로 패권 압력 +30 (§0.3-②) · 조서 발행 영구 불가
사례  삼국형·양강형: 헌제 / 일극형: 이미 확보됨 / 북방형: 원소가 확보 시 천명 우위 확정
```

> **발동 임계 8%는 유효 세력 하한 10%(`world-state.md` §4.0)의 한 단계 아래다.**
> 「유효 세력이기를 그치기 직전」에 황제가 손을 떠난다 — 195년 이각·곽사의 붕괴가
> 그 자리다. 시해 −45는 문서 전체에서 **단일 최대 천명 손실**이며,
> 이것이 「왜 조조는 황제를 시해하지 않는가」의 답이다.

### [F-03] 상징의 발견
```
정의  정통성을 대체·보강하는 물건이 출현한다
발동  전화 계수 ≤ 0.30 인 파괴된 수도 권역에 최초 진입
주체  진입 세력
결과  반환 천명 +20 / 보관 ±0 (칭제 조건 개방) / 양도 본인 +5·수령자 +10 / 파기 −15
사례  전 형 공통 — 전국옥새
```

### [F-04] 참칭
```
정의  실력이 명분에 못 미치는 자가 최고위를 칭한다
발동  상징 보유 ∧ 천명 ≤ 35 ∧ 군주 성향 = 야심
주체  조건 충족 세력 (AI는 자동, 플레이어는 선택)
결과  천명 −30 · 패권 압력 +25 · 등용 성공률 −50%
      3개월마다 소속 인물 이탈 판정 (절의 성향 이탈 확률 60%)
사례  삼국형: 원술 / 그 외: 조건 충족 세력 누구든
```

> **천명 35는 사세삼공의 초기값이다**(§0.3-①). 원술은 시작하는 순간 조건선 위에 있다.
> 반대로 황제를 쥔 세력은 초기 45에서 시작해 예우로 더 올라가므로 **구조적으로 참칭에 들어갈 수 없다.**
> 「원술은 왜 칭제했고 조조는 왜 안 했는가」가 눈금 하나로 갈린다.

### [F-05] 격상 선언
```
정의  자유도를 얻는 대가로 명분을 내놓는다
발동  회랑 2개 이상 접속 권역 확보 ∧ 실동원 ≥ 40
주체  플레이어 선택
결과  신하 유지 (사기 −5, 조서 제약 지속)
      칭왕 천명 −10 / 칭제 천명 −25
      절의 인물 이탈 판정: 칭왕 시 확률 15%, 칭제 시 40%
      단 자국 천명 ≥ 50 이면 각각 절반
사례  삼국형: 한중왕·위왕 / 전 형 공통
```

> **실동원 40은 219년 오(47)가 겨우 넘고 208년 유장(36)이 못 넘는 선이다.**
> 격을 올리려면 최소한 한 시나리오의 주역이어야 한다.

### [F-06] 형식을 갖춘 왕조 교체
```
정의  같은 행위가 천명 수치에 따라 다른 이름으로 기록된다
발동  찬탈 진행도 = 100 ([F-31]에서 누적) ∧ 황제 보유
주체  권신 또는 최강자 군주
결과  천명 ≥ 60 → 「선양」 (천명 −10)
      천명 < 60 → 「찬탈」 (천명 −35 · 패권 압력 +20)
      「선양」 특성(조비 #18) 보유 시 감소 −40%
사례  삼국형: 조비→사마염 / 북방형: 원소 계열
```

> **검산.** 조비 220년 — 조조 대에 황제를 예우해 온 위의 천명은 60대이므로 「선양」,
> 특성 보정으로 실손실 −6. 사마염 265년 — 260년 조모 시해([F-02] −45)를 계승한
> 위의 천명은 60에 크게 못 미쳐 「찬탈」, −35.
> **같은 절차가 다른 이름으로 기록되는 것이 수치로 갈린다.**

## 2. 연합 (Coalition) 계열

### [F-07] 견제 연합의 결성
```
정의  한 세력의 패권 압력이 임계를 넘으면 나머지가 결집한다
발동  ① 최강자 패권 압력 ≥ 50 (「높음」)
      ② 견제 세력 실동원 합 ≥ 최강자 × 0.4
      ③ 참가 후보 간 배신 기록 0 ∧ 상호 동맹 신뢰도 ≥ 30
      ④ 맹주 천명 ≥ 40 또는 군주 유형 = 명문형
주체  맹주 = 위 ④를 충족하는 자 중 천명 최상위
결과  결성 / 명목 결성 (②를 1.1배 이내로 겨우 충족) / 결렬
사례  190 반동탁 / 208 손유 / 일극형에서는 이것 자체가 승리 조건
```

> **②의 0.4와 조기 종료 임계 0.33 사이가 일극형이다.**
> `world-state.md` §3.1의 조기 종료는 「견제 세력 합 < 최강자 × 1/3」이고,
> 일극형은 「최강자 ≥ 나머지 합 × 2.0」 즉 나머지가 0.50배다.
>
> ```
> 0.33 ────── 0.40 ────── 0.50
> 조기 종료    F-07 하한    일극형 상한
> ```
>
> **일극형에서 연합은 「겨우」 성립한다.** 한 세력만 이탈해도 0.4 아래로 떨어져
> 연합이 열리지 않고, 그대로 조기 종료 구간으로 미끄러진다.
> 「견제 연합 결성 자체가 승리 조건」(`world-state-setup.md` §5.3)이 **수치로 그렇게 된다** —
> 별도 규칙을 붙이지 않았고, 두 임계가 이미 그 띠를 만들고 있었다.

### [F-08] 연합 교섭
```
정의  자동 동맹은 없다. 조건을 협상한다
발동  [F-07] 결성 판정 통과 후 즉시
주체  참가 세력 전원
결과  동맹 신뢰도 초기값 결정
      공동방어 50 / 공동공격 60 / 영토 사전 분배 65 / 비밀 협약 40
      비밀 협약은 발각 시 해당 쌍 −25 · 제3자 쌍 −15
사례  208 손유회담 / 일극형 연합 교섭
```

### [F-09] 최강자의 분열 외교
```
정의  패권 압력에 대한 반격 — 연합을 안에서 깬다
발동  견제 연합 결성됨 ∧ 최강자 실동원 ≥ 연합 합 × 0.9
주체  최강자
결과  관직 / 영토 / 조서 / 불가침 / 공동 군사행동 제안
      성공 판정 = 제안 가치 − 대상의 동맹 신뢰도 ≥ 50
      성공 시 해당 세력 이탈 → [F-07] 재판정
사례  208 조조→손권 / 219 조조→손권 / 전 형 공통
```

> **0.9인 이유.** 208년은 조조 101 대 연합 46 으로 여유롭게 통과하지만,
> 219년은 위 104 대 촉·오 111로 **0.94배 — 겨우 통과한다.**
> 최강자가 연합보다 약해도 「거의 대등하면」 이간을 시도할 수 있어야 한다.
> 1.2배로 두면 219년 조조의 밀서가 발동하지 않는다.

### [F-10] 연합의 해체
```

발동  [LIKELY] 결성 후 18개월 경과 시부터 매월 해체 판정
      확률 = (경과 개월 − 18) × 3%, 상한 40%

```

> 190년 관동 연합은 「미해결 분배 항목 ≥ 2」로 18개월을 채우기 전에 깨진다.
> **연합은 시간이 아니라 분배로 깨진다** — 시간은 그 뒤에 오는 보조 조건이다.

### [F-11] 동맹 신뢰도 청산

      협약 위반 −35 · 배신 기록 +1 (영구)

> **60개월 = 5년.** 208년의 차용이 213년에 청구된다 — 실제 반환 교섭이 벌어진
> 시점(215년 상수 분할)에 근접한다. **219년의 비극이 208년에 예약된다**
> (`scenario-219.md` §1.1)가 타이머 하나로 성립한다.

### [F-12] 동맹의 배후 기습
```

      ② 동맹국 주력의 60% 이상이 타 전선에 투입됨

> **검산.** 219년 손·유 신뢰도는 차용 미반환 + 반환 요구 결렬로 25 안팎이다.
> 20 + 20 + 25 = **65%.** 높지만 확정이 아니다 —
> 백의도강은 **일어날 만했던 일이지 정해진 일이 아니었다.**

## 3. 공세 (Offensive) 계열

### [F-15] 요충 쟁탈
```
정의  지형적 결절 권역의 획득이 전략 구도를 바꾼다
발동  회랑 2개 이상 접속 권역이 적대 세력 소유

### [F-16] 최강자의 관문을 향한 도박적 공세
```
정의  이길 수 없는 자가 결정적 요충을 노린다
발동  ① 최강자의 관문 권역에 인접
      ② 자국 실동원 ≥ 최강자 × 0.4
      ③ 최강자 동원율 ≤ 0.45 (타 전선 구속)
      ④ 담당 지휘관 성향 = 절의 또는 야심
      ⑤ 담당 지휘관 통솔 ≥ 80
주체  조건 충족 세력의 해당 전선 지휘관
결과  판정 = 공세측 실동원 ÷ 관문 방어측 실동원 ([F-23] 전개 제한 적용 후)
        ≥ 2.5  관문 획득
        1.5~2.5 교착 → [F-12] 배후 기습 유발 판정
        < 1.5  전멸 위험 (지휘관 상실 확률 40%)
사례  삼국형: 관우·양번 / 양강형: 마초·진령 / 북방형: 조조 잔존·관도
```

> **검산.** 219년 촉 64 ≥ 위 104 × 0.4 = 41.6 ✓ · 위 동원율 0.40 ≤ 0.45 ✓ ·
> 관우 절의 ✓ · 통솔 특급 ✓ → **발동한다.**
> 조건 ⑤(통솔 80)를 새로 붙인 것은, ④만으로는 절의 성향의 하급 지휘관까지
> 도박을 걸어 이벤트가 흔해지기 때문이다. **도박은 걸 만한 자만 건다.**

> **조건 ④ 미충족 시 폴백 (J4 결정, 2026-08-23):** 해당 전선 지휘관 전원이 「실무」
> 성향뿐이면 F-16은 발동하지 않는다 — 이것은 결함이 아니라 의도된 결과다(실무형은
> 애초에 도박을 걸지 않는 인물이다). 대신 **할거 페널티가 누적되면 [F-17] 약자의
> 반복 공세**(주체 조건에 성향 제약이 없다)가 자연스럽게 대체 발동한다.
> 즉 절의·야심 지휘관이 있으면 「도박적 공세」로, 없으면 시간이 지나 「반복 공세」로
> — **어느 쪽이든 압력 구조 자체는 끊기지 않는다.** ACT가 통째로 스킵되는 사태는
> [F-17]이 막는다. 상세 근거: `docs/DECISIONS.md` V-10.
>
> **[J5 보강]** 폴백까지의 공백은 최대 **12개월**이다(§0.3-⑤ 할거 페널티 발동 시점).
> 「없으면 시간이 지나」의 그 시간이 이제 확정되어 있다.

### [F-17] 약자의 반복 공세
```
정의  가만히 있으면 지므로 나아간다
발동  할거 페널티 발동 중 (§0.3-⑤, 연속 12개월) ∧ 공세 경로 보유

      n회차 보정 — 상대 방어 +10% × (n−1)
                   자국 자금 −15% × n
                   회차 종료 시 55세 이상 인물 사망 확률 +10%p
사례  삼국형: 촉의 북벌 / 일극형: 연합 공세

> **실동원 30 하한**은 228년 촉(70)이 넉넉히 넘고 219년 한중 독립 세력(8)이
> 못 넘는 선이다. **반복 공세는 약자의 것이지 소멸 직전 세력의 것이 아니다.**
> 「인재 고갈」이 회차 보정에 들어가 있는 것이 `scenario-228-263.md` §9-1

### [F-18] 보급 거점 강습
```
정의  전선이 아니라 후방을 친다
발동  적 보급 집적지 위치 확보 (첩보 성공 또는 [F-28] 기밀 유출)
      ∧ 강습형 지휘관 통솔 ≥ 70 ∧ 투입 병력 ≥ 1전대(28척)
주체  열세측
결과  성공률 = 40% + (아군 지휘관 지력 − 방어 지휘관 지력) × 0.5%p
               + [F-28] 정보 제공 시 +30%p
      성공 → 적 사기 −35 · 보급률 −60%
      실패 → 정예 상실 (투입 전력 70% 소멸)
사례  200 오소 / 전 형 공통
```

> **[F-28] 내부자의 이탈이 [F-18]의 주 입력이다.** 허유가 넘어오지 않으면
> 오소는 40% 언저리의 도박이고, 넘어오면 70%가 된다.
> **관도를 결정한 것은 병력이 아니라 사람 하나였다**가 산식으로 남는다.

### [F-19] 열세측의 비대칭 결전
```
정의  정면으로는 이길 수 없으므로 다른 수를 쓴다
발동  전력비 ≤ 0.5 (1:2 이상 열세) ∧ 지형 조건 충족 ∧ 계략 인물 지력 ≥ 85
주체  열세측
결과  성공률 = 30%
               + (아군 최고지력 − 적 최고지력) × 1.0%p
               + 지형 보정 (밀집 진형 +25 / 협도 +30)
               + 특성 보정 (「고육계」 +20 · 「연환계」 +15 · 「인내」 +15)
               − 적 최고지력 × 0.15  (참모 간파)
사례  208 적벽 화공 / 222 이릉 화공
```

> **검산 1 — 적벽.** 주유 96 대 조조측 최고 90 → 30 + 6 + 25(밀집·연환) + 20(고육계)
> − 13.5 = **67.5%.** 화공은 성립하되 확정이 아니다.
>
> **검산 2 — 이릉.** 육손 93 대 촉군 최고 70 → 30 + 23 + 30(협도) + 15(인내)
> − 10.5 = **87.5%.** 거의 확실하다.
> **두 화공의 확률이 20%p 차이 난다** — 적벽은 아슬했고 이릉은 그렇지 않았다는
> 원전의 인상이 그대로 나온다. 계수를 그렇게 맞춘 것이 아니라
> **지력차와 지형만 넣었더니 그 차이가 나왔다.**

> 다른 인물에게 대체 배정하지 않는다. 등애가 죽으면 F-20은 §7 배정 우선순위
> ④「아무도 없으면 이벤트 미발동」을 그대로 따라 미발동 — **이것도 정당한 결과다.**
> 263 시나리오의 구조적 정체는 「비인접 침투」가 아니라 **「내부로부터의 붕괴」**
> (world-state.md §5)이므로, F-20 없이도 F-06·F-25·F-26·F-31·F-32·F-34가
> 시나리오를 지탱한다. 상세 근거: `docs/DECISIONS.md` V-10.

### [F-21] 순류 남정
```
정의  상류를 쥔 자가 하류로 내려간다
발동  대항로 상류 권역 전 장악 ∧ 하류 방어 지휘관 통솔 ≤ 70
주체  상류 보유 세력
결과  권역 획득마다 다음 권역 공략 소요 −15%, 누적 상한 −60%
      방어측 사기 매 권역 상실마다 −10
사례  280 두예·왕준 / 전 형 공통
```

### [F-22] 복수 원정과 그 실패
```
정의  잃은 것을 되찾으려다 더 잃는다
발동  요충 권역 상실 ∧ 1급 이상 인물 상실이 12개월 이내 동시 발생
      ∧ 군주 성향 = 인덕형 또는 무단형
주체  피해 세력 군주 (친정 강제)
결과  「직간」 성향 인물 보유 시 취소 확률 30% (인물 3인 이상이면 50%)
      대패 (군주 사망 확률 35% → 승계 → [F-33])
      / 교착 / 승리 (역사 최대 이탈)
      경로에 대회랑 포함 시 [F-19] 피격 위험
사례  222 이릉 / 양강형: 한중 재공세
```

> **검산.** 219년 형주 상실과 220년 관우 사망은 12개월 이내다 → 발동.
> 조운·진복의 만류가 30%로 들어가되 뚫린다 — **말릴 수 있었으나 말리지 못했다.**

## 4. 방어 (Defense) 계열

### [F-23] 관문 방어전
```
정의  소수가 대군을 막는다
발동  회랑 권역이 공격받음
주체  방어측 배치 지휘관
결과  전개 제한 — 방어측 전력을 환산 배율로 곱한다
        대회랑 ×2.5 / 중회랑 ×1.8 / 관문 ×1.4
      「진창」급 특성 보유 시 병력차 무시 (환산 상한 ×10)
사례  190 호뢰 / 228 진창 / 263 검각
```

> **검산 — 263 검각.** 강유 실동원 약 20 × 2.5 = 50 대 종회 약 100 → 2배.
> [F-16] 판정표로 「1.5~2.5 = 교착」이다. **검각은 뚫리지 않는다.**
> 그래서 등애가 [F-20]으로 돌아가야 했다 — 두 이벤트가 수치로 맞물린다.

### [F-24] 요충 위임의 실패
```
정의  잘못된 자에게 맡긴 관문
발동  공세 중 확보한 요충 ∧ 주력이 다른 전선으로 이동해야 함
주체  플레이어 선택
결과  실패율 = 성향 기저 + 통솔 보정
        실무형 5% / 절의형 10% / 명사형 25% / 야심형 20% / 무뢰형 35%
        「담병」급 특성 보유 시 기저를 45%로 대체
        통솔 < 70 이면 +15%p
      실패 시 보급 차단 → 전군 퇴각 · 공세 진행도 전액 소멸
      위임하지 않으면 주력 구속 (해당 전선 실동원 −25%)
사례  228 가정·마속 / 전 형 공통
```

> **검산.** 마속은 명사형이고 「담병」을 갖는다 → 45% + 통솔 보정.
> **그럼에도 절반은 성공한다.** 가정은 정해진 실패가 아니라 나쁜 배팅이었다.

### [F-25] 최후의 항전
```
정의  이길 수 없는 방어를 누가 얼마나 지연시키는가
발동  자국 실동원 ≤ 적의 1/3 ∧ 주권역 위협
주체  최고 방어 특성 보유 인물
결과  지연 기간(게임 내 년) = (지휘관 통솔 − 60) ÷ 5 × min(1, 자국 실동원 ÷ 10)
      통솔 60 이하면 지연 없음 (급속 붕괴)
사례  육항 / 나헌 / 장제
```

> **검산.** 육항 통솔 92 · 실동원 25 → (32÷5) × 1.0 = **6.4년.**
> 나헌 통솔 78 · 실동원 2 → (18÷5) × 0.2 = **0.7년 ≈ 8개월.**
> 영안 농성이 반년 남짓이었고 육항 사후 오가 5년을 더 버텼다 —
> **병력 계수가 없으면 나헌이 육항만큼 버틴다.** 그래서 붙였다.

### [F-26] 항복 결정
```
정의  계산인가 배신인가
발동  적 실동원 ≥ 자국 × 3.5 ∧ 「항론」 성향 인물 보유
주체  군주 선택 (AI는 아래 유틸리티로 판정)
결과  항복 유틸리티 = 위협도 × 10
                    + 주권역 직접 위협 시 +40
                    + 「항론」 인물 최고 정치 ÷ 2
                    − 자국 천명 × 0.4
                    − 절의 성향 인물 수 × 4
                    − 주력 잔존율 × 30
      ≥ 40 → 항복 (세력 소멸, 천명 소폭 유지) / < 40 → 항전
사례  263 초주 / 208 유종 · 장소
```

> **검산 3건 — 세 결과가 전부 다르게 나온다.**
>
> | 사례 | 위협도 | 직접 위협 | 항론 | 천명 | 절의 | 잔존율 | 합 | 결과 |
> |---|---|---|---|---|---|---|---|---|
> | **유종 208** | 3.94 → 39.4 | +40 | 괴월 80 → +40 | 40 → −16 | 1인 → −4 | 1.0 → −30 | **69.4** | **항복** |
> | **손권 208** | 3.05 → 30.5 | 0 | 장소 88 → +44 | 45 → −18 | 4인 → −16 | 1.0 → −30 | **10.5** | **항전** |
> | **촉 263** | 3.0 → 30 | +40 | 초주 85 → +42.5 | 55 → −22 | 5인 → −20 | 0.1 → −3 | **67.5** | **항복** |
>
> **손권과 촉을 가른 것은 위협도가 아니라 주력의 위치다.** 둘 다 3배 앞이었고
> 둘 다 항론 인물이 있었다. 손권에게는 주유의 함대가 남아 있었고
> 유선에게는 강유가 검각에 갇혀 있었다.
> **「주력 잔존율」 한 항이 적벽과 성도를 갈라놓는다.**

## 5. 내부 (Internal) 계열

### [F-27] 의사결정 지연
```
정의  강자의 역설 — 선택지가 많아서 늦다
발동  실동원 1위 ∧ 군주 유형 = 명문형 ∧ 상반된 조언 ≥ 2건
주체  해당 세력
결과  조언 채택률 = 60% − 참모 수 × 3%p, 하한 25%
      「강직」 성향 조언은 추가 −15%p
      미채택 시 해당 주기 최적수 상실
사례  200 원소 / 명문형 군주 전반
```

> **검산.** 200년 원소는 저수·전풍·심배·곽도·봉기 5인을 두었다 →
> 60 − 15 = **45%.** 전풍의 「강직」 조언은 **30%.**
> **참모가 많을수록 채택률이 떨어진다** — 인재를 모은 것이 약점이 된다.
>
> **플레이어가 명문형일 때** (§9 검토 포인트 5의 답): AI의 채택률 저하를
> 플레이어에게 그대로 적용할 수 없으므로, 대신 **결정 제한 시간**을 부여한다.
> 이벤트 선택지에 실시간 **90초 타이머**가 붙고, 미선택 시 「보류」가 자동 선택된다.
> `ai-design.md` §12-1(「명문형 AI가 결단 임계로 마비될 수 있음」)이 지적한
> 강제 결정 타이머와 **같은 장치를 플레이어 쪽에 대칭으로 놓는 것**이다.

### [F-28] 내부자의 이탈
```
정의  조언이 계속 무시되면 사람이 떠난다
발동  조언 무시 누적 ≥ 5회 ∧ 해당 인물 성향 = 야심 ∧ 충성도 ≤ 40
주체  무시당한 참모
결과  적 세력 합류 + 기밀 유출 → [F-18] 성공률 +30%p
      유출 정보 유효 기간 6개월
사례  200 허유 / 전 형 공통
```

> [F-27]의 채택률 45%는 **10회 조언 중 5.5회가 무시된다**는 뜻이다.
> 누적 5회는 열 번쯤 말하면 도달한다 — **두 이벤트가 같은 시계로 돌아간다.**

### [F-29] 내부 균열과 이간
```
정의  결속이 약한 세력은 안에서 깨진다
발동  군주-핵심 무장 상성 「불량」 이하 ∧ 이간 실행 인물 지력 ≥ 80
주체  적대 세력 또는 내부 인물
결과  성공률 = 35% + (실행자 지력 − 대상 군주 지력) × 1.0%p
      「연환계」급 특성 실행 시 판정 없이 상성 강제 최악화, 실행 인물 소멸
사례  190 왕윤·초선 / 전 형 공통
```

### [F-30] 지도자의 죽음과 후계 공백
```
정의  한 사람에게 의존한 세력의 취약점
발동  [FIXED] 인물 연령 ≥ 55 부터 매년 사망 판정
      사망 확률 = (연령 − 50) × 1.2%
      사서 기록 사망 연도 도달 시 그 해 70%로 상향, 이후 매년 +10%p
주체  없음
결과  후계 지명 완료 → 승계 (동원율 영향 없음)
      후계 미지정 → 동원율 −0.15 · 전 권역 안정도 −20 · 천명 −10 → [F-33]
      반골 성향 인물 반란 확률 = 25% − 「집행」 특성 보유자 수 × 25%p
사례  234 제갈량 / 220 조조 / 전 형 공통
```

> **사서 연도 70% 상향이 역사 복원력이다**(`world-state.md` §3.2).
> 강제하지 않되 그 해에 가장 죽기 쉽다. 100%가 아니므로 곽가가 살아남는 세계도 있다.

### [F-31] 권신의 대두
```
정의  방어에 성공할수록 유능한 신하가 위험해진다
발동  「야심」 또는 「낭고」급 특성 ∧ 지휘 병력 ≥ 세력 실동원의 30%
주체  해당 인물
결과  찬탈 진행도 누적 (사건 단위)
        방어 전공 1회 +15 / 정변·반란 진압 +20 / 군주 교체 +25
        「낭고」 특성 보유 시 각 항목 ×1.5
      100 도달 → 정변 → 형해화 → [F-06] 조건 성립
      「선견」 특성 보유 시 진행도 80 도달 시점에 경고
사례  사마의·사마사·사마소 / 손침 / 전 형 공통
```

> **검산.** 사마의 — 234 오장원 방어 +15 · 238 요동 정벌 +15 · 239 명제 사망(군주 교체)
> +25 · 241 오 방어 +15 · 244 흥세 반사 +10 · 247~249 정변 준비 +20 = **100.**
> **249년 고평릉에 정확히 도달한다.**
>
> 진행도를 「매월 누적」이 아니라 **「사건 단위」**로 둔 이유가 여기 있다.
> 시간으로 재면 234년에서 249년까지 15년이 너무 길거나 너무 짧다.
> **권신은 세월이 아니라 공적으로 자란다.**

### [F-32] 전횡
```
정의  군주의 신임을 등에 업은 자가 세력을 갉아먹는다
발동  군주 정치 ≤ 45 ∧ 「전횡」 특성 인물이 측근 지위
주체  해당 인물
결과  매월 천명 −0.5 · 행정 수입 −10% · 동원율 −0.05 (region-power.md §3.4-d)
      해당 세력 전 권역 안정도 매월 −2
      해임 성공률 = (군주 정치 − 전횡 인물 정치) × 2%p, 하한 5%
      「직간」 성향 인물 보유 시 천명 하락폭 절반
      「직간」 인물 3인 이상이면 해임 성공률 +30%p
사례  황호 / 손침 / 하정
```

> **검산 및 §9 검토 포인트 7의 답.** 유선 정치 35 대 황호 60 → 해임 성공률 **5%.**
> 사실상 불가능하다 — 그것이 설계 의도다. 그러나 **「직간」 인물 3인을 붙들고 있으면
> 35%가 된다.** 동윤이 살아 있는 동안 황호가 눌려 있던 것이 여기서 재현된다.
>
> **완화 경로는 새 시스템이 아니라 인사다.** 플레이어가 할 수 있는 일은
> 황호를 자르는 것이 아니라 **동윤을 지키는 것**이다. 그 편이 이 게임답다.

### [F-33] 후계 분쟁
```
정의  안에서 갈라진다
발동  군주 사망 ∧ 후계 미지정 ∧ 유력 후보(혈연 ∧ 정치 ≥ 50) 2인 이상
주체  후보 진영
결과  장기화 확률 = 40% + 후보 수 × 10%p − 「보정」·「직간」 인물 수 × 12%p
      조기 수습 — 손실 없음
      장기화 — 1급 이상 인물 숙청 판정 (후보 수 × 2명) · 동원율 −0.10 · 안정도 −25
      권신 부상 — [F-31] 진행도 +25
사례  이궁의 변 / 원소 사후 원담·원상 / 조비·조식
```

> **검산.** 원소 사후 — 후보 2인, 심배·봉기는 각 진영에 갈라져 있어 억제로 세지 않는다
> → 40 + 20 = **60% 장기화.** 조비·조식 — 가후·최염 등 억제 인물 3인 이상
> → 40 + 20 − 36 = **24%,** 조기 수습.
> **같은 조건에서 원씨는 갈라지고 조씨는 봉합된다** — 억제 인물의 수가 갈랐다.

### [F-34] 전공자의 반역
```
정의  이긴 자가 가장 위험해진다
발동  정벌 성공 ∧ 담당 지휘관 성향 = 야심
      ∧ 신점령지 잔존 세력 인물 ≥ 3인
      ∧ 지휘 병력 ≥ 세력 실동원의 40%
주체  정벌 지휘관
결과  반역 확률 = 20% + (지휘 병력 비중 − 40) × 1.0%p
                 + 잔존 세력 인물 내응 시 +15%p
                 − 감군 파견 시 −30%p
      「선견」 특성 보유자가 중앙에 있으면 사전 경고
사례  263 종회·강유 / 전 형 공통
```

> **검산.** 종회 — 지휘 비중 60% → 20 + 20 + 15(강유 내응) = **55%.**
> 감군(위관)을 붙이면 **25%.** 종회의 난은 일어났고 실패했다 —
> 확률로도 반반이고, 중앙이 손을 써 두었으면 대체로 막힌다.

## 6. 통치 (Governance) 계열

### [F-35] 토호의 귀부
```
정의  지방 세력이 중앙 세력을 평가한다
발동  중립 권역 인접 ∧ 접촉 시도 (사자 파견 또는 위압)
주체  토호 (귀부형 / 저항형 / 적대형)

## 7. 배정 우선순위

여러 세력·인물이 조건을 충족할 때의 선택 규칙.

```
① 역사 대응 인물이 조건을 충족하면 우선 배정
   (관우가 살아있고 조건을 만족하면 관우가 한다)

② 미충족 시 같은 성향·클래스 인물 중 능력 최고

③ 그마저 없으면 세력 단위로 배정 (「연합 선봉」 등)

④ 아무도 없으면 이벤트 미발동
```

> **①이 있어야 역사가 자연스럽게 재현되고,**
> **②③이 있어야 역사가 이탈해도 캠페인이 굴러간다.**

**①의 강도** [J5 확정] — §9 검토 포인트 3의 답.

| 항목 | 값 |
|---|---|
| 역사 대응 인물 가산 | **+15** (능력 환산) |
| ②의 대체 인물 성공률 감쇄 | −20% (J4의 육손「인내」 −60%은 특성 전용 예외) |

> 가산을 15로 둔 것은 **능력 15 이상 앞서는 인물이 있으면 그쪽이 한다**는 뜻이다.
> 역사 인물이 우선하되 **압도적으로 나은 대안까지 밀어내지는 않는다.**
> 「역사 생성의 의미가 약해진다」는 우려는 여기서 닫힌다.

### 8.0 배치표의 지위 — 게이트가 아니라 대표 목록이다 [2026-08-27 확정]

**이 표를 「이 시나리오에서 켜지는 이벤트 목록」으로 읽으면 안 된다.**
그렇게 읽으면 문서가 세 군데서 깨진다.

| 근거 | 내용 |
|---|---|
| **[F-01] 질서의 공백** | 발동이 **「[FIXED] 캠페인 개시 시 무조건」**이고 하는 일이 **전 세력 천명 초기값 설정**이다. 표에는 **190에만** 있다. 게이트로 읽으면 나머지 다섯 시나리오는 천명이 설정되지 않고 조서 시스템이 열리지 않는다 — **캠페인이 서지 않는다** |
| **[F-30] 지도자의 죽음** | 발동이 **「연령 ≥ 55부터 매년 사망 판정」**이다. 표에는 **190과 263이 빠져 있다.** 게이트로 읽으면 그 두 시나리오에서 아무도 늙어 죽지 않는다 — 190의 동탁도, 263의 사마소도 |

**표가 세는 것은 「그 시나리오를 규정하는 이벤트」다.**
190은 반동탁과 낙양 소각으로, 208은 손유 동맹과 적벽으로, 263은 내부 붕괴로 규정된다.
**서사·튜토리얼·QA 체크리스트가 쓸 목록이지 조건식이 참조할 목록이 아니다.**

> `사례` 줄은 §0.1의 기재 형식대로 **형**(삼국형 / 양강형 / 일극형 / 북방형)으로 적히고,
> §8 표는 **시나리오**로 적힌다. 두 축은 직교한다.
>
> 「전 형 공통」을 단 **17종 중 열셋이 §8에는 한 시나리오에만** 올라 있다.
> 두 축이 다른 것을 세고 있다는 표시였는데, 한 표 안에서 읽혔다.

### 8.1 패권 압력 검산 — 6시나리오 [J5]

§0.3-② 산식을 시나리오별 최강자에 적용한다.

| 시나리오 | 최강자 | 기저 점유율 | 우위 가산 | 명분 침해 | **합** | 구간 |
|---|---|---|---|---|---|---|
| **190** | 동탁 | 18 ÷ 70 = 26 | 황제 +10 · 인재 +8 | **폐립 +20** | **64** | **극대** |
| **200** | 원소 | 71 ÷ 194 = 37 | 인재 +5 | — | **42** | 중 |
| 200 | 조조 | 47 ÷ 194 = 24 | 황제 +10 · 인재 +8 | — | **42** | 중 |

**세 가지가 맞아떨어진다.**

1. **208년이 정확히 60** — `scenario-200-208.md` §7.2의 「패권 압력이 극대 구간에
   **진입**한다」와 일치한다. 경계값 그 자리다
2. **200년은 둘 다 「중」** — 동 문서의 「두 세력 모두 임계를 넘어 상호 견제 상태로
   진입」과 일치하고, **F-07이 200년 배치 목록에 없는 것**과도 맞는다.
   견제 연합이 열리지 않는 해이므로 배치되지 않았다
3. **190년 동탁은 실동원 3위인데 압력 1위다** — 익주 유언(37)·기주 한복이
   군사적으로는 앞선다. **압력은 힘의 순위가 아니라 위협의 순위다**

> **핵심 발견 — 반동탁 연합은 동탁이 강해서 결성된 것이 아니다.**
> 폐립 가산 +20이 없으면 동탁은 44 「중」에 머물고 [F-07]이 열리지 않는다.
> **명분 침해 항목을 넣지 않으면 190년 시나리오가 성립하지 않는다.**
>
> 이것은 계산 편의가 아니라 주제축이다. 「정통 vs 실력」에서
> **정통을 훼손하는 행위 자체가 실력과 무관하게 적을 만든다** —
> 관동 제후가 일어선 이유는 동탁의 군세가 아니라 소제를 폐한 일이었다.

### 8.3 무엇이 이벤트를 막는가 — 게이트 3층과 빈 넷째 [2026-08-27]

§8이 게이트가 아니라면 게이트는 어디에 있는가. **이미 셋 있다.**

| 층 | 게이트 | 어디에 적혀 있나 | 상태 |
|---|---|---|---|
| **① 발동 조건식** | 각 종의 `발동` 줄 | 본 문서 §1~6 | **확정** — J5에서 40종 절대값 부여 |
| **② 형 치환** | 양강형에서 [F-07]·[F-12] 미성립 → 치환 | §8.2 · `world-state-setup.md` §5.2 | **확정** |

| **④ 재발동 상한** | — | **어디에도 없다** | **미정** |

**④가 비어 있다는 것을 M0가 드러냈다.**
`m0-report.md` §2.4 ⑩의 100회 캠페인에서 넷이 회당 10회를 넘었다 —
[F-37] 16.5 · [F-25] 15.7 · [F-13] 10.0 · [F-07] 10.0.
**①②③은 전부 통과시켰다. 막을 것이 없었기 때문이다.**

> **①은 「지금 조건이 참인가」를 묻고, ④는 「이미 한 번 일어나지 않았는가」를 묻는다.**
> 40종의 발동 줄은 전부 앞의 질문으로만 쓰여 있다.
> 그래서 조건이 유지되는 동안 같은 이벤트가 계속 참이고,
> **지속 상태가 사건으로 읽힌다.**

#### 넷의 분류 — 상세는 `05-narrative/event-scripts.md` §7.6

빈도는 **연출 쪽에서 먼저 드러났다**(회당 16회 뜨는 연출은 소음이 된다).
분류와 근거는 그쪽에 있고, 여기에는 조건식이 받아야 할 형태만 옮긴다.

| 축 | 뜻 | 해당 | 재무장 |
|---|---|---|---|
| **상태 변화 시에만** | 전이에서 한 번. 지속분은 효과가 맡는다 | **[F-13]** 권역당 | 연결 회복 후 재차단 |
| **세력당 N회** | 주체가 한 번밖에 겪을 수 없다 | **[F-37]** 도읍당 1회 · **[F-25]** 지휘관당 1회 | 도읍 변경 / 지휘관 교체 |
| **캠페인당 N회** | 판이 재편되는 것 | **[F-07]** 결성 분기만 2회 | [F-10] 해체 |

> **상한은 새로 정하는 값이 아니다.**
> [F-13]의 발동 줄은 이미 「인접 아군 권역이 0이 **됨**」이라는 전이로 쓰여 있고,
> [F-25]의 지연 기간 산식은 이미 육항 6.4년 · 나헌 8개월을 낸다.
> **문서가 전이와 기간을 적어 두고도 ④ 층을 만들지 않았을 뿐이다.**

**나머지 36종의 ④ 배정은 미작성이다** (§10).
