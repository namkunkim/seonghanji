> 각 Timeline 문서에 흩어진 이벤트를 **구조 정의**로 통합한다
> 작성일: 2026-08-22 / 상태: 초안 — 검토 요망

---

## 0. 이 문서의 역할

세계 상태 4형이 작동하려면 이벤트가 **인물의 이름이 아니라 압력의 구조**로 정의되어야 한다.

```
「관우의 북벌」          → 특정 인물·특정 무대에 종속. 삼국형에서만 성립
「최강자의 관문 공세」   → 조건을 충족하는 누구든 수행. 4형 전부에서 성립
```

### 0.1 기재 형식

```
[F-##]  명칭
정의    이 이벤트가 표현하는 압력 구조
발동    충족해야 하는 조건 (시스템 변수로 기술)
주체    수행자 배정 규칙
결과    분기
사례    삼국형 / 양강형 / 일극형 / 북방형에서의 구현
```

## 1. 질서 (Order) 계열

### [F-01] 질서의 공백
```
정의  중앙 권위가 물리적으로는 존속하나 실효를 상실한다
발동  [FIXED] 캠페인 개시 시 무조건. 천명 전 세력 바닥
주체  없음 (상태 이벤트)
결과  조서 시스템 개방 · 토호 자립 · 세력 형성 개시
사례  전 형 공통 — 후한 말의 전제 상태
```

### [F-02] 상징의 쟁탈
```
정의  정통성의 물리적 담지자를 누가 확보하는가
발동  현 보유 세력의 실동원이 임계 미만으로 하락
      또는 보유 세력 붕괴
주체  인접 권역 보유 세력 중 실동원 최대
결과  옹립(±0) / 정중히 모심(+대) / 유폐(−중) / 시해(−극대)
사례  삼국형·양강형: 헌제 / 일극형: 이미 확보됨 / 북방형: 원소가 확보 시 천명 우위 확정
```

### [F-03] 상징의 발견
```
정의  정통성을 대체·보강하는 물건이 출현한다
발동  파괴된 수도 권역에 최초 진입 시
주체  진입 세력
결과  반환(천명+대) / 보관(칭제 조건) / 양도(수령자 칭제 유도) / 파기(−중)
사례  전 형 공통 — 전국옥새
```

### [F-04] 참칭
```
정의  실력이 명분에 못 미치는 자가 최고위를 칭한다
발동  상징(옥새 등) 보유 ∧ 천명 임계 미달 ∧ 야심 성향 군주
주체  조건 충족 세력 (AI는 자동, 플레이어는 선택)
결과  천명 붕괴 · 전 세력 적대 · 급속 몰락
사례  삼국형: 원술 / 그 외: 조건 충족 세력 누구든
```

### [F-05] 격상 선언
```
정의  자유도를 얻는 대가로 명분을 내놓는다
발동  요충 권역 확보 ∧ 실동원 임계 초과
주체  플레이어 선택
결과  신하 유지(사기−) / 칭왕(천명−중) / 칭제(천명−대)
      + 절의 인물 이탈 판정 (성향태그 §3.3)
사례  삼국형: 한중왕·위왕 / 전 형 공통
```

### [F-06] 형식을 갖춘 왕조 교체
```
정의  같은 행위가 천명 수치에 따라 다른 이름으로 기록된다
발동  찬탈 진행도 완료 ∧ 황제 보유
주체  권신 또는 최강자 군주
결과  천명 임계 이상 → 「선양」 / 미달 → 「찬탈」
사례  삼국형: 조비→사마염 / 북방형: 원소 계열
```

## 2. 연합 (Coalition) 계열

### [F-07] 견제 연합의 결성
```
정의  한 세력의 패권 압력이 임계를 넘으면 나머지가 결집한다
발동  최강자 패권 압력 ≥ 「높음」
      ∧ 견제 세력 실동원 합 ≥ 최강자 × 0.4
      ∧ 참가 후보 간 적대 관계 없음
주체  맹주 = 천명 최상위 또는 명문형 군주
결과  결성 / 명목 결성 / 결렬
사례  190 반동탁 / 208 손유 / 일극형에서는 이것 자체가 승리 조건
```

### [F-08] 연합 교섭
```
정의  자동 동맹은 없다. 조건을 협상한다
발동  [F-07] 결성 판정 통과 후
주체  참가 세력 전원
결과  공동방어 / 공동공격 / 영토 사전 분배 / 비밀 협약
      → AllianceTrust 초기값 결정
사례  208 손유회담 / 일극형 연합 교섭
```

### [F-09] 최강자의 분열 외교
```
정의  패권 압력에 대한 반격 — 연합을 안에서 깬다
발동  견제 연합 결성됨 ∧ 최강자 실동원 ≥ 연합 합의 1.2배
주체  최강자
결과  관직 / 영토 / 조서 / 불가침 / 공동 군사행동 제안
      성공 시 [F-07] 무효화
사례  208 조조→손권 / 219 조조→손권 / 전 형 공통
```

### [F-10] 연합의 해체
```
정의  목적을 달성했든 못 했든 연합은 반드시 흔들린다
발동  [LIKELY] 연합 결성 후 일정 기간 경과
      또는 목표 달성 · 보급 소진 · 전과 분배 분쟁
주체  참가 세력 각자
결과  유지 / 독자 행동 / 동맹국 공격(천명−대, 배신 기록)
사례  190 관동 연합 / 219 손유 동맹
```

### [F-11] 동맹 신뢰도 청산
```
정의  함께 싸운 자들이 전과를 정산한다
발동  공동 승리 직후 ∧ 미해결 분배 항목 존재
주체  동맹 참가 세력
결과  협약 준수(유지) / 차용 합의(−소, 반환 요구 예약)
      / 협약 위반(−대, 배신 기록 영구)
사례  208 형주 분배 / 219 반환 요구
```

### [F-12] 동맹의 배후 기습
```
정의  신뢰의 최종 청산
발동  AllianceTrust ≤ 임계
      ∧ 동맹국이 타 전선에 주력 투입
      ∧ 요충 권역이 기습 사거리 내
주체  제3자 중 실동원 최대. 「야심」 성향 지휘관 보유 시 확률 상승
결과  성공 → 요충 상실 → [F-13] 연쇄 / 실패 → 신뢰도만 붕괴
사례  삼국형: 백의도강 / 양강형: 신복속 반란 / 일극형: 연합 이탈
```

### [F-13] 고립과 비지화
```
정의  한 권역의 상실이 나머지를 끊는다
발동  아군 권역 중 인접 아군 권역이 0이 됨
주체  없음 (자동 판정)
결과  생산 −50% · 병력 보충 불가 · 유지비 2배
      장기 지속 시 자동 이탈 또는 독립
사례  219 관우군 / 상용권 맹달 / 전 형 공통
```

### [F-14] 동맹 복원
```
정의  배신 이후, 공동의 위협 앞에서
발동  공동 위협 패권 압력 「극대」 ∧ 양측 생존
주체  약소측이 제안
결과  성공 시에도 신뢰도는 이전 수준으로 복귀하지 않음
      배신 기록은 영구 계승
사례  223 손유 동맹 복원 (등지)
```

## 3. 공세 (Offensive) 계열

### [F-15] 요충 쟁탈
```
정의  지형적 결절 권역의 획득이 전략 구도를 바꾼다
발동  회랑 2개 이상이 접속된 권역이 적대 세력 소유
주체  인접 세력 중 실동원 임계 초과
결과  획득(경로 개방) / 실패(방어 종심 상실) / 부분 획득(비지)
사례  삼국형·양강형: 한중 남정권 / 북방형: 관중 장안서부권
```

### [F-16] 최강자의 관문을 향한 도박적 공세
```
정의  이길 수 없는 자가 결정적 요충을 노린다
발동  ① 최강자의 관문 권역에 인접
      ② 자국 실동원 ≥ 최강자 × 0.4
      ③ 최강자 동원율 ≤ 0.45 (타 전선 구속)
      ④ 담당 지휘관 성향 = 절의 또는 야심
주체  조건 충족 세력의 해당 전선 지휘관
결과  관문 획득 / 교착 / 배후 기습 유발 / 전멸
사례  삼국형: 관우·양번 / 양강형: 마초·진령 / 북방형: 조조 잔존·관도
```

### [F-17] 약자의 반복 공세
```
정의  가만히 있으면 지므로 나아간다
발동  할거 페널티 발동 중 ∧ 공세 경로 보유
주체  최강자가 아닌 세력 중 동원율 최고
결과  최대 6회 반복. 회차마다 재선택
      회차↑ → 상대 방어 강화 · 인재 고갈 심화
사례  삼국형: 촉의 북벌 / 일극형: 연합 공세
```

### [F-18] 보급 거점 강습
```
정의  전선이 아니라 후방을 친다
발동  적 보급 집적지 위치 정보 확보 ∧ 정예 강습 부대 보유
주체  열세측
결과  성공(적 사기 붕괴) / 실패 / 역정보(정예 상실)
사례  200 오소 / 전 형 공통
```

### [F-19] 열세측의 비대칭 결전
```
정의  정면으로는 이길 수 없으므로 다른 수를 쓴다
발동  전력비 1:2 이상 열세 ∧ 지형 조건 충족 ∧ 계략 인물 보유
주체  열세측
결과  화공 / 매복 / 위장 항복 / 유인
      성공률 = 지력차 + 지형 + 특성 − 적 참모 간파
사례  208 적벽 화공 / 222 이릉 화공
```

### [F-20] 비인접 침투
```
정의  지도에 없는 길을 뚫는다
발동  ① 후기 시나리오 한정
      ② 인접 성계 완전 장악
      ③ 「음평도」급 특성 인물 보유
      ④ 1회 한정
주체  해당 특성 보유 인물
결과  성공(수도 직격, 회랑 방어 무효화) / 실패(함대 전멸)
사례  263 등애 / 전 형 공통 (무대만 변경)
```

### [F-21] 순류 남정
```
정의  상류를 쥔 자가 하류로 내려간다
발동  대항로 상류 권역 완전 장악 ∧ 하류 방어 핵심 인물 부재
주체  상류 보유 세력
결과  진격 속도 누적 상승. 방어 붕괴 가속
사례  280 두예·왕준 / 전 형 공통
```

### [F-22] 복수 원정과 그 실패
```
정의  잃은 것을 되찾으려다 더 잃는다
발동  요충 + 핵심 인물 동시 상실 ∧ 군주 성향 = 인덕형 또는 무단형
주체  피해 세력 군주 (친정)
결과  대패(군주 사망 → 승계) / 교착 / 승리(역사 최대 이탈)
      경로에 대회랑 포함 시 [F-19] 피격 위험
사례  222 이릉 / 양강형: 한중 재공세
```

## 4. 방어 (Defense) 계열

### [F-23] 관문 방어전
```
정의  소수가 대군을 막는다
발동  회랑 권역이 공격받음
주체  방어측 배치 지휘관
결과  전개 제한으로 병력차 상쇄
      「진창」급 특성 보유 시 병력차 무시
사례  190 호뢰 / 228 진창 / 263 검각
```

### [F-24] 요충 위임의 실패
```
정의  잘못된 자에게 맡긴 관문
발동  공세 중 확보한 요충의 수비 위임 필요
주체  플레이어 선택
결과  실무형(안정) / 명사형·「담병」 특성(실패율) / 위임 안 함(주력 구속)
      실패 시 보급 차단 → 전군 퇴각
사례  228 가정·마속 / 전 형 공통
```

### [F-25] 최후의 항전
```
정의  이길 수 없는 방어를 누가 얼마나 지연시키는가
발동  자국 실동원 ≤ 적의 1/3 ∧ 주권역 위협
주체  최고 방어 특성 보유 인물
결과  「최후의 명장」급 보유 시 수년 지연
      부재 시 급속 붕괴
사례  육항 / 나헌 / 장제
```

### [F-26] 항복 결정
```
정의  계산인가 배신인가
발동  주권역 상실 임박 ∧ 「항론」 성향 인물 보유
주체  군주 선택 (AI는 천명·국력 기반 판정)
결과  항전(인명 손실) / 항복(세력 소멸, 천명 소폭 유지)
사례  263 초주 / 208 유종 · 장소
```

## 5. 내부 (Internal) 계열

### [F-27] 의사결정 지연
```
정의  강자의 역설 — 선택지가 많아서 늦다
발동  실동원 최대 세력 ∧ 군주 유형 = 명문형
      ∧ 참모 간 상반된 조언 존재
주체  해당 세력
결과  조언 채택률 저하. 「강직」 성향 조언은 반발 유발
      최적수를 놓치는 확률 발생
사례  200 원소 / 명문형 군주 전반
```

### [F-28] 내부자의 이탈
```
정의  조언이 계속 무시되면 사람이 떠난다
발동  조언 무시 누적 ≥ 임계 ∧ 해당 인물 성향 = 야심
주체  무시당한 참모
결과  적 세력 합류 + 기밀 유출 → [F-18] 조건 충족
사례  200 허유 / 전 형 공통
```

### [F-29] 내부 균열과 이간
```
정의  결속이 약한 세력은 안에서 깨진다
발동  군주-핵심 무장 상성 불량 ∧ 이간 실행 인물 보유
주체  적대 세력 또는 내부 인물
결과  「연환계」급 특성 실행 시 상성 강제 최악화
      실행 인물 소멸
사례  190 왕윤·초선 / 전 형 공통
```

### [F-30] 지도자의 죽음과 후계 공백
```
정의  한 사람에게 의존한 세력의 취약점
발동  [FIXED] 시나리오 기간 중 핵심 인물 사망 판정
주체  없음
결과  후계 지명 완료(승계) / 미지정(동원율 −0.15)
      + 반골 성향 인물 반란 판정 → 「집행」 특성 보유 시 즉시 처단
사례  234 제갈량 / 220 조조 / 전 형 공통
```

### [F-31] 권신의 대두
```
정의  방어에 성공할수록 유능한 신하가 위험해진다
발동  방어 전공 누적 ∧ 「야심」 또는 「낭고」급 특성 인물 보유
주체  해당 인물
결과  진행도 누적 → 정변 → 형해화 → [F-06] 조건 성립
      「선견」 특성 보유 시 1턴 전 경고
사례  사마의·사마사·사마소 / 손침 / 전 형 공통
```

### [F-32] 전횡
```
정의  군주의 신임을 등에 업은 자가 세력을 갉아먹는다
발동  군주 능력 임계 미달 ∧ 「전횡」 특성 인물 보유
주체  해당 인물
결과  천명·행정 지속 하락. **해임 곤란** (군주 신임에 종속)
      「직간」 성향 인물 보유 시 하락폭 절반
사례  황호 / 손침 / 하정
```

### [F-33] 후계 분쟁
```
정의  안에서 갈라진다
발동  후계 미지정 ∧ 유력 후보 2인 이상 ∧ 개입 인물 존재
주체  후보 진영
결과  조기 수습 / 장기화(명장 다수 숙청) / 권신 부상
      억제: 「보정」·「직간」 성향 인물
사례  이궁의 변 / 원소 사후 원담·원상 / 조비·조식
```

### [F-34] 전공자의 반역
```
정의  이긴 자가 가장 위험해진다
발동  정벌 성공 ∧ 담당 지휘관 「야심」 ∧ 신점령지에 잔존 세력 인물 존재
주체  정벌 지휘관
결과  독립 세력화 / 사전 감독으로 저지 / 「선견」 보유 시 경고
      멸망 세력 인물의 내응 가능
사례  263 종회·강유 / 전 형 공통
```

## 7. 배정 우선순위

여러 세력·인물이 조건을 충족할 때의 선택 규칙.

```
① 역사 대응 인물이 조건을 충족하면 우선 배정
   (관우가 살아있고 조건을 만족하면 관우가 한다)

② 미충족 시 같은 성향·클래스 인물 중 능력 최고

③ 그마저 없으면 세력 단위로 배정 (「연합 선봉」 등)

④ 아무도 없으면 이벤트 미발동
```

> **①이 있어야 역사가 자연스럽게 재현되고,**
> **②③이 있어야 역사가 이탈해도 캠페인이 굴러간다.**
