# PART A — 시나리오 5 「출사표」(228~252)

## 1. 핵심 질문

> **이길 수 없다는 것을 알면서도 나아갈 것인가?**

## 1.1 구조적 정체

> **약자의 강제된 공세**

「북벌」이 아니다. 북벌은 삼국형에서의 형태일 뿐이다.
**어느 세계 상태에서든 「가만히 있으면 지는 세력이 무리한 공세를 반복한다」는 구조는 유지된다.**

## 1.2 세 개의 압력

이 시나리오는 **플레이어를 강제로 밀어낸다.**

| 압력 | 작동 |
|---|---|
| **성장 비대칭** | 최강자는 전화 회복으로 계속 자란다. 격차는 매년 벌어진다 |
| **할거 페널티** | 확장 없이 방어만 하면 **천명이 지속 하락** |
| **인재 고갈** | 후기 명장 30인. 특급·1급 비율 최저. **시간이 갈수록 더 나빠진다** |

> **가만히 있으면 진다.**
> 제갈량이 왜 승산 없는 북벌을 여섯 차례나 반복했는지가 시스템으로 설명된다.

### ACT 3 — 비인접 침투

**【기능】 비인접 침투 — 존재하지 않는 길**

**Event 04. 음평 [CHOICE]**

**게임 내 유일한 비인접 성계 간 직접 침투.**

```
발동 조건
  ① 후기 시나리오 한정
  ② 인접 성계(양주) 완전 장악
```

| 항목 | 값 |
|---|---|
| 경로 | 양주 → **익주 성도권 직격** (지도상 연결 없음) |
| 소요 | 기저 항로 수준 |
| 탐지 | **전 구간 무효** |

| 방어측 대응 | 조건 |
|---|---|
| **사전 배치** | 음평 경로 예측 시. 제갈첨 요격 |
| 수도 방어 | 최후 방어전 |
| 즉시 항복 | 초주「항론」 채택 |
| **주력 회군** | 검각 방어 포기 → 정면 축 돌파 |

> **검각을 아무리 두텁게 지켜도 등애는 성도 앞에 나타난다.**
> 그리고 방어측은 **검각과 수도 중 하나를 포기해야 한다.**
> 회랑 방어 체계 전체를 무효화하는 단 하나의 능력.
