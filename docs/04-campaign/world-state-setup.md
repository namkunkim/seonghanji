## 0. 이 문서의 구조

### 0.1 왜 24개가 아니라 21개인가

`JOBS.md` J8은 「4형 × 6시나리오 = 24개」로 산정되어 있었다.
작업 중 **시나리오 1(190)은 1형만 성립한다**는 것이 드러났다.

```
190 ──▶ 200 ──▶ 208 ──▶ 219 ──▶ 228 ──▶ 263
 │
 └─ 캠페인의 첫 시나리오. 계승할 이전 상태가 없다
```

세계 상태는 **이전 시나리오의 결과를 판정해 결정된다**(`world-state.md` §4).
190은 계승할 것이 없으므로 판정 자체가 성립하지 않으며,
단편 모드도 항상 삼국형이다(동 §3.3). **190의 배치는 역사 배치 하나뿐이다.**

| 시나리오 | 성립하는 형 | 수 |
|---|---|---|
| **190** | 삼국형만 | **1** |
| 200 · 208 · 219 · 228 · 263 | 4형 전부 | 20 |
| | | **계 21** |

> **200년의 북방형은 성립한다.** 190~199 사이에 조조가 몰락하면
> 200년 시작 판정에서 원소 계열 우위가 잡힌다 — 관도가 열리기 전에 관도가 끝난 세계다.

### 0.2 기재 방식 — 기본형 전체 + 변주형 차분

```
기본형   권역 45개를 세력별로 전부 나열
변주형   기본형으로부터의 「이동」만 기재 + 세력별 합계로 45 검산
```

**분기 복제(×4)를 피하기 위한 형식이다**(`DECISIONS.md` R-06, 물량 ×1.3 원칙).
명시되지 않은 권역은 **기본형과 동일**하다.

### 0.3 각 시나리오의 기본형

`world-state.md` §4.0-b에서 확정한 것을 그대로 쓴다.

| 시나리오 | 기본형 | 근거 |
