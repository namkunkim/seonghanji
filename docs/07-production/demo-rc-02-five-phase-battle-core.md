# DEMO-RC-02 — 적벽 턴제 5단계 전투 코어 계약

> 최신화: 2026-09-10 · `MGMT-HANDOVER-01`
> 요구사항 정본: `docs/07-production/demo-rc-requirements-interview.md`

## 전투 구조

- 전투는 최대 20턴이며 모든 판정은 동일 입력에서 동일 결과를 내는 결정론적 규칙을 사용한다.
- 기존의 `접적 → 포화 → 교전 → 강습 → 결착`은 전투 전체를 한 번씩 통과하는 진행 단계가 아니라, 매 턴 명령을 해석하는 판정 단계로 유지한다.
- 한 턴은 탐지·접적, 장거리 포화, 직접 교전, 강습·요격, 결과·결착 순으로 판정한다.
- 매 턴 이동·전투가 끝난 뒤 모든 승리 조건을 검사하며 하나라도 충족되면 즉시 게임을 종료한다.

## 명령과 이동

- 명령 단위는 전대이며 여러 전대를 편성한 함대에는 함대 단위 명령을 내릴 수 있다.
- 명령에는 자유 좌표 이동과 다중 경유점, 방향, 진형, 무기별 사용 비율, 공격 대상과 사격 중지가 포함된다.
- 이동은 기동 속도 순으로 교차 판정한다. 경로 교차 시 요격하고 탐지된 적이 사거리·사격각에 들어오면 기회 사격한다.
- 정면·측면·후면, 진형, 지형, 탐지 수준, 사기, 지휘관 능력, 제한 탄약·에너지·열과 특수 자원을 전투 판정에 반영한다.
- 턴 실행 전에는 명령을 자유롭게 수정·취소한다. 실행 뒤에는 되돌리지 않고 전투 기록으로 확인한다.

## 함대 편성과 지휘 승계

- 전투 중 전대 전체를 함대에 편입하거나 제외할 수 있다. 편입은 함대 지휘 범위 안에서 예약하며 해당 턴 판정 뒤 적용한다.
- 전대 내부 함선·장수 재배치는 전투 중 허용하지 않는다.
- 함대 지휘관이 지휘 불능이면 부함장, 최고 레벨 전대 지휘관, 최고 지휘 능력치 순으로 승계하고 승계자 전대를 새 기함 전대로 지정한다.
- 승계 뒤 한 턴 동안 기동력·명중률·진형 변경 속도에 결정론적 명령 혼선 불이익을 적용한다. 새 지휘 한도 초과 불이익과 중첩한다.

## 요격함·고속정·보급

- `요격함`은 제7 함종이며 고속 요격, 측후방 공격, 함대 차폐와 호위를 맡는다. `호위`는 함종이 아닌 전술 임무다.
- 고속정은 소형 전투정으로 여러 척을 고속정 전대로 편성한다. 요격·뇌격·정찰·구조 임무 장비 코스트를 기본 선체 코스트에 더한다.
- 임무 장비는 전투 중 교체하지 않지만 지원 범위 안의 전술 임무는 언제든지 바꿀 수 있다. 판정 재생 중 변경은 다음 명령 단계부터 적용한다.
- 고속정의 연료·탄약은 제한 자원이다. 비상 귀환 기준은 가장 가까운 자동 보급 영역까지 필요한 연료와 한 턴분 예비 연료의 합이다.
- 보급함·보급 가능한 강습모함·아군 거점은 자동 보급 영역을 제공한다. 영역 안에서 한 턴을 유지하면 자동 보급하며 처리량 초과 시 잔여 연료, 진입 시점, 전대 고유 번호 순으로 처리한다.
- 도달 가능한 보급 영역이 없고 연료를 소진하면 표류한다. 표류 전대는 이동·공격할 수 없으며 구조 또는 나포 대상이 된다.

## 저장과 검증

- 수동 저장 3개와 별도 턴 종료 자동 저장을 제공한다.
- 저장은 대기 명령, 손권 수동 문의 상태, 탐지 정보, 제한 자원, 사기, 지휘관 상태, 증원, 승리 조건 진행을 복원한다.
- 기존 5페이즈 단일 진행 명령과 phase 5 전용 승자 계산은 최신 계약에 의해 대체된다.
