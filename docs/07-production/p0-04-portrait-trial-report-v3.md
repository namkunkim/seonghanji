> 선행: `p0-04-portrait-trial-report.md` v2 · 산출물: `assets/preproduction/p0-04/runpod-v3/`

## 1. 결론

역할 3종(C903 제독, C906 관료, C910 돌격병) × 모델 2종(FLUX.1 schnell, SDXL 1.0)의
고정 시드 비교 6장을 생성했다. 생성 단계에서는 중립 회색 배경만 사용하고 계층 틴트는
결정론적 후처리로 적용했다. 해상도·비율·모델 SHA·워크플로 SHA·프롬프트 SHA·출력 SHA는
모두 기록됐다.

품질 판정은 **합격 0 / 보류 0 / 재작업 6**이다. FLUX는 역할별 상반신 구조가 SDXL보다
가까웠지만 모자·가짜 문자·표식을 반복했고, SDXL은 역사극 복식·전신/측면 구도로 회귀해
역할 실루엣이 무너졌다. **최종 모델, 최종 공용 11종, 명장 120명 확장으로 승격하지 않는다.**

발주자 판정으로 **v2 이미지 스타일은 유지한다.** 다음 시험은 화풍 교체가 아니라 v2의
저채도 반사실적 디지털 페인팅을 기준으로 두고, ControlNet/IP-Adapter 계열 구조 제어로
역할 실루엣과 구도를 교정한다.

2026-09-01 추가 판정으로 **SDXL은 이후 인물 제작에서 제외**한다(V-50). 관모·군모·두건·
헬멧·머리 장식의 직접 착용과 가상 문자·표식은 허용한다. 이후 발주자가 v4 3장 게이트를
대체해 FLUX production v1 공용 11종을 직접 승인했다. 이 문서는 비교 이력으로만 보존하며
현행 판정은 `p0-04-portrait-production-v1-report.md`를 따른다.

시작하지 않았으며, 재연결 뒤 동일 입력으로 6장 모두 정상 생성했다.

## 3. v3 보정 사항

- 생성 프롬프트에서 진영·계층 색을 제거하고 중립 회색 배경으로 고정.
- `no text, no signatures, no watermark, no logograms, no badges, no insignia, featureless garment panels`를
  양·음 프롬프트에 반영.
- 제독은 지휘 어깨선·비대칭 고칼라·흉부 구조, 관료는 정제된 비전투 수직 패널, 돌격병은
  전면 흉갑·견갑·전투용 하중 구조를 별도로 정의.
- 가장자리 연결 배경 마스크에 정확한 역할 틴트와 −18% 비네트를 적용. 원본과 후처리본 분리 보존.

## 4. 이미지별 판정

| 이미지 | 판정 | 근거 |
|---|---|---|
| FLUX C903 제독 | **재작업** | 높은 역사식 모자, 모자 문장과 흉부 가짜 문자/표식. 제독 어깨·칼라는 읽히나 금지 요소가 탈락 트리거 |
| FLUX C906 관료 | **재작업** | 역사식 관모가 지배적이고 미래 행정관보다 시대극 관료로 읽힘 |
| FLUX C910 돌격병 | **재작업** | 전면 장갑·견갑은 명확하나 머리 장식과 갑주 표식이 남고 역사 장수 인상이 강함 |
| SDXL C903 제독 | **재작업** | 얼굴 중심 역사 포의 소묘. 함대 지휘관의 어깨·칼라·흉부 구조가 없음 |
| SDXL C906 관료 | **재작업** | 전신 역사 유랑 무사 복식과 손의 무기. 상반신·비전투 행정관·얼굴 위치 기준 실패 |
| SDXL C910 돌격병 | **재작업** | 측면 역사 인물과 포의 중심. 전면 장갑·전투용 상체 구조 없음 |

320px 그레이스케일에서도 FLUX 3종의 외곽 차이는 남지만 모자가 계층 신호를 대신한다. SDXL은
세 역할 중 둘이 포의 중심으로 수렴해 제독/관료/돌격병 구분이 성립하지 않는다.

## 5. 당시 다음 의사결정 — V-50으로 대체됨

- **모델:** FLUX 단독으로 좁힘. 다만 품질 기준선 확정은 v4 통과 전까지 보류.
- **SDXL:** 신규 인물 제작 중단. 기존 비교 결과만 보존.
- **스타일:** v2 스타일 유지(발주자 판정). v3 화풍으로 교체하지 않음.
- **착용물·표식:** 역할에 맞는 관모·군모·두건·후드·왕관·헬멧·머리 장식과 가상 문자·표식 허용.
  실제 읽을 수 있는 현대 문구·서명·워터마크는 금지.
- **재시험:** 당시에는 FLUX v4 3장을 권고했으나 production v1 공용 11종 직접 승인으로 대체.
- **확장:** 공용 11종은 승인 완료. 명장 120명은 실제 UI 프레임 통합 검수 뒤 별도 승인.
