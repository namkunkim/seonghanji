## 3. G8-04 — 장수 부상·전사·포로

**상태: 미착수. 규칙·수치 없음.**

- G8-00 전투 효과는 함선 손실만 확정하고 장수 결과를 후속으로 미뤘다(`red-cliffs-combat-effects-rules.json` statement). G8-01~03(승패 판정)도 장수 결과를 만들지 않았다.
- G8-04는 결과 화면 작업이다(`demo-rc-completion-review-checklist.md` 「손실·장수·나포·계략·주요 턴·후일담」). 장수 판정 규칙은 그 전에 정해져야 한다.
- 캠페인 쪽에는 일기토 패배 시 포로·사망만 있다(`combat.md` §6.3).
- **POC에 대한 답:** `{조조_상태}`는 「기록되지 않았다」 고정을 유지한다. 실시간 쪽에서 장수 판정을 먼저 만들지 말 것 — 본편이 규칙을 정하면 알린다.
