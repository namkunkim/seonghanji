## 1. 결론

현재 제작 기준선은 **초상 131장(명장 120 + 일반 무장 공용 11), 코드 네이티브 UI,
BGM 6곡**이다. 권역 배경 45장, 일반 무장 개별 초상 189장, 기능 이벤트별 고유 삽화는
지금 제작하지 않는다.

첫 수직 슬라이스는 시나리오 3 「적벽 전야」의 ACT 3~9를 대상으로 한다. 공용 초상
11장과 핵심 명장 일부, L1 전투 표현, 지도·진형·함급 UI, BGM과 UI SFX만으로 구성한다.
3D 함선, 실시간 전투 VFX, 사전 렌더 영상은 수직 슬라이스에서 제외한다.

## 7. 제작 착수 금지 항목

- 권역별 배경 45장 — 화면 슬롯과 권역 지형 축이 없다.
- 일반 무장 개별 초상 189장 — V-43으로 폐기됐다.
- 기동병기·에이스·전투기 연출 — 대응 시스템이 미설계다.
- 무장 위성 방어 영상 — 독립 시스템인지 장식 연출인지 미확정이다.
- B10의 영상 11종 전부를 MP4로 만드는 작업 — 실시간 상태에 반응할 수 없다.
- 기능 이벤트 40종별 고유 삽화 — 슬롯·재사용 규칙·물량 예산이 없다.
- 프롤로그·막간·엔딩별 고유 배경 — 연출 화면 명세가 없다.
- 함선 3D 본제작 — L2 채택 전에는 후보 탐색 이상 진행하지 않는다.
- 초상 대량 생성 — 공용 11종으로 모델·해시·샘플러를 잠그기 전 진행하지 않는다.
- AI 영상 — 서비스 약관 5항목과 스토어 고지 방침 확정 전 진행하지 않는다.

## 8. 리스크와 검수 게이트

### 스타일 일관성

공용 11장으로 기준선을 잠근 뒤 명장 120장으로 넘어간다. 원본 100%뿐 아니라 실제 표시
크기인 약 320px와 48~64px에서 계층·성향·얼굴 식별성을 확인한다.

### 반복 생성과 후처리

시드, 프롬프트 조각, 모델 변종, 가중치 SHA-256, 샘플러·스텝·CFG를 매니페스트에 남긴다.
틴트·비네트·크롭·WebP 파생을 담당할 결정론적 후처리 도구가 대량 생성의 선행물이다.

### 라이선스와 법무

FLUX.1 schnell, SDXL, ACE-Step, CC0 후보는 채택 시점에 원문과 확인일을 기록한다.
상업 이용 허가와 저작권 귀속은 별개이며, 불명확한 사항은 **확인 필요**로 둔다.

### 오디오

루프 4곡은 사람이 마디 경계와 제로 크로싱을 확인한다. BGM과 SFX의 라우드니스 기준을
통합하고, 야간에는 배너 진동·소리가 나지 않는 정책과 연결한다.

### 기기 성능

초상 PNG는 마스터로 보관하고 APK에는 WebP q90 파생본을 사용한다. 영상은 실제 Android
태블릿에서 용량·디코딩·발열·메모리를 측정하기 전 출시 범위에 넣지 않는다.

1. 수직 슬라이스를 시나리오 3 ACT 3~9로 확정한다.
2. 핵심 명장 12~16명의 정확한 목록을 확정한다.
3. 원전 도상 준수와 SF 재해석의 경계를 확정한다.
4. 공용 초상 11종으로 SDXL/FLUX.1 schnell을 비교한다.
5. 모델·가중치 해시·샘플러·스텝·CFG를 잠근다.
6. 후처리의 틴트 교정/배경 재합성 방식을 결정한다.
7. UI 스타일 토큰과 기능 이벤트 6계열 악센트를 확정한다.
8. BGM 6곡과 UI SFX 20종의 제작·권리 기준을 확정한다.
9. L2 실시간 3D 채택 여부를 결정한다.
10. 기동병기와 무장 위성의 시스템 지위를 결정한다.
11. 마지막으로 컷씬 4종과 AI 영상 서비스를 결정한다.
