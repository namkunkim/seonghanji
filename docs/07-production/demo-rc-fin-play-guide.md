# 적벽대전 데모 — 목표 플레이 안내

> 최신화: 2026-09-10 · `MGMT-HANDOVER-01`
> 상태: 최신 요구사항 기준 목표 흐름. 현재 실행본의 구현 완료를 뜻하지 않는다.
> 요구사항 정본: [적벽 데모 요구사항 인터뷰](demo-rc-requirements-interview.md)

## 목표 플레이 흐름

1. 적벽대전 시나리오를 선택한다.
2. 역사적 위치·함대·전대·장수·함종 편성을 확인한다.
3. 역사적 기본 편성을 그대로 사용하거나 사용자 설정 메뉴에서 재편성한다.
4. 전투를 시작하고 유비군 전대·함대의 이동, 방향, 진형, 무기 사용 비율과 공격 대상을 정한다.
5. 턴 실행 뒤 손권 함대를 직접 제어할지 선택한다.
6. 수동이면 손권군 명령을 입력하고, 자동이면 손권 AI가 명령을 정한다.
7. 조조 AI를 포함한 이동·탐지·요격·전투 판정을 2D 연출로 확인한다.
8. 승패가 결정되지 않으면 다음 턴을 진행하고, 결정되면 결과 화면을 확인한다.

## 전술 지도 조작

- 전대 또는 함대를 클릭해 선택한다.
- 자유 좌표와 여러 경유점을 클릭해 이동 경로를 정한다.
- 하단 명령 패널에서 방향, 진형, 무기 비율, 목표와 사격 중지를 설정한다.
- 탐지되지 않은 적은 확정 정보로 표시하지 않는다. 마지막 확인 위치와 정보 신뢰도를 확인한다.
- 고속정은 잔여 연료, 비상 귀환 예상 턴과 자동 귀환 경로를 확인한다.
- 턴 결과 연출은 재생, 속도 변경, 건너뛰기를 사용할 수 있다.

## 함대·전대와 보급

- 모든 전대는 개별 지휘할 수 있으며 여러 전대를 함대로 묶어 함대 단위로 지휘할 수 있다.
- 전투 중 지휘 범위 안의 전대를 함대에 편입하거나 제외할 수 있으며 판정 뒤 적용된다.
- 보급함·강습모함·아군 거점의 자동 보급 영역에 들어가 한 턴을 유지하면 자동 보급된다.
- 고속정은 연료 부족 시 자동 귀환하며 도달 가능한 보급 영역이 없으면 표류한다.

## 저장과 결과

- 전투 중 언제든 수동 저장 3개를 사용할 수 있다.
- 턴 종료 자동 저장은 수동 저장을 덮어쓰지 않는다.
- 결과 화면에서 승리 조건, 손실, 지휘관 상태, 나포, 계략, 주요 턴과 연합 결과를 확인한다.
- 결과 화면이 데모의 종료점이며 새 전투, 저장 불러오기, 전투 기록 다시 보기를 제공한다.

## 현재 구현과의 관계

기존 소스 후보의 손권 플레이, 선행 역사 조건 선택, 수동 집결, 5페이즈 단일 진행, 홈 지도 복귀는 과거 구현 기준선이다. 최신 목표 흐름과 충돌하므로 구현 완료 또는 사용자 수용 증거로 사용하지 않는다.
