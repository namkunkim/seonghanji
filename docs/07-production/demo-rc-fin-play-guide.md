# 적벽 전투 체험판 — 현재 후보 실행 안내

## 실행본의 현재 수준

이 안내는 기존 Godot 엔진으로 **격리된 소스 프로젝트를 실행**하는 방법이다. Windows export template가 이 호스트에서 발견되지 않아 독립 배포용 exe/PCK는 아직 생성하지 못했다. 소스 실행을 배포 패키지 완성으로 취급하지 않는다.

현재 구현 후보는 `C:/WorkSpace/Seonghanji/tmp/demo-rc-fin-20260909`에 있다. 원래 프로젝트의 기존 미커밋 코드와 대형 자산 변경을 이 후보로 덮어쓰지 않았다. 여기서 말하는 체험 완료는 적벽 전투 구간의 완료이며 SCN-03 전체 ACT의 완성이 아니다.

## 이 컴퓨터에서 소스로 실행

아래 명령은 현재 설치된 Godot를 사용한다. **기존 Godot 사용자 데이터와 저장 슬롯을 공유할 수 있다.** 기존 저장을 보존하려면 격리 사용자 경로를 사용하는 검수 절차를 먼저 적용한다. 기존 저장 슬롯에 무심코 저장하지 않는다.

```powershell
& 'C:\Tools\Godot\Godot_v4.7.2-stable_win64.exe' --path 'C:\WorkSpace\Seonghanji\tmp\demo-rc-fin-20260909'
```

진입 장면은 `res://scenes/main.tscn`, 프로젝트 설정은 1600×900·Forward+다. 설정값 존재와 실제 화면/GPU 수용은 별개이며 실제 기기 가독성·성능은 아직 미수용이다. 엔진 경로 또는 소스 위치가 바뀌면 위 명령도 조정해야 한다.

## 처음 플레이하는 순서

1. 상단 **적벽/DEMO**를 열고 브리핑의 **선택 시작**을 누른다. 플레이어는 손권이며 다른 세력의 선택은 선행 역사 조건을 설정하는 과정이다.
2. 선행 선택을 완료한다. 적벽 발생 경로에서는 **집결 시작 · 시간 재개**를 누른다. 비발생 경로에서는 대체 전투 없이 조기 종료 이유와 판세 평가를 확인한다.
3. **적벽 집결** 임무에서 **함대 선택**을 누르고 이동 패널에서 구지(RGN-04)로 이동을 요청한다. 손권 함대는 실제로 이동해야 한다. 조조 참가자는 체험판 전용 초기 배치로 구지에 배치된다.
4. 기본 배속은 ×4다. 손권의 합법 이동은 45틱으로, ×4 기준 약 12분의 집결 시간을 예상한다. 상단과 전투 내부에서 일시정지·재개·×1/×2/×4를 조절한다. 시험용 시간 가속은 제품 조작법이 아니다.
5. 개전 안내로 전투에 들어가 손권/손유 측의 진형·페이즈·AI 위임을 조작한다. 전투 화면의 시간 제어로 명령 적용을 재개할 수 있다.
6. 결착 뒤 전투 사실과 **결착 시점 판세 평가**를 확인한다. 전투 승리와 캠페인 목표·천하 통일은 같은 의미가 아니다. 결과를 닫아도 상단 **결과**에서 다시 열 수 있다.
7. **새 체험 시작 · 현재 진행 교체**는 현재 진행을 새로 시작한다. 수동 저장 슬롯을 자동으로 덮어쓰지 않는다.

## 저장·이어하기·설정

- 상단 **저장/이어**에서 단일 수동 슬롯을 사용한다. 파일은 `user://demo-rc-slot-1.json`이다. 자동 저장은 없다.
- 저장 성공 안내를 확인한 뒤 종료한다. 이어하기는 검증에 성공한 저장만 반영하고, 실패하면 현재 진행을 유지한다.
- 이어하기 성공 직후는 안전을 위해 일시정지 상태다. 시간 재개를 눌러 진행한다.
- 설정에서 도움말·크레딧/출처·음량·음소거를 확인한다. 초기 음량은 35%이며 최소 합성 피드백만 제공한다. BGM·보이스는 이번 범위가 아니다.
- 전투의 **천하도로 돌아가기**, 결과의 **천하도로**로 홈에 복귀한다. 앱 자체는 창을 닫아 종료한다.

## 저장 호환 범위

현재 UI는 검증된 `ok` 상태의 저장을 수용한다. 코어가 구 minor 규칙셋을 구별하더라도 UI에서 자동 이관·불완전 복원을 약속하지 않는다. 알려지지 않은 데모 프로필 ID/버전 또는 손권 역할 계약 위반은 로드를 거부한다.

과거 side 없는 명령의 재생 의미를 보존하는 시험은 있지만, **이전 빌드가 실제 생성한 보관 저장 파일과의 호환은 아직 입증되지 않았다.** 중요한 기존 저장은 별도 보존한다.

## 아직 완료로 주장하지 않는 항목

- 독립 배포용 Windows 패키지와 깨끗한 대상 PC 실행.
- 실제 GPU 화면, 1600×900·OS 배율별 가독성 및 성능 측정.
- 처음 접하는 사람의 무힌트 완주와 물리 입력 관찰.
- 모든 필수 플레이 매트릭스의 최종 수용. 최신 자동시험 결과는 진행 기록과 QA 증거를 따른다.

전투는 의도적으로 정지 이미지와 상태 HUD를 사용한다. 실제 플레이 중 막힌 위치·안내 문구·다음 행동의 이해 여부는 이후 사람 검수 체크리스트에 기록한다.
