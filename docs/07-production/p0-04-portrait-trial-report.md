## 1. 결론

- 모델 기준선 잠금: **불가**. 두 모델 모두 배치 공통 트리거인 계층 틴트·실루엣 구분을 통과하지 못했다.
- 공용 11종 최종화: **불가**. 22장 전부 `재작업`; 사용자 승인 전 채택하지 않는다.
- 명장 120명 배치 전환: **불가**. R-13·R-18·R-19·R-20 해소 전 P0-07/P0-08을 진행하지 않는다.
- 현재 선도 후보: **FLUX.1 [schnell]**. 삼국지적 얼굴+SF 복식 결합과 구도 일관성은 SDXL보다 낫지만,
  가짜 문자·군모·틴트 문제를 먼저 해결해야 한다. 이는 모델 확정이 아니라 다음 시험의 권장 출발점이다.

## 4. §8 열 개 판정 축 적용

코드: `P` 통과, `R` 재작업, `D` 사용자/3인 검수 결정 필요, `N` 초상에 직접 적용 불가.
초상은 지도·함선용 축도 임의 삭제하지 않고 적용성 `N`으로 기록했다.

| 축 | FLUX 배치 | SDXL 배치 | 근거 |
|---:|---|---|---|
| 1 정보 판독 | N | N | 항로·회랑·보급을 담지 않는 초상 |
| 2 인간 전쟁 | P | P | 외계 종족·생물 표현 없음 |
| 3 프랜차이즈 비연상 | D | D | 규정상 최소 3인·2인 이상 일치 필요; 현재 단독 검수로 확정 금지 |
| 4 장르 양립 | R | R | FLUX 일부는 현대 군복·군모, SDXL 다수는 역사 복식만 보여 SF×삼국지 양립 실패 |
| 5 색각 이중 부호화 | R | R | 흑백 320px에서 계층 틴트가 사라지고 클래스 실루엣이 반복됨 |
| 6 한국어 우선 | R | P | FLUX 다수의 가짜 한자·문장·서명 발생; SDXL은 문자 없음 |
| 7 규모 정합 | N | N | 함종·전대 규모를 담지 않는 초상 |
| 8 전투 서사 | N | N | 전투 장면이 아닌 초상 |

## 6. 모델 비교와 권장안

| 항목 | FLUX.1 [schnell] | SDXL 1.0 |
|---|---|---|
| 장점 | 얼굴 시대감과 SF 복식 결합, 정면 구도 일관성, 빠른 4-step 생성 | 얼굴 질감·수염 디테일, 가짜 문자 억제, 일부 갑주 재질 |
| 단점 | 서명·한자형 문장, 현대 군모, 동일 얼굴/복식 반복, 정확한 HEX 틴트 실패 | 역사 복식으로 강하게 회귀, 전신·소묘 구도 이탈, 클래스별 SF 실루엣 약함 |
| 다음 시험 | 선도 후보. 문장·계급장·모자 요소를 완전 제거하고 배경 틴트를 후처리로 고정 | 보조 비교 후보. 포즈/크롭/의상을 구조 제어하지 않으면 기준선 부적합 |

권장 다음 시험은 **시드 고정 3종(C903·C906·C910) × 두 모델 = 6장**이다. 생성 프롬프트에서 배경색을
모델에 맡기지 않고 후처리로 정확히 합성하며, `no badges, no insignia, no logograms, featureless garment panels`를
추가한다. 클래스마다 어깨·칼라·흉부 외곽의 형태 언어를 먼저 정의한 뒤 색 이외의 구분을 검증한다.

## 7. 라이선스·원장 상태

`판정 → 확보 → 검증` 체계에서 현재 상태는 다음과 같다.

- 판정: FLUX Apache-2.0, SDXL OpenRAIL++ 사용 가능성 확인.
- 확보: 가중치 6개·워크플로 2개·시험 PNG 22개·프롬프트/시드/출력 해시 확보.
- 검증: 모델 라이선스와 파일 무결성은 검증 완료. **자산 품질 검증은 재작업**, 프랜차이즈 축은 3인 검수 전 `결정 필요`.
- 최종 에셋 원장의 ART-C901~C911 상태는 바꾸지 않는다. 시험 산출물 확보를 최종 채택으로 간주하지 않는다.
