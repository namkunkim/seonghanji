# DEMO-RC-LT-02 — 적벽대전 단편 시작·턴 전투·결과 루프

> 최신화: 2026-09-10 · `MGMT-HANDOVER-01`
> 요구사항 정본: `docs/07-production/demo-rc-requirements-interview.md`

## 범위

`SCN-03` 적벽 데모는 선행 Event 03·04·06·07 선택과 수동 집결을 생략하고 역사적 전투 준비 상태에서 시작한다. 플레이어는 유비다. 역사적 기본 편성과 사용자 재편성 메뉴를 제공하고, 편성 확정 뒤 2D 턴제 전투로 진입한다.

## 상태 흐름

```text
시나리오 선택
→ 역사적 전투 준비·사용자 편성
→ 유비 명령
→ 손권 수동 제어 문의
→ 손권 수동 명령 또는 손권 AI
→ 조조 AI 포함 턴 판정
→ 매 턴 승리 조건 검사
→ 다음 턴 또는 결과 화면
```

접적·포화·교전·강습·결착은 매 턴의 판정 단계다. 전투는 최대 20턴이며 결과 화면에서 데모가 끝난다. 적벽 미발생 DEC-01 분기와 캠페인 종료 형 판정은 이 단편 데모의 플레이 경로가 아니다.

## 저장

전투 준비, 유비 명령, 손권 문의, 손권 수동 명령과 판정 뒤 상태를 저장·복원할 수 있어야 한다. 수동 저장 3개와 별도 턴 종료 자동 저장을 사용한다.

## 기존 구현 기준선

기존 선행 선택→수동 집결→pending→active→5 phase→캠페인 결과 적용 흐름과 관련 시험 결과는 과거 구현 증거로 보존한다. 최신 목표와 충돌하므로 새 완료 판정에 그대로 사용하지 않는다.
