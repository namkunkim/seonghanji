# A-05-03 — 지형 강제 및 진형 변경 상태기계

상태: PASS (2026-09-07)

이동 명령이 `Orders.resolve_move`로 확정한 최악 지형을 `Fleet.encounter_terrain`에 동결한다. 일반 전투는 이를 재추론하지 않으며, 대회랑은 장사진을 강제하고 기저·중회랑의 금지 진형은 코어에서 하향/거부한다.
