## 1. 「영상」의 정의 — 나머지 전부의 선행 (D1) · **확정: C 혼합 (2026-08-30, 발주자)**

> **D1 = C.** §3~§4는 이제 잠정이 아니라 확정 전제다. §5의 D2~D7만 P0-09 잔여.

### 1.1 문제

발주자 요구 B10은 **「영상 11종」**이라 적었고(`requirements.md`), `DECISIONS.md` **V-26**은
전투 표현을 **L1(2D 인게임) / L2(실시간 3D) / L3(사전 렌더 컷씬)** 세 계층으로 갈랐다.
`asset-ledger.md` §5.2의 배정과 `roadmap-solo.md`는 **후자(계층)를 전제**한다.
이 간극이 닫히지 않으면 §3 이하가 전부 잠정이다(`asset-ledger.md` §5.6-② · 검토 7).

### 1.2 세 해석

| 안 | 뜻 | 전투 결과에 반응하는가 | 드는 자원 | 평가 |
|---|---|---|---|---|
| **A. 사전 렌더 mp4 전면** | 전투 연출까지 고정 영상 파일 | **못 한다.** 진형 7종·함종 6종·5페이즈·계략이 매번 다른데 영상은 고정 → **관전이 아니라 배경 영상** | L3 인코딩·용량만 | `visual-direction-guide.md` §3·§5.3과 정면 충돌. 전투 규칙의 시각화 실패 |
| **B. 실시간 3D 전면** | 모든 연출을 엔진 내 실시간 렌더 | 완전 반응 | **L2 자원 전량** — 함선 3D 6종 조달(R-16) · VFX 9종 · 카메라 연출 · 10주+(실측 12~13주) | **1인 개발 최대 위험**(R-15 · `roadmap-solo.md` §0.2) |
| **C. 혼합 (권고)** | **L1** = 2D·UI 인게임 연출(반응형) · **L2** = 실시간 3D(선택) · **L3** = 사전 렌더 컷씬(결과에 반응할 필요 없는 극적 순간만) | 계층별 | 로드맵·대장 §5가 이미 전제. L1만으로 상품 성립 | ✅ |

### 1.3 권고 — C(혼합)

근거 셋:

1. **전투 연출은 반드시 반응형이어야 한다.** `visual-direction-guide.md` §3-2는
   「폭발을 끄거나 정지 화면으로 보아도 현재 페이즈·양측 사기·보급·진형·다음 결정이
   남아야 한다」고 못 박았다. 고정 mp4로는 불가능하다 → **A 배제.**
2. **L1만으로 상품이 성립한다**(V-26). 실시간 3D를 전제로 깔면 필수 L1·콘텐츠·QA가
   선택 연출에 밀린다(R-15) → **B는 「전면」이 아니라 「선택」이어야 한다.**
3. **L3 컷씬이 정당한 자리가 따로 있다.** 행성 점령·함선 수리·함선 대파는 전투 판정의
   분기에 반응할 필요가 없는 **결과 장면**이다(`asset-ledger.md` §5.5). 여기서는 고정
   영상이 옳다.

> **발주자 확인 질문(D1):** 「영상」을 **혼합(C)** 으로 확정하는가?
> A/B로 확정되면 §3~§4를 전면 재계산한다.

### 3.5 기능 이벤트 연출 — 40종 중 영상이 필요한 것 선별

**판정: 40종 전부 영상(mp4·실시간 3D)이 필요 없다. 정지 화면 + 텍스트로 성립한다.**

근거 셋:

1. **【연출】이 전부 「화면 구성」만 적었다.** 「조정. 빈 자리가 많다」 · 「수레 행렬. 밤.
   호위의 수가 적다」 · 「상선의 행렬. 흰 옷. 강 위. 야간」. `event-scripts.md` §8 검토 6이
   「【연출】은 화면 구성만 적었다. 음악·효과음·전환은 아트/사운드 방향이 정해진
   뒤에야 붙는다」고 명시했다.
2. **텍스트가 본체다.** [FIXED]·[LIKELY]·[CHOICE] 세 화법(§0.3)과 ②차등 삽입 한 행이
   이벤트를 만든다. 연출은 그 텍스트를 얹을 배경일 뿐이다.
3. **반복 노출**(`event-scripts.md` §7.5). `[F-37]` 회당 16.5회 · `[F-25]` 15.7회 ·
   `[F-13]` 10.0회 · `[F-07]` 10.0회. 영상이면 반복이 더 큰 소음이 된다. **정지 화면이 옳다.**
4. **P0-02가 같은 결론을 냈다.** `preproduction-scope.md` §109 — 필수 이벤트 9종의
   에셋은 「이벤트 전용 일러스트 = 해당 없음. 텍스트 + UI 연출만」이다.

| 항목 | 내용 |
|---|---|
| 목적 | 압력 구조를 텍스트로 전달할 때의 배경 화면 |
| 물량 | 이벤트 카드 **템플릿 1** + 분류부(PART A~F 6군)별 배경 **6~12장.** 개별 40장이 아니다 |
| 제작 방식 | 카드 배경 = 계층 틴트 + 아이콘/실루엣(`ai-media-pipeline.md` §4.1 초상 규격·틴트 5색 재사용) 또는 소수 키 정지 이미지(AI, RunPod). **L1**(자작 조립) / 조건부 AI 정지 이미지 |

| 계층 | **L1** |
| 전투 직결 이벤트 | `[F-16]` 관문 도박 공세 · `[F-19]` 비대칭 결전(화공) · `[F-20]` 비인접 침투는 전투 5페이즈 연출(§3.6)로 흡수한다. **별도 컷씬을 만들지 않는다** |
