# 적벽 체험판 시나리오·결과 표현 계약

> 작성: 2026-09-10 · 조율자 결정
> 적용: [자율 진행 기록](demo-rc-overnight-execution.md)의 Windows 전투 체험판
> 정본: [엔딩 §5.2](../04-campaign/endings.md) · [오 계열 후일담](../05-narrative/ending-variations.md)
> 본 문서는 구현 계약이며 실제 제품 적용·검수 완료를 의미하지 않는다.

## 1. 시점과 플레이어

제목은 ‘적벽 전야 — 전투 체험판’으로 한다. 플레이어는 손권이며, 전투에서 조작하는 진영은 손유 연합이다. 선행 사건 선택은 여러 세력의 역사 조건을 정하는 체험판 장치다.

브리핑 설명:

> 이번 체험판에서는 적벽 전야의 역사 조건을 고른 뒤, 손권의 함대를 지휘합니다. 참가 함대를 구지로 집결시키고 전투를 마무리하십시오. 적벽의 조건이 성립하지 않으면 조기 종료됩니다.

선택 영역의 보조 제목은 ‘선행 역사 조건 설정’으로 한다. 사건 제목에서 조조·유비 등 선택 주체를 구별한다. 권장 선택은 전투 경로를 보여주기 위한 안내이며 자동 선택이 아니다.

## 2. 종료 표현

| 코어 사실 | 제목 | 결과 성격 | 보조 설명 |
|---|---|---|---|
| 적벽 resolved 및 캠페인 결과 적용 | 적벽 전투 체험 완료 | 결착 시점 판세 평가 | 전투 체험 구간이 끝났습니다. 형주 분배 이후의 전체 시나리오는 이번 체험판에 포함되지 않습니다. |
| DEC-01 종료 | 적벽 미발생 — 시나리오 조기 종료 | 조기 종료 시점 판세 평가 | 선택한 선행 조건에서 적벽이 발생하지 않았습니다. 대체 전투 없이 조기 종료 당시 상태로 판정합니다. |
| 필수 참가자 소실/철수 등 취소 | 집결을 계속할 수 없습니다 | 진행 중단 | 해당 코어 사유와 새 데모/홈 복귀 행동을 표시합니다. 이를 승전이나 정규 엔딩으로 표현하지 않습니다. |

전투 승패와 플레이어 목표, 세계의 판세는 각각 표시한다. ‘전투 승리’가 곧 ‘통일 달성’은 아니며 손권의 병립 목표를 실패로 취급하지 않는다.

## 3. 결과 판정 데이터의 소유

코어의 읽기 전용 결과 투영이 다음 사실을 제공한다. 최종 함수/필드명은 코어 담당이 UI 담당에게 고정해 전달한다.

- 결과 가용 여부와 종류: 전투 체험 완료 / DEC-01 / 취소.
- 플레이어 진영, 전투 승자, 결과 적용 여부, 코어 종료 사유.
- 판정 시점 tick, 세계 상태, 플레이어 천명, 플레이어 존속/목표 여부.
- `ending_id`: Mandate / Hegemony / Division / Fragmentation / Extinction.
- 발생 조건별 충족 여부와 플레이어 선택 요약.

판정 규칙은 §5.2를 따른다. 플레이어 세력 소멸이면 Extinction. 그 외 일극형은 통합, 나머지 형은 병립이며 천명 70 이상/미만으로 네 사분면을 구분한다. 화면은 이 값을 자체 계산하지 않는다. 결과는 전투 결과 적용 또는 DEC-01 전이 시점에 코어가 고정하고 저장 재생으로 복원한다. 재열람 시에도 ‘결착 시점 판세 평가’ 또는 ‘조기 종료 시점 판세 평가’로 표시한다. 이후 캠페인의 현재 상태 및 미래 전체 캠페인 결과와 구분한다.

코어 모델에 없거나 판정하지 않은 사실을 표시용 서사로 만들어 넣지 않는다. 실제 발생하지 않은 영토 획득·동맹 변화·황제 처우를 결말에 주장하지 않는다.

## 4. 결과 설명과 정본 후일담

| 판정 | 짧은 시스템 설명 |
|---|---|
| Mandate | 당시 판세는 통합이며 천명이 정통성 기준에 도달했습니다. |
| Hegemony | 당시 판세는 통합이지만 천명이 정통성 기준에 미달합니다. |
| Division | 여러 세력이 병립하고 천명이 정통성 기준에 도달했습니다. 병립은 손권에게 정당한 목표입니다. |
| Fragmentation | 여러 세력이 병립하지만 천명이 정통성 기준에 미달합니다. |
| Extinction | 플레이어 세력이 소멸해 절사로 판정합니다. |

기존 `ending-variations.md` 오 계열 §3.1~3.4와 `epilogues.md` 기본 절사 원문을 후일담 출처로 사용한다. 체험 완료 화면에서 미래의 창업·왕조 존속을 실제 결과로 단정하지 않도록, 제공할 경우 ‘이 판세에 대응하는 정본 후일담 미리보기’라고 명시한다. DEC-01도 직접 구현되지 않은 사건을 덧붙인 새 후일담을 쓰지 않는다.

이번 구현에서는 짧은 판정 설명을 우선 제공하고 정본 후일담은 별도 읽기 패널로 분리한다. 전문을 포함할 경우 원문의 문단을 임의 축약·재창작하지 않고 출처를 기록한다. 후일담 패널이 미구현이면 체크리스트 G6-04를 완전히 수용하지 않는다.

## 5. 사용자 행동

결과 화면에는 ‘천하도로’, ‘새 체험 시작’, 저장이 유효한 경우 ‘저장’이 제공돼야 한다. 홈으로 돌아가도 ‘결과 보기’로 해당 평가를 다시 읽을 수 있다. resolved 전투의 전술 명령을 재개하는 방식으로 결과를 다시 보여주지 않는다.

새 체험은 기존 상태를 교체하므로 진행 중인 기록을 잃을 수 있음을 표시한다. 수동 저장 슬롯은 새 체험을 시작했다는 이유로 자동 덮어쓰지 않는다.

## 검토 포인트

- 별도 데모 초기 프로필 채택 시 고정 배치와 선행 역사 조건의 연대가 모순되지 않는지 검토한다.
- 현재 세계 상태 판정과 실제 목표 함수의 차이는 오류처럼 숨기지 않고 서로 다른 의미로 표시한다.
- 정본 후일담의 미래 시점은 체험 구간 완료와 구분한다.
