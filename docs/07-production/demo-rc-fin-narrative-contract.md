# 적벽대전 데모 시나리오·결과 표현 계약

> 최신화: 2026-09-10 · `MGMT-HANDOVER-01`
> 요구사항 정본: [적벽 데모 요구사항 인터뷰](demo-rc-requirements-interview.md)
> 본 문서는 목표 계약이며 현재 제품 적용 완료를 뜻하지 않는다.

## 1. 시점과 플레이어

제목은 ‘적벽대전’으로 한다. 플레이어는 유비이며 손권과 조조는 AI다. 선행 외교 사건이나 장거리 집결을 선택하지 않고, 역사적 참가자와 함대가 전투 준비를 마친 시점에서 시작한다.

브리핑은 유비군의 생존이 연합 결과에 직접 연결되고, 손권군은 매 턴 수동 제어 여부를 선택할 수 있음을 설명한다. 역사적 기본 편성을 권장하되 사용자 설정 메뉴를 제공한다.

## 2. 전투 중 표현

- 장수 대화는 초상과 한글 텍스트로 제공하며 음성 연기는 사용하지 않는다.
- 유비군 명령 단계, 손권 수동 문의, 손권 수동·자동 상태, 조조 AI 판정 상태를 분명히 구분한다.
- 탐지 정보의 확실성과 마지막 확인 위치를 사실처럼 과장하지 않는다.
- 연쇄 폭발 작전은 SF 화공으로 표현하며 발동 조건과 결과를 전투 기록에 남긴다.
- 3D 함선·3D 시네마틱 대신 정지 이미지와 2D 전투 효과를 사용한다.

## 3. 결과 판정 표현

| 판정 | 결과 제목 | 필수 설명 |
|---|---|---|
| 연합군 승리 | 적벽대전 — 연합군 승리 | 충족한 승리 조건과 유비군·손권군 상태 |
| 제한적 연합군 승리 | 적벽대전 — 제한적 승리 | 유비 기함과 필수 전대의 탈출 및 잔존 전력 |
| 조조군 승리 | 적벽대전 — 조조군 승리 | 연합 패배 조건 또는 동시 조건 우선 판정 |
| 20턴 판정 | 적벽대전 — 잔존 전력 판정 | 양측 시작 대비 잔존 코스트 비율과 동률 규칙 |

유비로 플레이하지만 일반 전투 결과는 손유 연합 단위로 판정한다. 유비 기함 파괴, 유비군 70% 이상 손실 또는 사기 붕괴·항복은 연합군 패배다. 상반된 조건이 같은 턴에 성립하면 조조군 승리다.

## 4. 결과 화면 정보

- 실제로 충족한 승리·패배 조건
- 양측 함선 손실, 잔존 코스트와 나포 함선
- 생존·부상·사망·포로 장수
- 발동 계략, 연쇄 폭발 작전과 주요 턴
- 유비군 개별 결과와 손유 연합 결과
- 전투 상태 평가와 해당 결과의 후일담

실제로 발생하지 않은 영토 획득, 동맹 변화, 황제 처우나 천하 통일을 결과로 단정하지 않는다.

## 5. 종료 행동

결과 화면이 1차 데모의 종료점이다. ‘새 전투’, ‘저장 불러오기’, ‘전투 기록 다시 보기’를 제공한다. 홈 지도 또는 후속 캠페인 복귀, 나포 함선의 전투 후 재사용은 이번 데모에 포함하지 않는다.
