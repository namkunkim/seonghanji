# Q-05-02 — 검산기 자동 실패 판정 및 음성 시험 보강

Task ID: Q-05-02
공식 제목: 검산기 자동 실패 판정 및 음성 시험 보강

네 검산기는 `tests/harness.gd`의 `EXIT_PASS`/`EXIT_FAIL` 계약을 사용한다. 모두 전체 항목을 끝까지 검사한 뒤 누적 실패가 있으면 `1`로 종료한다.

- `verify_power.gd`: 세력별 국력 편차, 누락 성계·권역, 권역 총계 45를 누적 보고한다.
- `verify_budget.gd`: 모든 세력의 수입·행정비·잔여를 계속 대조한다.
- `verify_chibi.gd`: 5개 페이즈 계수, 간파·위장 항복·화공 및 네 갈래 확률, 세 분기별 페이즈 사기·잔존 함선·붕괴율을 검산한다. `EXPECTED_*` 수치는 새로 만든 시험 fixture가 아니라 기존 `combat.md §4.3·§5.3~§5.7`의 2.20배 잠금 기준과 현행 Battle/Scheme 정수 산식을 재실행해 전사한 정본값이다.
- `verify_glyphs.gd`: 폰트 굵기, 한글 11,172자, app 코퍼스 누락을 보고한다. 시스템 폴백 전용 기호는 경고이며 경성 실패가 아니다.

음성 검증은 원본 정본을 바꾸지 않는 임시 사본에서 수행한다. 예를 들어 `verify_chibi.gd`의 `EXPECTED_SCHEMES["화공 (주유 · 밀집)"]`를 1만 변경해 실행하면 나머지 계략·분기 검사를 출력한 후 exit 1이어야 한다. 같은 방식으로 power의 `doc` 또는 budget의 `DOC` fixture를 변경해 exit 1을 검증한다.
