# DEMO-RC-04 — 적벽 전술 지도 및 3D 증거창

`RedCliffBattleView`는 1600×900 기준에서 좌측 2 비율의 전술 지도와 우측 1 비율의 실시간 전장 뷰를 배치한다. 지도는 한 `ActiveBattle` 상태에서 페이즈, 양측 함선 수·사기, 궤도·교전권·점령 목표, 곡선 이동 경로와 함대 쐐기 전열을 그린다.

우측은 프로젝트 전용 원본 자산 `assets/ui-mockups/red-cliffs-live-battle-v1.png`를 aspect-cover 방식으로 렌더하고, LIVE pulse·전황 ticker·함대 식별 tag·양측 함선/사기 bar를 코어 상태로 갱신한다. 배경 자산은 첨부 레퍼런스의 영화적 밀도와 냉청색/적색 대립만 참고했으며 글자·로고·함선 디자인·정확한 배치를 복제하지 않았다. 이 계층은 전투 판정을 하지 않으며 코어 상태의 시각적 증거다. 버튼은 46px 이상으로 마우스·키보드·터치 입력을 지원한다.

초기 prototype의 procedural `BoxMesh` 전투 뷰는 폐기됐다. 최종 1600×900 캡처에서는 하단 명령 덱 잘림 없이 2:1 화면 비율, 한글 glyph, 지도/전장 상태 동기화를 확인했다.
