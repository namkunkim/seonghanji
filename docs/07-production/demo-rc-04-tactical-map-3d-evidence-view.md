# DEMO-RC-04 — 적벽 전술 지도 및 3D 증거창

`RedCliffBattleView`는 1600×900 기준에서 좌측 2 비율의 전술 지도와 우측 1 비율의 실시간 전장 뷰를 배치한다. 지도는 한 `ActiveBattle` 상태에서 페이즈, 양측 함선 수·사기, 궤도·교전권·점령 목표, 곡선 이동 경로와 함대 쐐기 전열을 그린다.

우측은 실제 `SubViewport`/`Node3D` 전장이다. 코드 생성 다단 장갑 주력함과 호위함, 엔진 발광·트레일, 사격선·피격광, 별 깊이장과 이동 카메라가 매 프레임 움직이며 페이즈가 오를수록 편대 간격·사격·폭발 밀도가 변한다. 함선 수와 사기는 `ActiveBattle`만 읽으며 0척 진영은 즉시 3D 편대에서 사라진다. `tests/test_demo_rc_03_04.gd`가 양측 0척 및 단일 진영 잔존 경계를 회귀 고정한다.

후방 `assets/ui-mockups/red-cliffs-orbital-backdrop-v1.png`는 함선·무기·폭발이 전혀 없는 행성/성운 환경판으로만 쓰인다. 따라서 배경이 코어 함선 수와 모순하지 않으며, 양측 전력·사기 HUD도 같은 코어 상태를 표시한다. 이 계층은 전투 판정을 하지 않는 시각적 증거 계층이다. 버튼은 46px 이상으로 마우스·키보드·터치 입력을 지원한다.

초기 정적 원화 전투 뷰는 폐기됐다. 최종 1600×900 GPU 캡처에서는 하단 명령 덱 잘림 없이 2:1 화면 비율, 한글 glyph, 지도/3D 전장 상태 동기화를 확인했다.
