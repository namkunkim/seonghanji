## 3D 경계

- 3D는 실제 적벽 20턴 전투 화면 안의 읽기 전용 공간 증거 계층이다. 별도 미니게임이나 명령 입력 화면이 아니다.
- renderer는 `viewer_3d_projection` DTO만 받고 battle controller, raw snapshot, authoritative receipt를 받지 않는다.
- 미탐지 적은 0개, 추정 접촉은 부정확한 proxy, 확인 접촉도 적 정확 함급·척수·HP·방향을 표시하지 않는다.
- 3D가 코어 상태를 변경하거나 자체 공격·피해·승패·무작위 사건을 만들지 않는다. L3 사전 렌더 시네마틱은 범위 밖이다.

## 기본 화면

- 기준 해상도는 Windows 1600×900이며 필수 조작은 마우스로 완수할 수 있어야 한다.
- 기본 중앙 화면은 2D 전술 지도 2/3과 3D 증거창 1/3이다. 3D 확대와 Esc 복귀가 가능하되 명령 접근성을 유지한다.
- 지도에서 전대·함대를 선택하고 자유 좌표와 다중 경유점을 클릭해 이동 경로를 설정한다.
- 하단 명령 패널에서 방향, 진형, 무기별 사용 비율, 공격 대상, 사격 중지와 함대 편입·제외를 설정한다.
- 지도 표식은 위에서 본 함선 이미지와 진형 실루엣을 사용하고, 3D는 같은 공개 위치·방향·진형·편성·상태를 공간적으로 보강한다.

## 정보와 전쟁 안개

- 탐지 밖 적은 숨기거나 부정확하게 표시한다. 탐지 상실 뒤에는 마지막 확인 위치와 확인 턴을 표시한다.
- 마지막 확인 위치에 추정 사격할 수 있으나 명중 불이익을 적용한다.
- 정보 신뢰도에 따라 적 예상 이동과 위협 범위를 구분해 표시한다.
- 성운, 잔해, 행성 그림자는 이동·탐지·무기 판정에 미치는 효과와 함께 지도에 표시한다.
- 고속정은 잔여 연료, 비상 귀환 예상 턴, 자동 귀환 경로와 보급 영역을 표시한다.

## 2D·3D 전투 연출

- 턴 판정은 이동, 사격선, 유도탄·함재기, 피격, 폭발, 발광, 화면 이동·확대 효과로 재생한다.
- 재생, 속도 변경, 건너뛰기를 모두 제공한다.
- 배경은 어두운 우주와 세력색을 사용하고 동양적 문양은 UI 테두리와 세력 문장에 절제해 사용한다.
- 색상만으로 상태를 구분하지 않고 아이콘·문자·형태를 함께 사용한다.
- 첫 실행 튜토리얼은 즉시 건너뛸 수 있으며 설정에서 다시 열 수 있다.

과거의 단일 우측 정지 이미지 증거창과 네 개 시각 표식은 구현 이력이다. 현재 완료 조건은 canonical 2D 명령 지도와 viewer-safe 3D 증거창의 일치이며, UX 디자이너와 독립 리뷰어가 정보 계층, 입력, 가독성, 상태 피드백과 모델 방향·재질·크기 일관성을 검증한다.
