# DEMO-RC-04 — 적벽 전술 지도 및 3D 증거창

`RedCliffBattleView`는 1600×900 기준에서 좌측 2 비율의 전술 지도와 우측 1 비율의 3D 증거창을 배치한다. 지도는 한 `ActiveBattle` 상태에서 페이즈, 양측 함선 수·사기와 교전선을 그린다.

우측은 외부 자산을 사용하지 않는 Godot `BoxMesh` primitive 4개와 조명·카메라로 만든 prototype 증거 표현이다. 빨강은 조조측, 파랑은 손권·유비측이다. 이는 전투 판정을 하지 않으며, 코어 상태의 시각적 증거일 뿐이다. 버튼은 48px 높이로 마우스·키보드·터치 입력을 함께 지원한다.
