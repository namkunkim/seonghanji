# DEMO-RC-04 — 적벽 전술 지도 및 정지 이미지 증거창

`RedCliffBattleView`는 1600×900 기준에서 좌측 2 비율의 전술 지도와 우측 1 비율의 전투 기록 이미지를 배치한다. 지도는 한 `ActiveBattle` 상태에서 페이즈, 양측 함선 수·사기, 궤도·교전권·점령 목표, 곡선 이동 경로와 함대 쐐기 전열을 그린다. 함대 전열은 페이즈 1~5 진행도에 따라 베지어 항로를 따라 목표로 접근하며, 항로 표식은 연속 이동한다. 페이즈 2부터 교전 링과 사격선, 페이즈 3부터 폭발 신호가 단계적으로 추가된다. 이 움직임은 표시 연출이며 코어 전투 판정을 변경하지 않는다.

2026-09-09 발주자 지시에 따라 별도 지시 전까지 실시간 3D는 사용하지 않는다. 우측은 `red-cliffs-live-battle-v1.png` 한 장을 `TextureRect`로 표시하며 `SubViewport`, 3D 함선, 카메라 및 프레임 애니메이션을 생성하지 않는다. 페이즈와 양측 함선 수·사기는 이미지 위의 읽기 전용 HUD만 `ActiveBattle` 상태로 갱신한다. `tests/test_demo_rc_03_04.gd`가 이미지가 정확히 한 장이고 3D viewport가 없으며 0척 상태도 HUD에 반영됨을 회귀 고정한다.

정지 이미지는 분위기와 전장 맥락만 제공한다. 현재 함선 수·사기·페이즈의 권위는 이미지가 아니라 겹쳐 표시되는 코어 HUD와 좌측 전술 지도에 있다. 이 계층은 전투 판정을 하지 않는다. 버튼은 46px 이상으로 마우스·키보드·터치 입력을 지원한다.

향후 구현 집중도는 좌측 전술 지도, 명령 가독성, 페이즈별 상태 변화와 플레이 피드백에 우선 배분한다. `tests/test_demo_rc_03_04.gd`는 페이즈가 오를수록 함대가 목표에 가까워지고 전술 애니메이션 시계가 계속 전진함을 검증한다. 실시간 3D 재개는 발주자의 별도 지시가 있을 때만 진행한다.

전술 지도 아래의 `PhaseBattleReport`는 가장 최근에 완료된 페이즈, 양측 함선 손실, 사기 증감, 계략 발생 수를 한 줄에 표시한다. 명령 버튼은 내부 action ID 대신 한국어 명령명과 다음 전역 틱 반영 시점을 피드백한다. 이 정보도 `ActiveBattle.phase_results`와 공개 명령 영수증만 소비한다.

보고 패널의 두 번째 줄은 현재 페이즈별 작전 지침을 표시한다. 접적은 경로 점검, 포화는 사기·전열 압박, 교전은 진형 상성·잔존 전력, 강습은 붕괴 측면·지휘선, 결착은 잔존 전력 집중을 안내한다. AI 위임 중에는 같은 줄에 위임 상태를 명시한다. 지침은 설명 문구이며 새로운 판정값이나 승률 예측을 만들지 않는다.

상단 위군 전력 카드는 현재 적용 중인 코어 진형을 함선 수와 함께 표시한다. 진형 선택기는 첫 진입 및 실제 진형 변경이 적용된 순간에만 canonical `attacker_formation_id`와 동기화하므로, 사용자가 새 후보를 고르는 동안 매 프레임 기존 값으로 되돌아가지 않는다.

하단 명령 덱은 각 버튼에 normal·hover·pressed·focus·disabled 상태를 명시한다. `다음 페이즈`는 금색 주 행동, 진형 적용은 보조 금색, 진형 유지·AI 위임·홈 복귀는 청회색 보조 행동으로 구분한다. 비활성 상태는 낮은 명도와 별도 테두리를 사용해 실행 가능 여부를 텍스트에만 의존하지 않는다.

진형 선택기는 후보를 고르는 즉시 코어 `Formations` 데이터에서 강점 페이즈와 최고 계수, 전개폭, 필요 통솔, 전용 특성을 읽어 하단 브리핑으로 표시한다. 별도 UI 상수나 승률 예측은 만들지 않으며, 적용 버튼을 누르기 전에는 코어 진형을 변경하지 않는다.

전투가 resolved로 전이하면 숨겨진 내부 문자열에만 결과를 남기지 않는다. 5단계 타임라인 바로 아래에 결착 완료 배너를 열고 승자, 양측 잔존 함선 수와 사기를 한 줄로 표시한다. 승자 진영 색을 사용하되 금색 테두리와 `승전` 텍스트를 함께 사용해 색상에만 의존하지 않는다.

페이즈가 바뀌면 지도 상단에 1.8초 동안 단계 번호·이름·전환 신호를 표시한 뒤 자동으로 사라진다. 배너는 입력을 가로채지 않는다. 직전 전과의 계략 표시는 단순 건수를 버리고 `phase_results.schemes[].name`의 실제 발동 이름을 나열하며, 없으면 `계략 없음`을 명시한다.
