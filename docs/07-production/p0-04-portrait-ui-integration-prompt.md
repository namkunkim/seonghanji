# P0-04 공용 초상 UI 연결 작업 프롬프트

> 작성일: 2026-09-01 · 상태: **기술 검수 완료** · 선행: V-50 공용 초상 11종 승인
> 기준 보고서: `p0-04-portrait-production-v1-report.md`

## 실행 프롬프트

P0-04에서 승인한 `ART-C901~911` FLUX 공용 초상 11종을 Godot의 실제 `SC-F3` 임명 화면에 연결하고 검수한다. 최종 PNG 마스터는 수정하거나 재생성하지 않는다. UI는 `assets/preproduction/p0-04/production-v1/final/flux/`의 승인 파일만 읽는다.

인물의 `class[0]`과 `disposition`으로 공용 초상을 결정론적으로 고른다. 제독형 실무 A/B는 `CHR-####` 숫자부의 홀짝으로 나눈다. 제독형은 무뢰=`C903`, 절의=`C904`, 그 밖=`C905`; 관료형은 실무=`C906`, 그 밖=`C907`; 참모형은 실무=`C908`, 그 밖=`C909`; 강습형=`C910`; 파일럿형=`C911`이다. 이 규칙은 명장 개별 초상이 아직 없는 동안 일반 공용 프리뷰에만 쓴다.

`SC-F3`의 지휘부 행에는 정사각 상단 크롭 칩을 표시하고, 선택한 인물은 4:5 비율의 **256×320px** 실제 게임 초상 프레임으로 확인할 수 있게 한다. 프레임은 얼굴 위치·어깨·배경 틴트·텍스트 대비를 검수할 수 있어야 하며, 원본의 색 또는 알파를 UI에서 변경하지 않는다.

완료 조건은 다음과 같다.

- 11개 ID가 모두 승인 최종 파일 경로로 해석되고 누락 없이 로드된다.
- 320px 프레임은 4:5를 유지하고, 칩은 정사각 상단 크롭을 사용한다.
- SC-F3에서 실제 선택/교체에 따라 초상과 매핑 ID가 바뀐다.
- 원본 SHA-256은 `selection-manifest.json`과 동일하다.
- Godot 부팅·기존 자동 시험을 통과하고, 화면 캡처 또는 동일 프레임의 검수 근거를 보고서에 남긴다.

범위 밖: RunPod 실행, 신규 생성, SDXL, 명장 120명 생성, 최종 모델 재선정, 원본 PNG 변경.
