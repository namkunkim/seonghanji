## 0. 우선순위와 완료 정의

1차 목표는 **적벽대전 선택 → 역사적 전투 준비 → 유비군 지휘 → 손권 턴별 수동/자동 선택 → 최대 20턴의 전대·함대 전투 → 결과 확인**이다.

기존 손권 플레이, 선행 사건 선택, 수동 집결, 전투 전체 5페이즈 순차 진행, 홈 지도 복귀와 캠페인 결과 적용은 최신 목표와 충돌한다. 관련 구현과 시험은 과거 기준선으로 보존하되 새 완료 증거로 사용하지 않는다.

완료는 다음을 모두 충족해야 한다.

- Windows 1600×900 제품 경로에서 처음부터 결과까지 완주한다.
- 구현, 관련 자동시험, 별도 독립 검증과 사람 UX 검수를 통과한다.
- 이미지·음원 출처, 라이선스, 생성 기록과 해시를 남긴다.
- 동일 Task ID와 제목으로 Tracker와 Handover를 갱신한다.
- 경로 지정 선택적 스테이징, 커밋, `origin/main` 푸시와 HEAD 일치를 확인한다.

## 1. 반드시 해야 할 일

- 플레이어가 보는 전투 준비·지휘·전투·결과 기능을 CI 확장보다 우선한다.
- 역사적 위치, 함대·전대, 장수와 함종 재고를 명시 데이터로 제공한다.
- 역사적 기본 편성과 모든 참가 함선·장수의 사용자 재편성 메뉴를 제공한다.
- 전대 개별 지휘와 여러 전대를 묶은 함대 단위 지휘를 모두 제공한다.
- 자유 좌표 이동, 다중 경유점, 방향, 진형, 무기 비율, 공격 대상과 사격 중지를 제공한다.
- 탐지·전쟁 안개, 지형, 요격·기회 사격, 사기·지휘 승계와 제한 자원을 판정한다.
- 요격함, 고속정 전대와 자동 보급·비상 귀환·표류·구조·나포를 제공한다.
- 매 턴 승리 조건을 검사하고 결정된 결과를 명확히 설명한다.
- 언제든 저장과 정확한 상태 복원을 제공한다.
- 2D 전술 지도, 정지 이미지, 2D 효과, BGM과 효과음을 제공한다.

## 2. 하지 말아야 할 일

- 선행 외교 사건이나 장거리 집결을 1차 데모의 필수 플레이로 되살리지 않는다.
- 플레이어를 손권으로 바꾸거나 유비군 지휘권을 AI에 전부 위임하지 않는다.
- phase 5에서만 승패를 정하거나 페이즈 진행 버튼만으로 전투를 끝내지 않는다.
- 함선 3D 모델, 3D 카메라, 3D 항해·전투 시네마틱을 만들거나 사용하지 않는다.
- 결과 뒤 홈 지도나 후속 캠페인 진행을 필수로 만들지 않는다.
- UI·시험 fixture가 승자, 손실, 도착, 탐지나 자원을 직접 주입해 정상 플레이를 대신하지 않는다.
- 자동시험 PASS, 노드 존재, 소스 실행만으로 완성이나 배포 수용을 선언하지 않는다.
- 관리 작업에서 게임 코드·자산을 직접 구현하지 않는다.
- 공유 작업 트리의 기존 변경을 일괄 스테이징·삭제·복원하지 않는다.
