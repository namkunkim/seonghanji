# A-05-01 — 진형 전투 계약과 기준선 시험 확정

상태: PASS (2026-09-07)
정본: `data/formations.json`, `core/world/formations.gd`, `core/world/fleet.gd`, `docs/03-systems/ship-specs.md` §5.2~§5.6

## 동결한 계약

| 항목 | 계약 |
|---|---|
| 진형 식별 | 데이터 ID `FRM-01`~`FRM-07`을 새 전투/명령 API 입력으로 쓴다. 기존 저장 호환 때문에 `Fleet.formation`은 한국어 이름을 계속 저장하며, 코어만 ID→이름을 정규화한다. |
| 7종 | FRM-01 어린진, 02 학익진, 03 방원진, 04 안행진, 05 봉시진, 06 장사진, 07 팔진. 파일 순서가 결정론적 목록 순서다. |
| 페이즈 | 접적·포화·교전·강습·결착의 계수는 `Formations`가 적재한 JSON 값만 사용하고, 전투력의 기존 함종 계수에 고정소수점으로 곱한다. |
| 상성 | 학익→어린→방원→봉시→안행→학익은 ③ 교전에서 공격측 +20%다. 장사진은 모든 상성에 −10%, 동일 진형은 0%다. |
| 팔진 | 통솔 90 이상이며 `staff_traits`에 실제 특성명 `신기묘산`이 있을 때만 사용한다. JSON의 `팔진 전용`은 표시용 요구 라벨이며 판정 특성명은 아니다. 팔진이 어느 쪽에 있어도 상성 판정은 무효다. |
| 지형 | `Formations.allowed_in`/`forced_formation`을 단일 판정으로 쓴다. 기저는 광폭 불가, 중회랑은 방원·봉시·장사만, 대회랑은 장사진 강제·변경 불가다. |
| 변경 | 전투별 1회, 페이즈 경계에서만. 명령은 `battle_id`, 다음 phase, 목표 `FRM-*`를 담고, 같은 명령/경계의 재적용을 거부한다. 통솔 미달은 실패이며 그 도착 페이즈의 전 계수 ×0.8이다. 팔진 조건 충족자는 변경 판정을 자동 성공한다. |
| 재생 | 명령과 적용 결과(성공/실패/거부 사유)는 코어가 정하고 저장 명령 로그·지문에 포함한다. UI/AI는 그 결과를 읽기만 한다. |

## 기준선과 범위

2026-09-07 `Godot_v4.7.2-stable_win64_console.exe --headless --path . --script tests/run_tests.gd` 결과는 35/35 섹션, 701 단언, 실패 0이다. 이 기준선의 일반 5페이즈 전투는 `Fleet.formation` 및 `Formations.coefficients()`를 읽지 않고 중립 계수 1000을 전달한다. 따라서 이것은 **진형 미적용 기준 결과**다.

이번 A-05는 공용 코어 계산·명령·저장 재생과 현재 G-10 phase 1~2의 공용 판정 사용까지다. G-10 phase 3~5, 실제 전투 UI, 신규 전술 UX, 밸런스 수치 조정은 제외한다.
