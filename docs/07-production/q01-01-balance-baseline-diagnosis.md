# Q-01-01 계략·전투 밸런스 기준선 진단

## 실행과 결정성

Godot 4.7.2 콘솔에서 `tests/run_campaign.gd`를 실행했다. 표본은 고정 시드 1000..1099, 표준 역사 편향(HB) 0.25이며, 동일 실행 재현과 100회+HB 비교 300회의 구조 검증 7/7 및 exit 0을 확인했다. 이 Task는 코어 규칙·데이터·기존 시험을 변경하지 않았다.

## 원인 분해의 현재 한계

67.0%는 기존 규칙셋 값과 일치한다. 매복의 성공량과 회랑/비회랑 공격측 피격률 차이는 매복을 조사 우선 후보로 만든다. 다만 이 관측만으로 계략·회랑·공수 보정·손실/사기 중 어느 하나를 원인으로 단정할 수는 없다. Q-01-02에서 동일 시드 단일 변수 A/B로 분리한다.

초기 샌드박스 실행의 `user://` 쓰기 실패는 승격된 실행 환경에서 재검증했고, 최종 `run_save_restore.gd`는 73 통과·의도적 SKIP 2·실패 0이다.

## 페이즈·사기·진형 대조

최종 잠금 ruleset의 `verify_chibi.gd`는 문서와 코드의 계략 분기·손실·사기를 대조했다. 표준 진형 5페이즈 계수는 접적 0.860, 포화 1.060, 교전 1.070, 강습 0.910, 결착 0.875다. 적벽 화공 성공 분기에서 조조 손실은 접적 109 → 포화 18 → 교전 5 → 강습 0, 손유는 109 → 96 → 81 → 73 → 70이며 조조의 화공 사기 E는 52.5다. 정욱 간파 분기는 손유가 109 → 81 → 51 → 28 → 12로 감소하고 결착에서 즉시 붕괴한다. 위장 항복 실패 분기는 손유 109 → 96 → 67 → 45 → 30, 최대 붕괴 16%다.

이는 고정 적벽 검산의 제어된 페이즈별 증거이며, 100회 캠페인의 집계 전투·점령 지표와 함께 진형·손실·사기 상호작용이 매복 보정 변경으로 손상되지 않았는지 확인하는 근거다. 검산기는 문서 대조형이라 자체 PASS/FAIL 대신 수치 일치를 출력한다.
