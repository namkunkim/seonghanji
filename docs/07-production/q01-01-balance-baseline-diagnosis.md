# Q-01-01 계략·전투 밸런스 기준선 진단

## 실행과 결정성

Godot 4.7.2 콘솔에서 `tests/run_campaign.gd`를 실행했다. 표본은 고정 시드 1000..1099, 표준 역사 편향(HB) 0.25이며, 동일 실행 재현과 100회+HB 비교 300회의 구조 검증 7/7 및 exit 0을 확인했다. 이 Task는 코어 규칙·데이터·기존 시험을 변경하지 않았다.

## 원인 분해의 현재 한계

67.0%는 기존 규칙셋 값과 일치한다. 매복의 성공량과 회랑/비회랑 공격측 피격률 차이는 매복을 조사 우선 후보로 만든다. 다만 이 관측만으로 계략·회랑·공수 보정·손실/사기 중 어느 하나를 원인으로 단정할 수는 없다. Q-01-02에서 동일 시드 단일 변수 A/B로 분리한다.

`run_save_restore.gd`의 별도 실행은 이 환경에서 `user://` 쓰기 거부로 52 통과·5 실패했다. 이는 A-07-E1 실행 환경 위험으로 기록하며, 기준선 수치나 성공한 캠페인 결정성의 근거로 바꾸어 해석하지 않는다.
