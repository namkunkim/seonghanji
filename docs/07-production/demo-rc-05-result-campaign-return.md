# DEMO-RC-05 — 적벽 결과 판정과 데모 종료 계약

> 최신화: 2026-09-10 · `MGMT-HANDOVER-01`
> 파일명은 과거 작업 ID 참조 보존을 위해 유지하지만 캠페인 복귀 계약은 폐기한다.
> 요구사항 정본: `docs/07-production/demo-rc-requirements-interview.md`

## 승패 판정

- 매 턴 이동·전투 판정 뒤 모든 승리 조건을 검사하며 하나라도 충족되면 즉시 종료한다.
- 상반된 승리 조건이 같은 턴에 동시에 충족되면 조조군 승리다.
- 유비 기함 파괴, 유비군 시작 코스트 70% 이상 손실 또는 유비군 사기 붕괴·항복은 연합군 패배다.
- 조조 기함 파괴 또는 조조 기함의 조조군 탈출 지점 도달은 연합군 승리다.
- 유비 기함과 필수 전대가 연합군 탈출 지점에 도달하면 제한적 연합군 승리다.
- 그 밖의 전력 붕괴는 손유 연합과 조조군 각각의 시작 코스트 대비 70% 이상 손실로 판정한다. 손권군 단독 패배는 유비군이 계속 싸울 수 있으면 즉시 종료하지 않는다.
- 20턴까지 다른 종료 조건이 없으면 시작 코스트 대비 잔존 코스트 비율이 높은 측이 승리하며 동률은 조조군 승리다.

## 결과 화면

- 승리 조건, 양측 함선 손실과 잔존 코스트, 생존·부상·사망·포로 장수, 나포 함선, 발동 계략과 주요 턴을 표시한다.
- 유비군 결과와 손유 연합 결과를 구분해 표시한다.
- 전투 결과, 상태 평가와 후일담을 표시한다.
- 결과 화면이 1차 데모의 종료점이다. 캠페인으로 복귀하거나 전투 결과를 전략 상태에 계속 적용하지 않는다.
- 결과 뒤에는 새 전투 시작, 저장 불러오기, 전투 기록 다시 보기만 제공한다.

기존의 홈 지도 복귀와 resolved 재진입 거부 시험은 현재 구현 기준선으로 보존하되 최신 제품 완료 조건으로 사용하지 않는다.
