# DEMO-RC-03 — 유비·손권 턴별 지휘 선택 계약

> 최신화: 2026-09-10 · `MGMT-HANDOVER-01`
> 요구사항 정본: `docs/07-production/demo-rc-requirements-interview.md`

## 지휘 권한

- 플레이어는 유비이며 유비군 전대와 함대를 직접 지휘한다.
- 조조군은 모든 턴에 AI가 지휘한다.
- 손권군은 기본적으로 AI가 지휘하지만 매 턴 유비 명령 입력 뒤 사용자가 수동 지휘 여부를 선택한다.

## 턴 흐름

1. 사용자가 유비 측 전대·함대 명령을 설정하고 턴 실행을 누른다.
2. 손권 함대를 직접 제어할지 묻는다.
3. `Yes`이면 손권 측 전대·함대 명령을 같은 수준으로 입력하고 다시 턴 실행을 누른다.
4. `No`이면 손권 AI가 해당 턴 명령을 결정한다.
5. 손유 양측과 조조 AI 명령을 함께 판정한다.
6. 이동·요격·사격·피격·상태 변화를 2D로 재생하고 승리 조건을 검사한다.

## 문의와 자동 운용

- 손권 문의 화면의 `더 이상 묻지 않기`를 선택하면 이후 턴은 손권 AI 자동 운용으로 넘어간다.
- 설정에서 문의를 다시 활성화할 수 있다.
- 손권을 수동 제어한 턴에만 손권의 전술 명령을 사용자가 입력한다. 자동 보급은 지휘 주체와 관계없이 모든 세력에서 무개입으로 처리한다.
- 기존의 전투 전체 `delegate_ai` 잠금은 사용하지 않는다. 위임 여부는 손권군에 대해 턴마다 선택하며 유비군 지휘권은 유지한다.
