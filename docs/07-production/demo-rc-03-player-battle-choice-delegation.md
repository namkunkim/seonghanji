# DEMO-RC-03 — 적벽 최소 플레이어 전투 선택 및 위임 흐름

`RedCliffBattleView`는 정본 `ActiveBattle`을 읽고, `Campaign.issue_red_cliff_player_command` 공개 API로만 입력을 전달한다. 화면은 승자, 손실 또는 사기를 계산·변경하지 않는다.

허용 입력은 현재 진형 유지, 다음 페이즈 진형 변경, 다음 페이즈 진행, AI 위임이다. 명령이 없을 때의 기본 행동은 “현재 진형 유지 후 다음 페이즈 진행”으로 표시한다. 코어는 `origin="player"` 명령 로그, 진형의 A-05 허용성, 중복·resolved 거부와 AI의 결정론성을 책임진다. 화면은 빈/거부 응답을 중복 또는 상태 거부로 표시한다.

이 UI는 코어 API가 없는 중간 통합 상태에서도 명령 버튼을 안전하게 거부한다. 따라서 과거의 phase-2 승자 직접 지정 API는 노출하지 않는다.
