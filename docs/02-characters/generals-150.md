## 0. 문서 사용법

### 0.1 표 항목 설명

| 항목 | 의미 |
|---|---|
| **격** | 특급 / 1급 / 2급. 등용 난이도와 성능의 총합 지표 |
| **클래스** | A / B 두 개 보유. 편성 시 택1 (기획서 §8.2) |
| **특성** | 고유 개성. 격이 높을수록 효과가 크고 조건부 |
| **천명 임계** | 이 인물이 요구하는 세력 최소 정통성. 미달 시 등용 불가 |

### 0.2 클래스 약어

`제` 제독형 · `강` 강습형 · `파` 파일럿형 · `참` 참모형 · `관` 관료형

### 0.3 천명 임계 등급

| 등급 | 의미 | 해당 인물 성향 |
|---|---|---|
| **극** | 극도로 높은 정통성 요구 | 한실 충신, 절의지사 |
| **고** | 높음 | 명문 출신 명사, 유가 관료 |
| **중** | 보통 | 일반 사대부, 실무 관료 |
| **저** | 낮음 | 실력주의자, 현실주의자 |
| **무** | 무관 | 무뢰배, 용병, 이민족, 배신자 |

> **핵심:** 실력만으로 밀어붙이는 세력은 성계를 얻어도 극·고 인물을 얻지 못한다.

## 7. 세력 정원 체계 — 최소 20인 보장

### 7.1 문제 정의

명장 150인은 **세력 총량 기준**으로는 충분하다 (위43·촉37·오32·군웅38).
그러나 실제 플레이 단위는 **「시나리오 × 개별 세력」**이며, 이 단위에서는 심각한 결손이 발생한다.

| 시나리오 1 (190) 세력 | 보유 명장 | 편성 가능 여부 |
|---|---|---|
| 조조 | 약 10인 | 가능 |
| 원소 | 6인 | 빠듯 |
| 동탁 | 3인 | **불가** |
| 유표 | 3인 | **불가** |
| **공손찬** | **2인** | **불가** |
| 유비 | 4인 | **불가** |

> 함대 편성 최소 요건은 **제독형 3 + 참모형 2 + 강습·파일럿 4 = 9인**이며,
> 방면군 2개를 운용하려면 최소 15~20인이 필요하다.
> 현 상태로는 스토리 모드 「3대 + 주요 군웅」(기획서 §6.1)이 성립하지 않는다.

### 7.2 해법 — 인물 3계층 구조

명장을 늘리는 대신, **그 아래 계층을 신설**한다.
150인은 「주요 인물」의 정의로 유지하고, 정원은 하위 계층이 채운다.

| 계층 | 규모 | 출처 | 데이터 밀도 | 획득 방식 |
|---|---|---|---|---|
| **① 명장** | **150인** | 원전 실존·연의 | 고유 특성, 전용 기함, 고유 대사, 등용 3중 판정 | 등용·포로 설득 전용 |
| **② 일반 무장** | **250~300인** | **원전 실존 (2·3급)** | 간이 특성 1개, 스탯만 차등 | 일반 등용 (조건 단순) |
| **③ 재야 인물** | 수백 인 | **창작 (절차적 생성)** | 특성 조합 자동 생성 | 뽑기 초빙권 |

> **핵심 변경점:** 기존 설계는 ①과 ③만 있었다.
> 그 사이에 **원전 실존 2·3급 인물 계층**을 넣어 정원을 채운다.
> 이러면 "원전 직접 대응" 원칙(기획서 §1)을 훼손하지 않으면서 세력 정원을 확보할 수 있다.
> 삼국지 원전에는 순우경·심배·괴월·엄안급 인물이 충분히 존재한다.

### 7.3 정원 규칙

```
세력 초기 무장 정원 = 20인 (최소 보장)

  구성 = 명장(①) + 일반 무장(②)
  ③ 재야 인물은 정원에 포함되지 않음 (플레이 중 추가 획득분)

  명장이 20인을 초과하는 세력은 상한 없이 그대로 유지 (예: 208년 조조)
  명장이 부족한 세력은 ② 계층에서 자동 충원
```

**충원 우선순위:** 원전상 해당 세력에 실제 소속되었던 인물 → 해당 성역 출신 인물 → 창작 부장

### 7.4 충원 예시 — 시나리오 1 (190년)

| 세력 | ① 명장 | ② 일반 무장 (충원) | 계 |
|---|---|---|---|
| **공손찬** | 공손찬, 조운 | 엄강·전해·선우보·관정·추단·공손월·공손범·전예·단경·왕문·이렇게 18인 | 20 |

| **원소** | 원소, 저수, 전풍, 안량, 문추, 국의 | 심배·봉기·곽도·신평·허유·순우경·고람·여광·여상·최염·진림·원담·원희·원상 | 20 |
| **유비** | 유비, 관우, 장비, 미축 | 손건·간옹·미방·진도·유벽·공도·주창·요화·관평·배원소·진등·진규·전예·전해·왕충·조표 | 20 |

> 관리 부담을 낮추면서 편성 퍼즐의 재료 역할만 수행하게 한다.

### 7.5 후기 시나리오 대응

## 8. 이역 인물 — ③ 재야 풀 확장

### 8.1 취지

③ 재야 인물 풀(§7.2)을 **창작 인물 전용**에서 **창작 + 동시대 타 민족 실존 인물**로 확장한다.

**원전 정합성 근거:** 『삼국지』 위서 **동이전**에 부여·고구려·옥저·예·한·왜의
군장과 사절이 실명으로 기록되어 있다. 이들은 외부 삽입물이 아니라 **원전이 이미 다루는 인물**이다.
북방·서방 인물은 원전 범위 밖이지만, 기획서 §2.3에서 로마·이민족을 정식 세력으로 설정했으므로
세계관상 등장 근거가 확보되어 있다.

### 8.2 권역 구분

| 권역 | 범위 | 게임 내 접근 조건 | 천명 영향 |
|---|---|---|---|
| **동이권** | 부여·고구려·옥저·예·삼한·왜 | 동이 연합 접경 성역 보유 또는 교섭 상태 | 경미 (-1) |
| **북방권** | 흉노·선비·오환·강·저 | 변경 성역 보유 | 경미 (-1) |
| **서방권** | 로마·팔미라·사산조·파르티아·쿠샨 | **원거리 교역로 확보 필수** | **중대 (-5)** |

> 서방권 인물의 등용은 기획서 §2.3의 **「로마를 끌어들이는 것은 매국」** 규칙을 그대로 적용받는다.
> 강력하되 정통성을 대가로 치른다 — 「정통 vs 실력」 주제축이 뽑기 단계에서도 작동한다.

### 8.3 체급 규칙 — 국가원수는 뽑기 불가

| 구분 | 처리 |
|---|---|
| **국가원수급** (로마 황제, 사산조 왕, 고구려왕, 왜 여왕 등) | **뽑기 풀 제외.** 외교 NPC 또는 자유 모드 군주로만 등장 |
| **사절·망명자·용병대장·기술자·교역상·학자** | 뽑기 풀 편입 대상 |

> 로마 황제가 초빙권으로 유비 휘하에 들어오는 사태를 원천 차단한다.
> 대신 **로마의 퇴역 백인대장**, **사산조에서 망명한 중장기병 지휘관**,
> **위에 파견된 왜의 사절**은 자연스럽게 합류할 수 있다.

## 9. 등용 3중 판정 — 상세 설계

### 9.1 판정 순서

```
[1] 고유 조건 판정   ─ 서사 조건 충족 여부 (미충족 시 접촉 자체 불가)
        ↓ 통과
[2] 상성 판정       ─ 군주 성향 × 인물 성향 매트릭스
        ↓ 통과
[3] 천명 판정       ─ 세력 정통성 ≥ 인물 천명 임계
        ↓ 통과
   항구적 등용 성립
```

### 9.2 각 판정의 실패 결과

| 판정 | 실패 시 |
|---|---|
| **① 고유 조건** | 접촉 불가. 조건 힌트만 표시 |
| **② 상성** | 일시 복속 후 **일정 턴 내 이탈**. 이탈 시 적대 세력행 확률 |
| **③ 천명** | 거절. 재시도는 가능하나 매력 판정 페널티 누적 |

> **② 상성 실패의 의미:** 관우가 조조에게 포로가 되어 일시 복속하되
> 결국 떠나는 서사가 이 판정으로 재현된다.

## 14. 용병 시스템

### 14.1 취지 — 설계 공백의 보완

현 설계는 **인물 등용**만 다루고 **부대 단위 외국 병력**이 빠져 있다.
그러나 후한 말 전쟁의 상당 부분은 이민족 기병에 의존했다.

- 공손찬의 **백마의종**, 조조의 **오환돌기**(정복 후 「천하명기」로 편입)
- 동탁·마등의 **강호 기병**, 원소·조조 양측이 쓴 **남흉노 기병**
- 촉한의 **무당비군**(판순만이 기반), 오의 **산월 갑사**

> **인물과 용병은 층위가 다르다.**
> 인물은 등용하고 충성을 얻는 대상이며, 용병은 **자금으로 고용하는 자원**이다.
> 충성도가 없는 대신 이탈도 없다 — 계약이 끝나면 떠날 뿐이다.

### 14.2 인물 계층과의 관계

| 구분 | 인물(①②③) | **용병단** |
|---|---|---|
| 획득 | 등용 3중 판정 | **자금 지불 + 계약** |
| 지속 | 영구 (이탈 조건 별도) | **계약 기간 한정** |
| 충성 | 충성도·상성 존재 | 없음 — 계약이 전부 |
| 성장 | 경험 누적 | 없음 |
| 상실 | 이탈·사망 | 계약 만료 · 자금 부족 · 변절 |
| 천명 | 등용 시 임계 판정 | **고용 시 소폭 감소** (이민족 한정) |

### 14.4 고용 규칙

```
① 계약 기간    게임 내 6개월 ~ 2년 (실제 6~24시간)
② 선불 + 유지비 계약금 일시 지불 + 매월 유지비
③ 계약 만료    자동 해산. 재계약 시 비용 상승
④ 자금 부족    즉시 이탈 + 「약탈」 이벤트 → 민심·천명 하락
⑤ 변절        적 세력이 상회하는 조건 제시 시 이탈 판정 (충성도 없음)
⑥ 고용 상한    총 병력의 30% 초과 시 천명 급감
⑦ 개전 이탈    소속 권역·세력과 개전하면 즉시 계약 파기
```

### 14.5 천명 감소 체계

| 계열 | 1개 부대당 감소 | 근거 |
|---|---|---|
| 내지계 | **0** | 한의 백성이다 |
| 북적계 · 동이계 | 소 | 변경 군벌의 관행 (기획서 §2.3) |
| 남방계 | 소 | 회유의 결과로 간주 |
| **서방계** | **대 (5배)** | **로마를 끌어들이는 것은 매국** (기획서 §2.3) |

> **정통 노선의 대가:** 천명이 높은 세력일수록 이민족 용병을 쓰기 어렵다.
> 촉이 병력난에 시달리면서도 강족·남만에 손대기 망설이는 이유가 시스템으로 설명된다.
> 반대로 실력 노선은 용병을 자유롭게 쓰되 명사를 얻지 못한다.

### 14.6 인물과의 연동

**용병 고용은 인물 보유에 종속된다.** 이것이 이 시스템의 핵심이다.

| 인물 | 열어주는 용병 |
|---|---|
| **마초「금마초」** | 강족 철기 — 고용 비용 −50% |
| **염유「호중」** | 오환·선비 전 계열 — 변절 판정 무효 |
| **곽회「진서」** | 북적계 전반 — 유지비 −30% |
| **왕평** | **무당비군** — 촉 전용 최강 방어 부대 |
| **하제「산월토벌」** | 산월 갑사 — 획득량 +50% |
| **진론「대진상인」** | **로마 공병대** — 유일 개통 경로 |
| **마량「백미」** | 남방계 전반 — 회유 성공률 +40% |

> 마초를 잃으면 강족이 떠나고, 왕평을 잃으면 무당비군이 해산된다.
> **인물의 가치가 개인 능력치를 넘어 「무엇을 데려오는가」로 확장된다.**
