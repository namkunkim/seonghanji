# SEONGHANJI — 인물 성향 태그 설계 v0.1

> 인물 설계 v0.5 §9.3(상성 매트릭스)의 전제 문서
> 작성일: 2026-08-20 / 상태: 초안 — 검토 요망

---

## 0. 왜 필요한가

등용 3중 판정의 **② 상성 판정**은 「군주 성향 × 인물 성향」 매트릭스로 작동한다.
그런데 지금까지 **어느 인물이 어느 성향인지 정해진 바가 없었다.**

이 문서가 그 공백을 채운다.

---

## 1. 성향 정의 — 5종

| 성향 | 정의 | 행동 원리 | 대응 천명 임계 |
|---|---|---|---|
| **절의** | 의와 신의를 최우선한다 | 주군을 바꾸지 않는다. 명분이 깨지면 떠나거나 죽는다 | 극 · 고 |
| **명사** | 가문·명망·청류의 세계 | 예우와 격식을 요구한다. 무례에 민감하다 | 고 |
| **실무** | 능력과 결과를 본다 | 일할 수 있는 자리를 준다면 섬긴다 | 중 · 저 |
| **야심** | 자기 몫을 키운다 | 기회를 보며, 때가 오면 스스로 선다 | 저 · 무 |
| **무뢰** | 이익과 힘의 논리 | 대우가 좋으면 남고, 나쁘면 떠난다 | 무 |

### 1.1 절의의 두 갈래

절의는 **무엇에 대한 절의인가**에 따라 갈린다. 이 구분이 중요하다.

| 갈래 | 대상 | 예시 | 천명 임계 |
|---|---|---|---|
| **한실 절의** | 한 자체 | 순욱 · 동윤 · 공융 · 왕윤 | **극 · 고** |
| **주군 절의** | 특정 개인 | 관우 · 방덕 · 초선 · 진궁 | **낮을 수 있음** |

> 방덕은 천명 임계가 「무」이면서 절의다.
> 그가 지킨 것은 한실이 아니라 조조 개인이었기 때문이다.
> **한실 절의는 정통성을 요구하고, 주군 절의는 은의를 요구한다.**

## 2. 군주 성향 — 5종

플레이 가능 군주에게 부여되는 별도 축.

| 유형 | 성격 | 해당 인물 |
|---|---|---|
| **인덕형** | 명분과 인망으로 사람을 모은다 | **유비** · 도겸 · 유표 |
| **패도형** | 능력을 보고 쓰며, 결과로 증명한다 | **조조** · 손책 |
| **명문형** | 가문의 권위로 통솔한다 | **원소** · 원술 · 유장 |
| **실리형** | 이해를 계산하고 균형을 잡는다 | **손권** · 유장 · 사섭 · 공손강 |
| **무단형** | 힘으로 누른다 | **동탁** · 여포 · 공손찬 |

## 3. 상성 매트릭스 [개정]

인물 v0.5 §9.3의 매트릭스에 **중대한 오류**가 발견되어 수정한다.

### 3.1 발견된 문제

기존 매트릭스는 **「패도형 군주 × 절의 인물 = ✕ 이탈 확정」**이었다.
그런데 **순욱은 절의이며 조조(패도형) 밑에 있었다.**

역사적 사실은 이렇다.
순욱은 조조를 「한실을 부흥시킬 사람」으로 보고 섬겼고,
조조가 위공이 되려 하자 반대했으며, 그해에 죽었다.

> **관계는 성립했으나 끝내 파탄났다.**
> 「처음부터 불가능」이 아니라 「조건이 깨지면 파탄」이다.

### 3.2 개정된 매트릭스

|  | 절의 | 명사 | 실무 | 야심 | 무뢰 |
|---|---|---|---|---|---|
| **인덕형** | ◎ | ○ | ○ | △ | ✕ |
| **패도형** | **△\*** | △ | ◎ | ○ | ○ |
| **명문형** | ○ | ◎ | △ | △ | ✕ |
| **실리형** | △ | △ | ◎ | ◎ | ○ |
| **무단형** | ✕ | ✕ | ○ | ○ | ◎ |

◎ 보너스 · ○ 정상 · △ 페널티 · ✕ 이탈 확정
**△\* = 조건부 관계**

### 3.3 조건부 관계(△\*)의 규칙

```
패도형 군주 × 절의 인물

  성립  : 천명이 임계 이상으로 유지되는 동안 잔류
  경고  : 칭왕 시점에 이탈 경고 이벤트
  파탄  : 칭제 시점에 사직 또는 사망
```

> **이것이 조조 플레이의 핵심 긴장이다.**
> 순욱·순유·최염 같은 절의 인물을 데리고 천하를 얻을 수는 있다.
> 다만 **그 마지막 한 걸음을 내딛는 순간 그들을 잃는다.**
>
> 조조「유재시거」(#1)의 「상성 판정 1회 무시」는 이 관계를 **한 번 더 미루는** 능력이다.

## 6. ② 일반 무장 256인 — 규칙 기반 일괄 배정

개별 배정 대신 **자동 규칙**을 적용한다.

```
① 클래스 우선
   관료형 → 명사 또는 실무
   참모형 → 명사 또는 실무
   제독형 → 실무
   강습·파일럿형 → 무뢰 또는 실무

② 행적 보정
   주군 순사·항복 거부   → 절의
   세력 이적 2회 이상    → 야심 또는 무뢰
   배신·내응 실행        → 야심
   명문 출신·청류 교유   → 명사
   이민족·도적 출신      → 무뢰

③ 세력 보정
   촉 소속 → 절의·명사 가중
   위 소속 → 실무 가중
   오 소속 → 명사·야심 가중
   군웅   → 무뢰 가중
```

### 6.1 예외 지정 (수동 배정 필요, 22인)

| 인물 | 성향 | 사유 |
|---|---|---|
| 허유 | **야심** | 관도의 이반 |
| 진림 | 명사 | 격문 |
| 심배 | **절의** | 업성 순사 |
| 저곡 · 관정 | 절의 | 순사 |
| 후성 · 송헌 · 위속 | **무뢰** | 여포 포박 |
| 이유 | 실무 | 폐립 실행 |
| 서영 | 실무 | — |
| 이각 · 곽사 | **무뢰** | 장안 난정 |
| 부손 · 유종 | 실무 | 항복 주도 |
| 왕위 | **절의** | 직간 |
| 왕루 | **절의** | 간사 |
| 초주 | 실무 | **항복 주장 — 절의가 아님** |
| **황호** | **야심** | 전횡 |
| **손침** | **야심** | 폐립 |
| 등윤 | 절의 | 순사 |
| 장제(오) | 절의 | 최후 항전 |
| 관녕 | **명사(극)** | 은일. 등용 극난 |

> **초주의 배정이 미묘하다.** 그는 항복을 주장했으나 배신하지는 않았다.
> 「실무」로 두는 것이 정확하다 — **그는 계산했고, 그 계산이 옳았을 수도 있다.**

## 7. 성향과 시스템의 연동

| 시스템 | 연동 |
|---|---|
| **등용 상성 판정** | §3.2 매트릭스 |
| **천명 임계** | §1 대응표 — 절의·명사는 높은 천명 요구 |
| **이탈 조건** | 절의: 명분 훼손 시 / 무뢰: 대우 악화 시 / 야심: 기회 포착 시 |
| **전투 방침 「인물 위임」** | 성향이 자동 지시 선택에 반영 (전투 v0.2 §2.3) |
| **용병 고용** | 절의 인물 다수 보유 시 이민족 용병 고용에 추가 반발 |
| **엔딩 분기** | 「한실 부흥」 엔딩은 **한실 절의 인물 보유**를 조건으로 |

### 7.1 전투 방침에의 반영

「인물 위임」 선택 시 성향별 기본 성향은 다음과 같다.

| 성향 | 전투 성향 |
|---|---|
| 절의 | 신중 — 병사를 아낀다 |
| 명사 | 균형 |
| 실무 | 균형 — 손익 계산 |
| 야심 | 적극 — 전공을 노린다 |
| 무뢰 | 적극 — 약탈·추격 선호 |

> 여포에게 맡기면 무조건 돌진하고, 육손에게 맡기면 버틴다.
> **성향 배정 하나로 자동 전투 알고리즘의 절반이 결정된다.**
