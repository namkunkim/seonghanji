## 0. 이 문서가 정하는 것

기획서에서 확정된 것은 **비율**뿐이었다.

```
고속항로 ×1  /  회랑 ×3~5  /  기저 항로 ×4~6
```

여기에 **절대값**을 넣는다. 이 수치가 정해져야:

- 수익 모델 설계가 가능해진다 (시간 단축 과금 여부)
- 세션 리듬·푸시 알림·예약 명령 UX가 결정된다
- 캠페인 1회 완주 소요가 산출된다
- 「지형 = 게임 템포」(기획서 §6.2)가 실제로 성립하는지 검증된다

## 1. 설계 기준점 — 생활 리듬

모바일 게임의 대기 시간은 **플레이어의 하루 공백**에 맞춰야 한다.
임의의 숫자가 아니라 생활 패턴에서 역산한다.

| 공백 | 길이 | 대응해야 할 행동 |
|---|---|---|
| **접속 중 대기** | 5~15분 | 소규모 이동, 건설 착수, 소전투 |
| **짧은 공백** | 30분~1시간 | 고속항로 1구간 이동 |
| **반나절 공백** | 3~4시간 | **회랑 돌파**, 성계 공략 |
| **근무·수면** | 8~10시간 | 대규모 원정, 장기 개발 |

> **핵심 명제:** 회랑 돌파는 **「한 번의 생활 공백」**이어야 한다.
> 접속 중에 끝나면 지형의 무게가 사라지고, 하루를 넘기면 답답해진다.

## 2. 시간 축 대응

### 2.1 실제 시간 ↔ 게임 내 시간

```
실제 1시간  =  게임 내 1개월
```

이 비율을 채택하면 **원전의 행군 속도와 자연스럽게 맞아떨어진다.**

| 행동 | 실제 시간 | 게임 내 시간 | 원전 대조 |
|---|---|---|---|
| 고속항로 1구간 | 45분 | 약 22일 | 강을 따라 인접 주로 행군 — 타당 |
| **회랑 돌파** | **3시간** | **약 3개월** | 한중 공방전·검각 대치 — **정확히 일치** |
| 기저 항로 1구간 | 4시간 | 약 4개월 | 야지 행군 — 타당 |

> 실시간 대기가 「게임적 장치」가 아니라 **「역사적 소요」**로 느껴진다는 것이 이 비율의 가치다.
> 플레이어는 기다리는 것이 아니라, 함대가 실제로 그만큼의 거리를 가고 있다고 인식한다.

### 2.2 캠페인 소요

| 항목 | 값 |
|---|---|
| 시나리오 1회 목표 진행 | 게임 내 10~15년 |
| 소요 실제 시간 | 120~180시간 |
| 하루 2시간 플레이 기준 | **약 2~3개월** |

라이브 서비스 전제(기획서 §6.3)에 부합하는 길이다.

## 3. 항행 시간표 (기준값)

### 3.1 이동

| 구간 유형 | 기준 소요 | 배율 |
|---|---|---|
| **고속항로 1구간** | **45분** | ×1 |
| 고속항로 + 관문 통과 | 68분 | ×1.5 |
| **회랑 (중회랑)** | **2시간 15분** | ×3 |
| **회랑 (대회랑)** | **3시간 45분** | ×5 |
| **기저 항로** | **3시간** | ×4 |
| 기저 항로 (원거리) | 4시간 30분 | ×6 |

**대회랑** — 검각 · 진령삼도 · 함곡 · 이릉 · 합비 · 정형 · 양번
**중회랑** — 호뢰 · 무관 · 기산도 · 노룡 · 오령 · 하서 · 남중산도

### 3.2 주요 원정 소요 (실측 예시)

| 원정 | 경로 | 총 소요 |
|---|---|---|
| **촉 북벌** | 한중 → [진령삼도] → 옹주 | **3시간 45분** |
| **촉 북벌(기산)** | 한중 → [기산도] → 양주 | 2시간 15분 |
| **위 남정(적벽)** | 사예 → 남양 → [양번] → 형주 | 약 5시간 30분 |
| **오 북상** | 오회 → [합비] → 회남 | **3시간 45분** |
| **성도 진공** | 한중 → [검각] → 익주 | **3시간 45분** |
| **등애 음평도** | 양주 → 익주 (비인접 침투) | 3시간 · **무탐지** |
| 최장 종단 | 양주 → 교주 | 약 14시간 |

> **의도된 결과:** 주요 전략 행동이 전부 **2~4시간** 구간에 모인다.
> 아침에 명령하면 점심에, 퇴근 전에 명령하면 저녁에 결과를 본다.

### 3.3 기타 행동

| 행동 | 소요 |
|---|---|
| 함대 편성·재편 | 즉시 |
| 소규모 전투 판정 | 3~5분 |
| 대회전 판정 | 15~30분 |
| 성계 외곽 제압 | 30분 |
| 궤도권 공략 | 1시간 30분 |
| 식민지 개별 공략 | 45분 |
| **지구형 행성 공략** | **4시간** |
| 함선 생산 (1전대) | 1시간 |
| 성계 개발 1단계 | 2~6시간 |

## 4. 시간 단축 — 정당한 수단

**속도는 구매하는 것이 아니라 전략의 결과여야 한다.**
아래는 전부 무과금 요소다.

| 수단 | 효과 | 근거 |
|---|---|---|
| **고속항로 장악** | 해당 구간 ×1 적용 | 지도 §2 — 항로를 쥔 자의 보상 |
| **오 세력 특성** | 전 항행 −20% | 기획서 §7 — 항행 기술 특화 |
| **하후연「신속」** | −40% (매복 피해 +30%) | 명장 #3 |
| **보급함 편성** | 연속 항행 가능, 감쇄 없음 | 지도 §3.3 규칙 ⑤ |
| **영거 운하 확보** | 오령회랑 소요 −50% | 지도 §2.2 |
| **관도망 정비** | 사예 기점 방사 구간 −25% | 내정 투자 |
| **등애「음평도」** | 비인접 침투 + 무탐지 | 명장 #27 |

> 회랑은 **어떤 수단으로도 ×1이 되지 않는다.** 물리적 험지이기 때문이다.
> 최대 단축은 −50%(영거 운하)이며, 이는 인공 수로라는 서사적 근거가 있는 예외다.

## 5. 수익 모델

### 5.1 문제 정의

기획서 §6.2에 명시된 리스크:

> ⚠ 실시간 대기는 과금 단축 구조로 흐르기 쉽다.
> 그 경우 주제축(「정통 vs 실력」)이 지갑 싸움으로 변질된다.

**이 게임의 주제는 「무엇이 통치의 정당한 근거인가」다.**
그 답이 「과금」이 되는 순간 작품이 무너진다.

### 5.2 권고 — 시간 단축 과금 전면 배제

| 구분 | 판정 |
|---|---|
| 항행 시간 단축 | **금지** |
| 회랑 돌파 단축 | **금지** |
| 건설·생산 단축 | **금지** |
| 전투 즉시 완료 | **금지** |

**근거 셋**

1. **주제 훼손.** 위 5.1 그대로다.
2. **지형 설계 무효화.** 성계지도 전체가 「어디를 막고 어디로 도는가」로 설계되어 있다. 시간을 살 수 있으면 회랑·항로·관문이 전부 무의미해진다.
3. **대체 수단 존재.** 이미 뽑기 구조가 설계되어 있다 (§5.3).

### 5.3 채택 권고 — 수익 축

| 축 | 내용 | 주제 훼손 여부 |
|---|---|---|
| **초빙권 뽑기** | 재야 인재 초빙권 (명장 150인은 뽑기 불가) | **없음** — 인물 v0.3 §8.6의 3중 판정이 방어. 천명 낮으면 뽑아도 거절당한다 |
| **시즌 패스** | 시즌 대전 참가 + 보상 트랙 | 없음 |
| **외형·연출** | 기함 도색, 함대 문양, 성역 문장, 전투 연출 | 없음 |
| **추가 시나리오** | 프롤로그 확장, IF 시나리오, 이역 캠페인 | 없음 |
| **편의 기능** | 편성 프리셋 슬롯, 명령 예약 슬롯 증설, 통계 조회 | 경미 — 상한 설정 필요 |

> **초빙권 뽑기가 안전한 이유:** 과금해도 **천명이 낮으면 인재가 붙지 않는다.**
> 돈으로 초빙 기회는 살 수 있으나 등용 성공은 살 수 없다.
> 과금이 전략을 대체하지 못하는 구조가 이미 인물 설계에 내장되어 있다.

### 5.4 폐기된 절충안

조건부 시간 단축 상품(회랑 제외 · 1일 상한 · 무과금 병존)을 검토했으나 **폐기한다.**

> 제약을 아무리 걸어도 **「돈 낸 쪽이 빠르다」는 인식은 남는다.**
> 그 인식 하나가 「정통 vs 실력」이라는 주제를 조용히 무너뜨린다.

## 6. 오프라인 진행과 UX

B+C 하이브리드(기획서 §6.2)가 성립하려면 다음이 전제된다.

| 요소 | 설계 |
|---|---|
| **오프라인 진행** | 미접속 중에도 항행·건설·개발 진행. **접속은 명령을 위한 것이지 진행을 위한 것이 아니다** |
| **명령 예약** | 취침 전 여러 단계 명령을 큐에 넣고, 아침에 결과 확인 |
| **푸시 알림** | 항행 완료 / 회랑 돌파 완료 / 적 함대 접근 / 전투 발생 / 인재 이탈 경고 |
| **자동 대응 규칙** | 「접경 성계 피습 시 자동 방어 배치」 등 사전 설정 |
| **3~5분 세션** | 알림 확인 → 결과 판단 → 다음 명령 발행. 이것으로 한 세션이 완결 |

> **회랑 돌파 3시간이 성립하는 조건이 오프라인 진행이다.**
> 접속해서 기다려야 한다면 3시간은 고문이지만,
> 명령만 내리고 나가면 3시간은 「점심 먹고 오면 도착해 있는」 적절한 간격이 된다.

## 7. 시즌 대전의 시간 압축

시즌 대전(수일~수주)에 캠페인 시간표를 그대로 쓰면 시즌이 끝나지 않는다.

| 모드 | 시간 배율 | 회랑 돌파 실제 소요 |
|---|---|---|
| **싱글 캠페인** | ×1 | 3시간 |
| **시즌 대전** | **×0.25** | **45분** |
| (검토) 단기 시즌 | ×0.15 | 27분 |

> 시즌은 「압축된 삼국지」다. 지형의 상대적 관계는 유지하되 절대 시간만 줄인다.
> 회랑이 여전히 고속항로의 5배라는 점은 변하지 않는다.

## 8. 확정 사항

| # | 항목 | 확정값 |
|---|---|---|
| 1 | 실제↔게임 시간 비율 | **1시간 = 게임 내 1개월** |
| 2 | 고속항로 기준값 | **45분** |
| 3 | 대회랑 기준값 | **3시간 45분** / 중회랑 2시간 15분 |
| 4 | 기저 항로 기준값 | **3시간** (원거리 4시간 30분) |
| 5 | **시간 단축 과금** | **전면 배제 — 예외 없음** |
| 6 | 수익 축 | 초빙권 뽑기 · 시즌 패스 · 외형/연출 · 추가 시나리오 · 편의 기능(상한) |
| 7 | 시즌 시간 배율 | **×0.25** (회랑 돌파 45분) |
| 8 | 오프라인 진행 | **필수 전제.** 접속은 명령을 위한 것이지 진행을 위한 것이 아니다 |

### 8.1 불가침 원칙

향후 밸런싱·수익화 논의에서 다음 세 가지는 재론하지 않는다.

> **① 시간은 판매 대상이 아니다.**
> 속도는 전략의 결과여야 한다 — 항로 장악, 세력 특성, 인물 특성, 보급 편성.
>
> **② 회랑은 어떤 수단으로도 ×1이 되지 않는다.**
> 물리적 험지이기 때문이다. 유일한 예외는 영거 운하(−50%)이며, 인공 수로라는 서사적 근거가 있다.
>
> **③ 과금으로 초빙 기회는 살 수 있으나 등용 성공은 살 수 없다.**
> 천명이 낮으면 인재가 붙지 않는다 (인물 v0.3 §8.7 3중 판정).

> **§5.4 절충안(조건부 시간 단축 상품)은 폐기한다.**
