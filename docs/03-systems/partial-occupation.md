> 성계지도 §5의 구체화 문서
> 작성일: 2026-08-20 / 상태: 제안 — 검토 요망

## 0. 왜 필요한가

성계를 통째로만 주고받으면 다음이 표현되지 않는다.

| 원전 사건 | 통째 점령으로는 |
|---|---|
| **손유 형주 분할** (208~219) | 표현 불가 — 형주는 한 세력의 것이 되어버린다 |
| 관우의 형주 상실 | 「형주를 잃었다」로 뭉개짐. 강릉·공안만 잃은 것인데 |
| 맹달의 상용 이탈 | 표현 불가 |
| 합비 공방 | 회남 전체를 걸어야 함 |
| **지구 분단** | 태양계 배치의 핵심 매력 소멸 |

## 1. 점령 단위 — 권역(圈域)

### 1.1 계층 재정의

성계지도 §5의 4층 구조는 **공략 순서**를 정의한다.
점령 단위는 그와 별개로 **권역(圈域)**으로 정의한다.

```
성계(星系)  =  2~4개 권역(圈域)
   권역     =  지구형 행성 0~1  +  식민지 1~4  +  궤도 시설
```

**19개 성계 × 평균 2.4 = 약 45개 권역.**
성계 단위(19)보다는 세밀하고, 개별 거점 단위(130+)보다는 관리 가능하다.

### 1.2 주권역(主圈域)

각 성계에는 **치소(治所)가 놓인 주권역**이 하나 있다.

| 규칙 | 내용 |
|---|---|
| 명목 지배권 | 주권역을 쥔 세력이 해당 **성역의 목(牧)·자사(刺史)를 임명**한다 |
| 표기 | 지도·외교 화면에서 성계의 소속 세력으로 표시된다 |
| 실질 | 명목일 뿐이다. 타 권역의 생산·항로 통제는 실제 점령자에게 귀속된다 |

> **원전 재현:** 208년 이후 위는 형주자사를 임명했으나
> 강릉은 오가, 남부 4군은 유비가 쥐고 있었다.
> 명목과 실질의 괴리가 그대로 시스템이 된다.

## 3. 항로 통제 — 핵심 규칙

> **회랑·관문·고속항로는 특정 권역에 귀속된다.**
> **그 권역을 쥔 세력이 통행을 통제한다.**

| 통제 대상 | 귀속 권역 |
|---|---|
| 함곡관문 | 사예 장안권 |
| 호뢰관문 | 사예 낙양권 |
| **양번관문** | 형주 북부권 · 남양 신야권 |
| **장강 대항로(형주 구간)** | 형주 중부권 |
| **이릉협도** | 형주 중부권 · 익주 파군권 |
| **합비회랑** | 회남 합비권 · 양주揚 건업권 |
| **검각회랑** | 한중 남정권 · 익주 재동권 |
| 진령삼도 | 한중 남정권 · 옹주 장안서부권 |
| 기산도 | 한중 남정권 · 양주涼 무위권 |
| 무관회랑 | 남양 완권 · 옹주 장안서부권 |
| 정형회랑 | 기주 한단권 · 병주 진양권 |
| 노룡회랑 | 유주 어양권 · 요동 양평권 |
| 하서회랑 | 양주涼 돈황권 |
| 오령회랑 · 영거운하 | 형주 남부권 · 교주 교지권 |

### 3.1 전략적 파급

**한 권역만 빼앗아 항로를 끊을 수 있다.**

| 사례 | 효과 |
|---|---|
| 형주 **중부권** 탈취 | 장강 대항로 절단 → 익주와 양주(揚)가 분리됨 |
| 회남 **합비권** 탈취 | 오의 북상 경로 봉쇄 |
| 한중 **남정권** 탈취 | 촉의 북벌 경로 3개 동시 차단 |
| 양주涼 **돈황권** 탈취 | 서역·로마 접촉 경로 독점 |
| 형주 **북부권** 상실 | 한수 연결로 단절 → 남북 대항로 연결 붕괴 |

> **관우의 북벌이 양번을 노린 이유**가 시스템으로 설명된다.
> 북부권을 얻으면 한수 축이 열리고, 잃으면 형주가 남북으로 갈린다.

## 4. 보급과 비지(飛地)

### 4.1 보급 사슬

```
권역은 아군 권역과 「연결」되어 있어야 정상 기능한다.
연결 = 인접 권역 중 아군 소유가 하나 이상 존재
```

| 상태 | 효과 |
|---|---|
| **연결** | 정상 |
| **비지(飛地)** — 고립 | 생산 −50%, 병력 보충 불가, 유지비 2배 |
| **장기 고립** | 민심 하락 → 자동 이탈 또는 독립 |

> **맹달의 상용 이탈**이 이 규칙으로 재현된다.
> 상용권은 한중 남정권과 남양을 통해서만 이어지므로, 양쪽을 잃으면 고립된다.

### 4.2 항로 봉쇄와 보급

적이 항로 귀속 권역을 쥐면 **그 항로를 통한 보급이 차단**된다.
비지가 아니어도 보급 효율이 떨어진다.

## 6. 태양계권과 「원향(元鄕)」

지구·화성·달은 **형주 태양계권**에 함께 속한다.

| 상태 | 효과 |
|---|---|
| **태양계권 전체 보유 + 개발도 임계** | 「원향」 발동 — 천명 상승 |
| 일부만 보유 | **발동하지 않음** |
| **타 세력과 분점 상태** | **「고향이 갈렸다」 이벤트 — 양측 모두 천명 소폭 하락** |
| 장기 황폐 방치 | 보유 세력 천명 하락 |

> **분단은 아무도 이득을 보지 못한다.**
> 지구를 반으로 갈라 쥐고 있는 동안 위와 오 모두 명분을 잃는다.
> 「통일 vs 분권」 주제축에 대한 가장 날카로운 질문이 여기서 나온다 —
> **갈라 가진 채 유지하는 평화가 과연 답인가.**

## 7. 원전 재현 검증

### 7.1 형주 분할 (215년 상수 협정)

| 권역 | 소유 | 실제 효과 |
|---|---|---|
| 북부권 (양양·번성) | **위** | 양번관문 통제. 주권역이므로 형주자사 명목 보유 |
| 중부권 (강릉·강하) | **오** | 장강 대항로 통제 |
| 남부권 (장사·계양) | **오** | 상수 이동(以東) 할양 |
| 남부권 (무릉·영릉) | **촉** | 상수 이서(以西) |
| **태양계권** | **분점** | 위·오 양측 천명 하락 지속 |

> 세 세력이 한 성계를 나눠 갖는 상태가 그대로 성립한다.

### 7.2 관우의 형주 상실 (219년)

```
관우: 북부권 공략 중 (양번 포위)
  ↓  여몽「백의도강」 — 중부권 기습
관우: 중부권 상실 → 남부권과의 연결 끊김 → 비지화
  ↓
북벌군 보급 차단 · 퇴로 상실
```

> 「형주를 잃었다」가 아니라 **「중부권을 잃어 나머지가 고립됐다」**로 정확히 재현된다.

### 7.3 한중 공방 (219년)

유비가 한중 **남정권**을 얻는 순간 진령삼도·기산도·검각이 모두 열린다.
반대로 조조는 상용권만 남겨 비지 상태가 되고, 맹달 이탈 이벤트가 발동한다.

## 8. UI 부담 완화

부분 점령의 최대 리스크는 **모바일 화면의 정보 과부하**다.

| 계층 | 표시 |
|---|---|
| **기본 뷰** | 19개 성계 노드. 노드 색을 **점유 비율 파이**로 표시 |
| **성계 뷰** | 확대 시 2~4개 권역 표시. 권역별 소유·생산·항로 |
| **권역 뷰** | 개별 거점, 공략 진행도 (전투 시에만 진입) |

| 완화 장치 | 내용 |
|---|---|
| **분쟁 표식** | 두 세력 이상이 나눠 가진 성계에만 경고 아이콘 |
| **자동 방어 규칙** | 권역별 사전 설정 (기획서 §6.2 오프라인 UX와 연동) |
| **일괄 명령** | 성계 단위 명령 → 하위 권역 자동 배분 |
| **비지 경고** | 고립 위험 권역 자동 알림 |

## 9. 부가 시스템 — 할양과 반환

부분 점령이 있어야 성립하는 외교 행위.

| 행위 | 내용 |
|---|---|
| **할양(割讓)** | 권역 단위 양도. 동맹 조건으로 사용 |
| **반환 요구** | 「형주를 돌려달라」 — 거부 시 관계 악화, 수용 시 천명 상승 |
| **차용(借用)** | 기한부 점유. 기한 초과 시 천명 하락 |

> **유비의 「형주 차용」**이 정식 시스템이 된다.
> 빌린 상태로 두면 천명이 깎이고, 돌려주면 국력을 잃는다.
> 「정통 vs 실력」 주제축이 외교 화면에서 작동한다.
