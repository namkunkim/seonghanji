# 星漢志 — 외교·동맹 시스템 설계 v0.1

> 기획서 §2.3 / 인물 설계 v0.5 §8·§14의 확장 문서
> 작성일: 2026-08-20 / 상태: 초안 — 검토 요망

---

## 0. 설계 공백

현 설계에서 외국 세력은 전부 **일방적 대상**이다.

| 기존 관계 | 성격 |
|---|---|
| 회유 | 이쪽이 달래는 대상 |
| 용병 고용 | 이쪽이 돈으로 사는 자원 |
| 교역 | 이쪽이 이득을 취하는 통로 |
| 변경 압력 | 이쪽이 막아내는 위협 |

**대등한 동맹 상대가 없다.**
손유 동맹처럼 서로 필요해서 맺고, 이해가 어긋나면 깨지는 관계가 외부에는 하나도 없다.

> 본작의 주제는 「정통 vs 실력」과 「통일 vs 분권」이다.
> **외세와 손잡는 것은 실력을 얻고 정통을 잃는 선택**이며,
> 이 거래가 성립하려면 외세가 **거래 상대**여야 한다.

## 1. 정식 동맹 세력 — 둘

### 1.1 선정 기준

| 기준 | 내용 |
|---|---|
| **대등성** | 회유·고용 대상이 아니라 자기 이해를 가진 주체여야 한다 |
| **접근성** | 지도상 명확한 도달 경로가 있어야 한다 |
| **서사 근거** | 원전에 동맹·교섭 기록이 존재해야 한다 |
| **대비** | 둘이 서로 다른 성격이어야 선택이 발생한다 |

### 1.2 선정 결과

| 세력 | 성격 | 주 이용 세력 |
|---|---|---|
| **동이 연합(東夷聯合)** | 가깝고 강하되 **믿을 수 없다** | 오 · 변경 군벌 |
| **대월지(大月氏, 쿠샨)** | 충실하되 **지켜줘야 한다** | 위 (하서회랑 보유) |

> **사산조 페르시아는 동맹 대상에서 제외한다.**
> 한-사산조 교섭은 실제 기록이 희박하여 고증 근거가 약하다.
> 사산조는 **대월지를 잠식하는 서방의 위협**으로 배치한다 (§3.5).

## 2. 동이 연합 — 근거리 동맹

### 2.1 구성

요동 공손씨를 축으로 고구려·부여·왜·삼한이 **느슨하게 묶인 연합체**.
단일 국가가 아니라 **맹주가 대표하는 협의체**다.

| 구성원 | 역할 | 대표 인물 |
|---|---|---|
| **요동 공손씨** | 맹주. 대외 창구 | 공손도 · 공손강 · **공손연** |
| **고구려** | 최대 군사력 | 산상왕 · 동천왕 · 밀우 · 유유 |
| **부여** | 공손씨와 혼인 동맹 | 위구태 · 간위거 |
| **왜(倭)** | 해상 세력 | 히미코 · 난승미 |
| 삼한·예·옥저 | 주변 소세력 | 고이왕 · 진충 · 석우로 |

> **부여 위구태는 공손도의 사위**다 (인물 v0.5 §8.9).
> 연합의 결속에 실제 근거가 있다.

### 2.2 동맹의 논리

**위가 화북을 통일하면 요동이 다음 차례다.**
공손씨는 위를 견제할 세력을 필요로 하고, 오는 위의 배후를 흔들 수단을 필요로 한다.

> **원전 근거 (233년):**
> 손권이 공손연에게 사신을 보내 **연왕(燕王)으로 책봉**했다.
> 공손연은 그 사신들의 **목을 베어 위에 바쳤다.**
> — **동맹이 배신으로 끝난 실화가 이미 존재한다.**

### 2.3 게임적 효과

| 효과 | 내용 |
|---|---|
| **양면 압박** | 오가 동이와 동맹하면 위는 **유주 병력을 묶어둬야 한다** |
| 용병 개방 | 고구려 개마무사 · 부여 궁기 · 왜 수군 (v0.5 §14.3④) |
| 해상 경로 | 왜를 경유한 우회 항행 — 노룡회랑 봉쇄 시에도 접촉 유지 |
| 인물 접근 | 동이권 인물 27인 뽑기 풀 개방 |
| **천명 비용** | **소** — 변경 군벌의 관행 수준 |

### 2.4 리스크 — 배신

| 조건 | 결과 |
|---|---|
| 상대 세력이 **더 나은 조건 제시** | 배신 판정 발생 |
| 동맹국이 **명백한 열세**에 놓임 | 배신 확률 급상승 |
| 공손연 보유 시 | **배신 확률 최대** — 「양단(兩端)」 특성 |
| 배신 발동 | 파견 사절 처형 · 군사 정보 유출 · 즉시 적대 전환 |

> **공손연「양단」특성 신설:** 두 세력과 동시에 교섭할 수 있으며,
> 유리한 쪽에 다른 쪽의 정보를 판다. 원전 그대로다.

## 3. 대월지(大月氏) — 원거리 동맹

### 3.1 성격

**쿠샨 제국.** 서역 너머의 교역 대국이자 불교 전파의 중심.

| 인물 | 시기 | 역할 |
|---|---|---|
| **파조(波調) / 바수데바 1세** | 190~230 | **위(魏)로부터 「친위대월지왕」 책봉을 받음** |
| 카니슈카 2세 · 바시슈카 | 3C중 | 후계 왕. 사산조 압박 하 |
| **지겸 · 지루가참** | 후한말~3C | **대월지계 역경승.** 실제로 낙양·건업에서 활동 |
| 나가르주나(龍樹) | ~250 | 인도 중관파. 사상 계통 |

### 3.2 결정적 차이 — 책봉(冊封) 관계

> **원전 근거 (229/233년):**
> 대월지왕 파조가 위(魏)에 사신을 보냈고,
> 위는 그를 **「친위대월지왕(親魏大月氏王)」**으로 책봉했다.

**이것은 대등한 동맹이 아니라 상하 책봉 관계다.**
그리고 그 사실이 게임 설계에서 결정적이다.

| 관계 유형 | 천명 영향 |
|---|---|
| 외세를 끌어들임 (사산조·로마) | **감소** — 매국 |
| **외국을 신하로 책봉함 (대월지)** | **상승** — 천자의 권위 행사 |

> 대월지 동맹은 **천명을 잃지 않고 얻는 유일한 대외 관계**다.
> 「먼 나라가 스스로 찾아와 신하를 칭했다」는 것은
> 한제국의 정통성을 입증하는 사건이기 때문이다.
> **정통 노선 플레이어가 쓸 수 있는 유일한 외교 카드가 된다.**

### 3.3 접근 경로

```
중원 ── [하서회랑] ── 서역 ── 대월지(쿠샨)
```

**하서회랑(양주涼 돈황권)을 쥔 세력만 접촉 가능하다.**
통상적으로 **위 전용 카드**이며, 창자「돈황」 보유 시 조건이 완화된다.

### 3.4 게임적 효과

| 효과 | 내용 |
|---|---|
| **천명 상승** | 책봉 성립 시 일시 상승 + 유지 중 소폭 지속 상승 |
| 교역 수입 | 서역 항로 통행세 + 사치재 — 수입 규모 최대 |
| **사상 전파** | 역경승 계통 인물 개방 (지겸·지루가참·강승회·안세고) |
| 서역 안정 | 서역 소국들의 이탈·약탈 이벤트 감소 |
| 용병 | 쿠샨 중장기병 — 소규모, 고비용 |
| **군사 지원** | **약함.** 거리가 멀어 직접 참전이 사실상 불가 |

### 3.5 리스크 — 지켜줘야 하는 동맹국

대월지는 배신하지 않는다. 대신 **스스로 무너진다.**

| 시기 | 사건 |
|---|---|
| 224~ | 사산조 아르다시르 1세 건국. 서부 잠식 시작 |
| 240~ | **샤푸르 1세의 대규모 침공.** 대월지 서부 상실 |
| 3C 중반 | 쿠샨 쇠퇴. 사산조의 속국화 |

| 플레이어 대응 | 결과 |
|---|---|
| **원조 파견** (자금·물자) | 대월지 존속 기간 연장. 천명 유지 |
| **방치** | 대월지 붕괴 → 책봉 관계 소멸 → **천명 하락 (신하를 지키지 못한 천자)** |
| 서역 직접 개입 | 막대한 비용. 하서회랑 너머 원정은 사실상 불가능 |

> **「신하를 지키지 못한 천자」**라는 페널티가 이 동맹의 핵심 긴장이다.
> 책봉으로 얻은 정통성은, 그 신하가 무너질 때 되돌려 갚아야 한다.
> 값싼 명분이 아니라 **책임을 동반한 명분**이다.

### 3.6 로마·사산조의 위상

두 세력은 **교섭 불가 대국**으로 남는다.

| 세력 | 성격 |
|---|---|
| **로마** | 배경 압력 + 교역 상대(진론 사례). 동맹 불가 — 체급 차 |
| **사산조** | **위협.** 대월지를 잠식하며 서서히 다가온다 |

> 동맹 가능한 대상과 불가능한 대상이 분리되어야 세계의 깊이가 생긴다.
> **손잡을 수 없는 존재가 있어야 손잡을 수 있는 존재의 가치가 나온다.**

## 4. 두 동맹의 대비

| | **동이 연합** | **대월지** |
|---|---|---|
| 거리 | 가까움 — 노룡회랑 | 멂 — 하서 → 서역 |
| 관계 성격 | 대등한 동맹 | **책봉(상하)** |
| **천명** | **소폭 감소** | **상승** |
| 신뢰도 | **낮음 — 배신 리스크** | 높음 — 배신하지 않음 |
| 군사 지원 | **강함** — 개마무사·궁기·수군 | 약함 — 거리 문제 |
| 경제 | 보통 | **최대** — 서역 교역 |
| 주 이용 세력 | 오 · 변경 군벌 | 위 |
| 고유 리스크 | 배신 · 사절 처형 | **붕괴 — 방치 시 천명 하락** |
| 한 줄 | **쓸모 있지만 배신하는 이웃** | **충실하지만 지켜줘야 하는 먼 속국** |

> **선택의 구조:** 실력 노선은 동이 연합의 군사력을 취하고 배신을 감수한다.
> 정통 노선은 대월지 책봉으로 명분을 얻되, 그 신하를 지킬 책임을 진다.
> **촉은 둘 다 닿지 않는다** — 「고립된 정통」의 일관성 (인물 v0.5 §13.2).

## 4.5 중원 세력 간 동맹 [v0.2 확장]

> ⚠ **본 문서 §1~4는 「외국 세력」과의 동맹만 다뤘다.**
> **손유 동맹 같은 중원 세력 간 동맹 시스템이 비어 있었다.**

**§5의 4단계(통교→화친→맹약→군사동맹)를 중원 세력 간에도 동일 적용한다.**
단 **천명 감소는 없다** — 같은 한(漢)의 신하끼리 손잡는 것이므로.

**AllianceTrust (동맹 신뢰도)** — 시나리오 2·3 정합화 문서 §1.2에서 신설

```
약속 이행 · 공동 전투 · 영토 분배 · 정보 공유
· 인물 관계 · 외교 행동 · 배신 기록(영구 계승)
```

> **208년의 신뢰도가 219년 형주 문제로 계승된다.**
> 「동맹은 승리하는 순간부터 깨지기 시작한다.」

## 5. 동맹 단계 시스템

외교 관계를 4단계로 정의한다. 상위 단계일수록 얻는 것과 치르는 것이 모두 커진다.

| 단계 | 명칭 | 획득 | 대가 | 파기 가능성 |
|---|---|---|---|---|
| 1 | **통교(通交)** | 사절 왕래, 정보 열람 | 없음 | 자유 |
| 2 | **화친(和親)** | 교역 개통, 불가침 | 소액 세폐(歲幣) | 낮은 페널티 |
| 3 | **맹약(盟約)** | 용병 고용 개방, 기술 이전 | 세폐 증액 + **천명 감소 개시** | 천명 하락 |
| 4 | **군사동맹** | **공동 출병**, 양면 작전 | 세폐 최대 + 천명 지속 감소 + **참전 의무** | **큰 천명 하락 + 배신 낙인** |

### 5.1 참전 의무

군사동맹 단계에서 동맹국이 침공받으면 **참전 요청**이 발생한다.

| 대응 | 결과 |
|---|---|
| 참전 | 병력 소모. 동맹 신뢰도 상승 |
| 거부 | **동맹 신뢰도 급락 → 배신 확률 상승.** 천명 소폭 하락 |

### 5.2 배신 판정

```
배신 확률 = 기본치
          + (상대 세력의 제시 조건 우위)
          + (자국의 열세 정도)
          + (참전 거부 누적)
          − (신뢰도 · 인질 · 혼인 동맹)
```

| 억제 수단 | 효과 |
|---|---|
| **인질(質子)** | 배신 확률 대폭 감소. 원전의 표준 관행 |
| **혼인 동맹** | 지속적 신뢰도 보정 (부여 위구태 사례) |
| 세폐 증액 | 일시적 억제 |
| **염유「호중」** | 동이권 배신 판정 무효 |

## 6. 인물 연동

| 인물 | 효과 |
|---|---|
| **공손연「양단」** | 동이 연합 맹주 시 **양측과 동시 교섭.** 배신 확률 최대 |
| **염유「호중」** | 동이·북적 배신 판정 무효 |
| **진론「대진상인」** | 로마 직접 교섭 개통 (오 전용 경로) |
| **창자「돈황」** | **서역·대월지 접촉 조건 완화.** 책봉 성립의 실질 조건 |
| **마량「백미」** | 이민족 교섭 성공률 +40% |
| **노숙「천하이분」** | **동맹 유지 시 양측 이익 +25%** — 대외 동맹에도 적용 |
| **가후「독사」** | 동맹 세력 간 이간 공작 가능 |

> **노숙의 재해석:** 원전에서 손유 동맹을 설계한 인물이다.
> 「천하이분」을 대외 동맹에도 적용하면, 노숙 보유 여부가 외교 노선의 전제가 된다.

## 7. 원전 재현

| 사건 | 시스템 재현 |
|---|---|
| **손권의 공손연 책봉 (233)** | 오 → 동이 연합 **군사동맹** 체결 |
