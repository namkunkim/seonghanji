## 0. 설계 원칙

기획서에서 확정된 대응 규칙을 그대로 적용한다.

| 원전 | 본작 | 비고 |
|---|---|---|
| 1주 | **1성계** = 1성역 | 성역은 행정 명칭, 성계는 천체 단위. 동일 대상 |
| 주요 도시·대군 | **지구형 행성 1~2개** | 자연 거주 가능. 인구·생산의 중심 |
| 군·현·요새 | **테라포밍 식민지 · 궤도 도시 · 인공시설** | 다수 배치 |
| 험로·관 | **회랑** | 통과 강제, 소수로 대군 저지 |
| 대하·관도 | **고속항로** | 이동 시간·에너지 대폭 절감 |
| 그 외 | **저효율 공간** | 항행 소요 과다 |

**핵심 명제:** 지형이 곧 게임 템포다(기획서 §6.2).
회랑 돌파에는 실시간이 소요되고, 고속항로를 쥐면 그 시간이 단축된다.

### 1.1 특급 성계의 성격

| 성계 | 특급인 이유 |
|---|---|
| **사예** | 황제 소재. 정통성의 물리적 위치(기획서 §4). 황하·위수 항로 결절 |
| **기주** | 최대 인구·생산력. 원소의 기반이자 조조의 심장부 |
| **익주** | 회랑으로 완전 봉쇄 가능한 유일 성계. 「험지와 명분」의 촉 특성 근거 |
| **형주** | **남북 대항로의 유일 교차점.** 천하의 목구멍이자 **인류의 고향(태양계)** 소재지 |
| **오회** | 장강 하류 종점. 합비 관문 보유. 오의 존립 기반 |
| **한중** | **회랑 3개가 모이는 최다 접경 성계.** 익주의 목구멍이자 관중 진출의 발판. 작지만 이곳을 잃으면 촉은 방어에 갇히고, 얻으면 북벌이 성립한다 |

### 1.2 신설 성계의 성격

| 성계 | 전략적 의미 |
|---|---|
| **남양** | 사예·형주·옹주가 만나는 결절. 무관회랑의 종점. 후한 최대 인구군이라 자체 국력도 크다 |
| **회남** | 합비회랑을 보유. **오의 북상은 반드시 이곳을 지난다.** 원술 칭제 이벤트의 무대 |
| **요동** | 노룡회랑 하나로만 중원과 이어지는 **회랑 전용 성계**. 동이권 인물의 접점 |
| **남중** | 익주의 후방. 안정화 없이는 촉의 북벌이 성립하지 않는다 |

## 1.3 태양계 — 형주 성역

> **인류의 고향은 천하의 목구멍에 있다.**

| 천체 | 공식 표기 | 통칭 | 현 상태 |
|---|---|---|---|
| **지구** | 형주성역 구지 | 옛땅, 고향별 | 전화로 황폐. 소유권이 끊임없이 바뀜 |
| **화성** | 형혹 | 화성 | 테라포밍 식민지. 강릉 권역에 인접 |
| **달** | 태음 | 달 | 고대 조선소. 손상·복구를 반복 |

### 배치 근거

지구를 변방(청주·요동)에 두는 안은 **주제적으로는 아름다우나 게임적으로 죽은 땅**이 된다.
200년 이후 청주는 손바뀜이 거의 없고, 촉과 오는 게임 내내 지구를 한 번도 보지 못한다.
**세력 3분의 2에게 존재하지 않는 콘텐츠**가 되는 것이다.

형주 배치는 다섯 기준을 모두 충족한다.

| 기준 | 형주의 충족 |
|---|---|
| **쟁탈 빈도** | 원전에서 가장 많이 손바뀐 성계 — 유표 → 조조 → 손유 분할 → 관우 → 여몽 → 이릉 → 오 |
| **세력 형평성** | **삼국이 모두 접근 가능한 유일 성계.** 익주는 촉만, 청주는 위만 닿는다 |
| **전 구간 활성** | 190~263 내내 조용한 적이 없다 |
| **시스템 결합** | 부분 점령 빈도 최고 · 회랑 3개 · 남북 대항로 교차점 |
| **주제 기여** | 「잊힌 고향」이 「짓밟히는 고향」으로 전환 |

> **왜 하필 형주가 천하의 목구멍인가** — 인류가 여기서 퍼져나갔기 때문이다.
> 항로가 여기 모이는 이유가 지리가 아니라 역사에 있다는 설명이 성립한다.

### 서사적 파급 — 기존 사건의 격상

새 이벤트를 만들 필요가 없다. **기존 사건의 무게가 한 단계씩 올라간다.**

| 원전 사건 | 본작에서의 의미 |
|---|---|
| **적벽대전** | 오림·강하는 형주 성계 내부 — **지구 궤도에서 벌어지는 대회전** |
| **관우 북벌** | 고향을 지키기 위한 진격 |
| **여몽의 백의도강** | 위장 항행을 통한 **지구 탈취** |
| **이릉대전** | 고향을 되찾으려다 실패하는 이야기 |
| **유비의 「형주 차용」** | **「고향을 잠시 맡는다」** — 정통성 주장의 근거이자 약점 |
| **손유 형주 분할** | **지구는 오가, 화성은 위가 쥔** 분단 상태 (부분 점령 시스템) |

### 주제 기여

「통일 vs 분권」 축이 강화된다.
지구를 반으로 갈라놓은 채 병립을 유지하는 것이 과연 답인가 — 이 질문이 성립한다.

> **인류의 고향이 전장이 되었다.** 모두가 지나가는 길목이라 전화가 끊이지 않는다.
> 「잊힌 고향」보다 「짓밟히는 고향」이 더 비극적이고, 무엇보다 **플레이어가 실제로 겪는다.**

### 게임 내 처리

| 요소 | 효과 |
|---|---|
| **「원향」** | 구지 보유 + 개발도 임계 시 천명 상승. **보너스는 낮게 설정** |
| **황폐도** | 전화가 반복될수록 누적. 복구에 장기 투자 필요 |
| **방기** | 황폐 상태 방치 시 천명 소폭 하락 |
| **고대 조선소** | 태음(달) 시설 복구 시 특수 함종 생산 (미설계) |
| **전략 가치** | **의도적으로 낮게.** 상징 가치만 남기고 실리는 주지 않는다 |

> **형주 과부하 대응:** 형주는 이미 특급이며 천하의 목구멍이다.
> 지구까지 얹으면 한 성계에 비중이 몰리므로,
> 「원향」 보너스를 낮게 잡아 **상징적 가치만 남기고 실리는 배제**한다.
> 지구를 갖는 것은 명분이지 국력이 아니다.

## 2. 고속항로 

### 2.1 2대 간선

**① 황하 대항로 — 동서 북부축**

```
양주 ── 옹주 ── 사예 ── 연주 ── 청주
              │        │
           [위수지선] [관도망]
```

- 화북 전체를 관통하는 최대 동맥
- 사예에서 **관도망**과 접속 → 기주·예주로 방사
- **장악 효과:** 화북 전역의 병력 전개 속도 대폭 상승

**② 장강 대항로 — 동서 남부축**

```
익주 ── 형주 ── 오회
   │       │
[이릉협도] [한수지선]
```

- 남중국 전체를 관통
- 상류(익주)에서 하류(양주)로 **순류 이동 시 추가 가속**, 역류 시 감속
- **장악 효과:** 오의 기동력 특성(기획서 §7)의 물리적 근거

### 2.2 연결 지선

| 지선 | 구간 | 전략 의미 |
|---|---|---|
| **한수 연결로** | 한중 ── 형주(양양) | **남북 두 대항로를 잇는 유일 통로.** 형주와 한중이 함께 특급인 이유 |
| **위수 항로** | 옹주 ── 사예 | 관중과 중원의 연결 |
| **회수 항로** | 예주 ── 서주 ── 오회 | 위·오 대치선. 합비 관문과 연동 |
| **관도망** | 낙양 중심 방사 (업·허·완·장안) | 사예 장악 시 중원 전역 신속 전개 |
| **영거 운하** | 형주 ── 교주 | **오령회랑 내부에 부설된 인공 수로.** 확보 시 회랑 통과 소요 대폭 단축 |

### 2.3 지도 개형

```
                     [유주] ══ 노룡회랑 ══ 요동
                        ║
        [병주] ═정형═ [기주] ═══ [청주]
           ║              ║          ║
        [옹주] ═함곡═ [사예] ═호뢰═ [연주]
        ╱   ║              ║          ║
   [양주]  ║           [예주] ═══ [서주]
      ║   진령삼도           ║          ║
  하서회랑   ║            (회수항로)     ║
      ║   [한중]              ║          ║
   (서역)    ║ 검각             ╲       ╱
           [익주] ══이릉══ [형주] ═합비═ [오회]
              ║                ║              ║
           남중산도          오령회랑      (동해 변경)
              ║                ║
           [남중]           [교주]

  ═══ 고속항로   ══회랑══ 통과 강제 험지
```

## 3. 회랑  — 통과 강제 험지

### 3.1 대회랑 (전략 등급)

| 회랑 | 연결 | 원전 근거 | 게임 효과 |
|---|---|---|---|
| **함곡회랑** | 사예 ↔ 옹주 | 함곡관·동관 | 소수 방어 시 공격측 손실 3배. 포격함 압도적 |
| **검각회랑** | 한중 ↔ 성도 | 검각·금우도 | **일부무당관.** 방어 병력 1/10로 저지 가능 |
| **진령삼도** | 옹주 ↔ 한중 | 자오도·야곡도·산관도 | **3개 경로 중 택1.** 선택 은닉 가능 → 위연「자오곡」 연동 |
| **이릉협도** | 익주 ↔ 형주 | 장강 삼협 | 함대 종렬 강제. **화공 계열 피해 최대 3배** → 이릉대전 재현. 배율은 협도 너머 대치 기간이 정한다(`combat.md` §5.5-b) |
| **합비회랑** | 오회 ↔ **회남** | 합비·소호 | **오의 북상은 반드시 이곳을 지난다.** 장료「소요진」(#15) 발동 지점 |
| **양번관문** | 형주 ↔ **남양** | 양양·번성 | 한수 축의 관문. 관우 북벌의 표적 |
| **정형회랑** | 기주 ↔ 병주 | 태행팔형 | 대군 통과 불가. 우회 시 태행동로(저효율) |

### 3.2 중회랑

| 회랑 | 연결 | 원전 근거 | 특징 |
|---|---|---|---|
| **호뢰관문** | 사예 ↔ 연주·예주 | 호뢰관·사수관 | 낙양 동쪽 방벽. 시나리오 1 반동탁연합 무대 |
| **관도관문** | 사예·연주 ↔ **기주** | 관도·백마·연진 | 황하 도하점. **시나리오 2 관도대전의 무대.** 전개 제한 2~3 으로 원소의 수적 우위를 상쇄한다 |
| **무관회랑** | 옹주 ↔ **남양** | 무관 | 관중 남측 진출로. 남양 분리로 종점이 명확해짐 |
| **기산도** | 옹주 서부 ↔ 한중 | 기산 | **촉 북벌의 정규 경로.** 학소「진창」(#136) 대응 지점 |
| **노룡회랑** | 유주 ↔ 요동 | 노룡새·백랑산 | 동이 연합 진입로. 답돈(#147) 전장 |
| **오령회랑** | 형주 ↔ 교주 | 오령 | 남방 격리. 영거 운하 미확보 시 필수 경로 |
| **하서회랑** | 양주 ↔ 서역 | 하서주랑 | **서방권(로마) 접촉의 유일 관문**(§8.9 연동) |
| **남중산도** | 익주 ↔ 남중 | 노수·오도 | 맹획(#116) 전장. 촉의 후방 |

> ⚠ **2026-08-28 정정.** 관도관문 행이 **「대회랑」**이라 적고 있었다.
> `corridors.json` 의 COR-09 는 배율 **×3.0 — 중회랑**이며 이 표에 실려 있다.
> **회랑의 등급도 소속도 이름이 아니라 `corridors.json` 15종이 정한다** (V-36).
> 「관도관문」·「진령삼도」처럼 **이름에 「회랑」이 없는 것이 넷** 있고,
> 그중 **진령삼도·이릉협도는 대회랑**이다.

### 3.3 회랑 시스템 규칙

```
① 통과 강제      회랑이 존재하는 인접쌍의 이동은 반드시 회랑을 경유한다.
                 우회 항로는 존재하지 않는다.
② 전개 제한      회랑 내 동시 전개 가능 함대 수 상한 (대회랑 1~2, 중회랑 2~3)
③ 함종 보정      포격함 +60% / 강습모함 -40% / 전열함 진형 페널티
④ 실시간 소요    돌파에 실제 시간 소요. 고속항로 대비 3~5배
⑤ 보급 부담      회랑 내 체류 시 보급 소모 2배 → 보급함 필수
⑥ 탐지 확실      회랑 진입은 반드시 방어측에 노출됨
```

> **①이 회랑의 존재 이유다.** 검각을 막으면 성도로 들어갈 길은 없다.
> 소수로 대군을 저지한다는 원전의 그림이 규칙 하나로 성립한다.
>
> **④가 기획서 §6.2의 「지형 = 게임 템포」를 구현하는 지점이다.**
> 익주 회랑 돌파에 수 시간이 걸리므로, 플레이어는 접속하지 않은 사이에도
> 함대가 회랑을 통과하고 있다는 감각을 갖는다.

## 4. 기저 인접 항로

### 4.1 기본 원칙

> **인접한 두 성계 사이에 회랑이 없다면, 저효율의 기저 항로로 연결된다.**
> **회랑이 있다면 그 회랑이 유일한 통로다.**

즉 성계 간 연결은 셋 중 하나의 성격을 갖는다.

```
① 고속항로 병설   대하·관도를 따르는 최속 경로 (관문이 얹힐 수 있음)
② 회랑           통과 강제. 우회 불가. 봉쇄 시 완전 차단
③ 기저 항로      회랑도 고속항로도 없는 인접쌍. 저효율이되 항상 통행 가능
```

**어떤 성계도 완전히 고립되지 않는다.** 다만 회랑으로만 이어진 성계는
그 회랑을 잃는 순간 실제로 차단된다 — 익주·요동·서역·남중이 그렇다.

### 4.2 3단 속도 체계

| 계층 | 이동 소요 | 에너지 | 탐지 | 봉쇄 |
|---|---|---|---|---|
| **고속항로** | **×1** (기준) | ×1 | 확실 | 가능 — 우회로 존재 시 |
| **회랑** | ×3~5 | ×2 | 확실 | **완전 차단 가능** |
| **기저 항로** | ×4~6 | ×3 | 낮음 | 사실상 불가 |

### 4.3 전략적 함의

| 지형 조건 | 결과 |
|---|---|
| 회랑으로만 연결된 성계 | **관문 하나가 국경 전체.** 방어 비용 최소, 고립 위험 최대 |
| 기저 항로가 많은 성계 | 전면 방어 필요. 어디로든 들어올 수 있음 |
| 고속항로 결절 성계 | 병력 전개 최속. 대신 적도 빠르게 도달 |

**성계 성격의 대비**

- **익주** — 진출입이 전부 회랑(검각·진령삼도·기산도·남중산도). 봉쇄하면 완벽히 안전하나, 나가는 길도 같은 회랑뿐이다. 「험지와 명분」의 대가는 고립이다.
- **연주·서주** — 회랑이 하나도 없고 기저 항로로 사방과 이어진다. 주인이 자주 바뀌는 이유가 지형에 있다.
- **형주** — 고속항로 3개와 회랑 3개가 동시에 모인다. 막을 곳도 많고 뚫릴 곳도 많다.

### 4.4 등애「음평도」

회랑 강제 규칙의 **게임 내 유일한 예외**.

> **「음평도」** — **비인접 성계 간 직접 침투.**
> 지도상 연결이 존재하지 않는 **양주 → 익주** 경로를 단독으로 개척한다.
> 소요는 기저 항로에 준하되 **전 구간 탐지되지 않는다.**

**핵심:** 익주는 한중·형주·남중 세 방향으로만 이어져 있고,
서북의 양주와는 **애초에 연결이 없다.** 지도에 길이 그려져 있지 않다.
등애는 그 없는 길을 뚫는다.

> 촉이 한중을 잃어도 검각만 지키면 성도는 안전하다 — 등애가 없다면.
> **후기 시나리오에서 촉이 무너지는 이유**가 이 능력 하나로 설명된다.

### 4.5 인접 관계표

**(고)** 고속항로 · **(회)** 회랑 — 통과 강제 · 표시 없음은 기저 항로

| 성계 | 인접 성계 |
|---|---|
| **사예** | 옹주(고) · 기주(고) · 연주(고) · 예주(고) · 병주 · 남양 |
| **예주** | 사예(고) · 회남(고) · 연주 · 서주 · 남양 |
| **연주** | 사예(고) · 청주(고) · 기주 · 서주 · 예주 |
| **청주** | 연주(고) · 기주 · 서주 |
| **서주** | 회남(고) · 연주 · 청주 · 예주 |
| **기주** | 사예(고) · **병주(회)** · 유주 · 연주 · 청주 |
| **유주** | **요동(회)** · 기주 · 병주 |
| **병주** | **기주(회)** · 사예 · 유주 · 옹주 |
| **옹주** | 사예(고) · 양주(고) · **한중(회)** · **남양(회)** · 병주 |
| **양주** | 옹주(고) · **서역(회)** · **한중(회)** |
| **한중** | **익주(회)** · **옹주(회)** · **양주(회)** · 남양 |
| **익주** | 형주(고) · **한중(회)** · **남중(회)** |
| **남양** | 형주(고·양번관문) · **옹주(회)** · 사예 · 예주 · 한중 |
| **형주** | 익주(고) · 남양(고) · 오회(고) · **교주(회+운하)** · 회남 · *(태양계 소재)* |
| **오회** | 형주(고) · **회남(회)** · 교주 |
| **회남** | 예주(고) · 서주(고) · **오회(회)** · 형주 |
| **교주** | **형주(회+운하)** · 오회 · 남중 |
| **남중** | **익주(회)** · 교주 |
| **요동** | **유주(회)** |
| **서역** | **양주(회)** |

> **회랑 전용 성계** — 요동(노룡), 서역(하서)은 회랑 하나로만 세계와 이어진다.
> 남중도 익주와는 회랑, 교주와는 기저 항로 하나뿐이라 준 고립 상태다.
> 이 회랑을 잃으면 완전 고립되며, 반대로 지키면 중원의 혼란에서 벗어날 수 있다.
> **동이 연합과 서방권이 「독립 세력」으로 성립하는 지리적 근거**가 여기 있다.

### 4.6 교착 방지 — 회랑 봉쇄의 대가

**문제:** 회랑 통과가 강제되고 우회가 불가능하므로, 익주·요동·서역처럼
회랑으로만 이어진 성계는 관문 하나만 지키면 사실상 무적이 된다.

**설계 원칙:** 회랑을 약화시키지 않는다.
재현해야 할 것은 「봉쇄가 무력해지는 것」이 아니라
**「봉쇄는 성립하되, 봉쇄만으로는 이길 수 없는 것」**이다.
촉은 실제로 검각 뒤에서 40여 년을 버텼고, 버티다가 졌다.

> 기획서 §1의 주제축은 **삼국 병립 엔딩을 실패가 아닌 하나의 답으로 인정**한다.
> 따라서 교착의 발생 자체는 문제가 아니다.
> 문제는 **교착이 유리한 선택이 되는 것**이다.

---

#### ① 천명「할거」 페널티 — 주 장치

일정 기간 이상 **영토 확장 없이 방어만 지속**하면 천명이 서서히 하락한다.

| 항목 | 처리 |
|---|---|
| **발동 조건** | **연속 12개월간 신규 권역 획득 없음** [J5 확정, 2026-08-23] |
| **효과** | **매월 천명 −1.** 누적 24개월 이후 **−2** → 인재 이탈, 등용 실패, 민심 저하 |
| 완화 | 공세 개시 시 즉시 중단. 원정 실패해도 감소는 멈춤 |
| **면제** | **유랑 세력([F-40]) · 보유 권역 3개 이하 · 이민족 세력** |

> **「N턴」이 아니라 「12개월」인 이유:** 이 게임에 턴은 없다. 실시간이며
> **실제 1시간 = 게임 내 1개월**이다(`time-and-monetization.md` §2.1).
> 시나리오 1회가 게임 내 10~15년이므로 한 시나리오 안에 **열 번 이상 청구된다.**
> 그리고 촉의 북벌 간격이 대체로 1~2년이었다 —
> 「가만히 있으면 진다」가 원전의 출병 빈도와 같은 리듬으로 온다.
> 상세: `04-campaign/function-events.md` §0.3-⑤ · `DECISIONS.md` V-16

**명분:** 한실 부흥을 표방하면서 안전한 산속에 웅크려 있으면 정통성이 훼손된다.
「정통 vs 실력」 주제축이 지형 문제의 해답으로 작동한다.

> **이 장치의 진짜 가치:** 제갈량이 왜 승산 없는 북벌을 여섯 차례나 반복했는가가
> 시스템으로 설명된다. **가만히 있으면 지기 때문이다.**
> 페널티가 인위적으로 느껴지지 않고 서사가 된다.

#### ② 성장 비대칭 — 근본 구조

국력이 **보유 성계 수와 인구에 비례**하도록 설계하면,
익주 1성계는 위 9성계를 결코 따라잡지 못한다.
봉쇄하는 동안 상대는 계속 자라고, 격차는 매 턴 벌어진다.

> 별도 페널티 없이도 **교착은 그 자체로 「천천히 지는 것」**이 된다.
> ①과 병용하면 충분하며, 새로운 개념을 추가하지 않는다는 장점이 있다.

#### ③ 봉쇄 유지비 — 보조 장치

§3.3 규칙 ⑤(회랑 체류 시 보급 소모 2배)를 **방어측에도 동일 적용**한다.

| 방어 규모 | 결과 |
|---|---|
| 소수 주둔 | 저비용, 돌파 위험 상존 |
| 대군 주둔 | 안전하되 국고 압박 |

> 회랑은 거주 불가 공간이므로 주둔 함대는 후방 성계에서 보급선을 끌어야 한다.
> **병력 규모 자체가 전략 판단**이 된다.

#### 채택하지 않는 안

| 안 | 기각 사유 |
|---|---|
| 회랑 통과 비용 인하 | 검각·이릉·합비가 「그냥 좁은 길」이 됨. 지형 설계 전체가 무의미해짐 |
| 우회로 재개방 | 동일. §4.1 원칙과 정면 충돌 |
| 공격측 일방 보너스 | 밸런스는 맞아도 「일부당관」의 서사가 소멸 |

#### ④ 시즌제 대전의 별도 처리

싱글 캠페인은 ①②③으로 충분하나, **시즌제 대전(3~8인, 수일~수주)에서는 교착이 치명적**이다.
사람을 상대로는 「천천히 지는 중」이라도 끝까지 나오지 않는 플레이어가 반드시 발생한다.

| 후보 장치 | 내용 |
|---|---|
| **시즌 타이머** | 정해진 기간 종료 시 강제 판정 |
| **영역 축소** | 후반부에 외곽 성계가 순차 소실 |
| **점수제 승리** | 점령 성계 수 + 천명 합산으로 순위 결정 |

> **싱글의 룰을 그대로 가져가면 시즌이 끝나지 않는다.** 별도 설계가 필수다.

## 5. 성계 내부 구조

성계 하나는 다층 구조를 갖는다. 공략은 바깥에서 안으로 진행된다.

```
[성계 외곽] ── 항로 진입점 · 관측소 · 봉쇄 가능 지점
     ↓
[궤도권]   ── 궤도 도시 · 조선소 · 방어 위성망
     ↓
[식민지]   ── 테라포밍 거점 다수 (원전의 군·현)
     ↓
[지구형 행성] ── 인구·생산 중심 (원전의 주치·대군)
```

| 층위 | 공략 수단 | 소요 |
|---|---|---|
| 외곽 | 함대전 승리 | 단기 |
| 궤도권 | 공성함 필요 | 중기 |
| 식민지 | 강습 백병전 | 개별 공략 |
| 지구형 행성 | 공성함 + 강습부대 | 장기 |

> **부분 점령을 채택했다.** 점령 단위는 **권역**이며,
> 성계 하나는 2~4개 권역으로 나뉜다 (전체 약 45개 권역).
> 형주 성계의 강릉은 오가, 양양은 위가 쥐는 상태가 성립한다.
>
> **상세: 「부분 점령 시스템 설계 v0.1」 별도 문서 참조.**
> 항로·회랑은 특정 권역에 귀속되므로, **한 권역만 빼앗아 항로를 끊을 수 있다.**

## 6. 시나리오별 세력 배치 (예시)

### 6.1 시나리오 3 — 적벽 전야 (208)

| 세력 | 보유 성계 | 접경 회랑 |
|---|---|---|
| **조조** | 사예 · 기주 · 연주 · 청주 · 서주 · 예주 · 병주 · 유주 · **남양** · 형주 북부(양양) | 함곡 · 정형 · 무관 · 양번 |
| **손권** | 오회 · **회남 일부** · 형주 일부(강하) | 합비 · 이릉 |
| **유비** | 형주 남부 4군 (임시) | 양번 · 오령 |
| **유장** | 익주 | 검각 · 남중산도 |
| **장로** | **한중** | 검각 · 진령삼도 · 기산도 |
| **마등·한수** | 옹주 · 양주 | 함곡 · 기산 · 하서 |
| **사섭** | 교주 | 오령 |
| **공손강** | **요동** | 노룡 |
| (미개척) | **남중** | 남중산도 |

**전황 요약:** 조조는 **남양을 전진 기지로 삼아** 양번관문을 통해 남하한다.
남양 확보가 곧 형주 진입의 전제이며, 장강 대항로 진입에는 아직 실패한 상태.
손권은 **합비회랑과 이릉협도 양쪽을 동시에 방어**해야 하는 압박을 받는다.

### 6.2 시나리오 5 — 출사표 (228)

| 세력 | 보유 성계 | 공세 축 |
|---|---|---|
| **위** | 사예 · 기주 · 연주 · 청주 · 서주 · 예주 · 병주 · 유주 · 옹주 · 양주 · **남양** · **요동** | 방어 |
| **촉** | 익주 · **한중** · **남중** | **기산도** 또는 **진령삼도** |
| **오** | 오회 · **회남** · 형주 · 교주 | 합비회랑 |

**핵심 판단:** 촉은 **한중을 전진 기지로 삼아** 북벌한다.
한중을 보유해야만 기산도·진령삼도에 접근할 수 있으므로, 한중 상실은 곧 북벌 불능이다.
공세 시 **기산도(안전·저속)** 와 **진령삼도(고속·고위험)** 중 선택한다.
진령삼도의 자오도를 택하면 위연「반골」(#51)의 자오곡 계책이 발동하며,
학소「진창」(#136)이 산관도에 배치되어 있으면 돌파가 사실상 불가능하다.
